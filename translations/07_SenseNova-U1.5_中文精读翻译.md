## 摘要

我们发布 SenseNova-U1.5，一个 8B-MoT 原生统一多模态模型（native unified multimodal model），它能在无视觉编码器、无 VAE 的架构内理解、推理并生成视觉内容。我们通过空间连贯的块重建（spatially coherent patch reconstruction）强化其视觉接口，并借助精心筛选的生成与编辑数据、改进的任务表述（task formulation）、结构化提示增强（structural prompt enhancement）以及最高 4K 的原生分辨率来扩展其训练。在后训练阶段，我们针对视觉美学、中英双语文本渲染、信息图生成和图像编辑优化了专门的专家模型，并通过多专家在策略蒸馏（multi-expert on-policy distillation）将它们的能力整合为一体。在大规模评测中，SenseNova-U1.5 在图像保真度、文本渲染、复杂组合构图、多参考编辑和交错生成方面大幅进步，同时改进了指令遵循能力，并能保持主体身份、几何结构与未修改区域。尽管其生成数据中接触结构化格式的样本有限，SenseNova-U1.5 仍能有效泛化到长而复杂的结构化视觉指令，进一步证明多模态理解能力可以迁移到视觉规划与创作。这些发现共同表明，原生统一建模（native unified modelling）是构建"在完全端到端框架内感知、推理与创造"系统的一条有前景路径。我们将开源训练代码，包括监督微调、强化学习和在策略蒸馏。

## 1 引言

近年来，视觉生成正在快速超越传统的图像合成，演变为一种通用的视觉创作媒介，涵盖多语言排版、信息密集型设计、高分辨率渲染、多参考组合、细粒度的对象-背景编辑以及交错生成。然而，这一更广的范围暴露出一个根本性的架构鸿沟：大多数系统通过预训练视觉编码器（vision encoders, VEs）[108, 152, 97, 119] 感知图像，却通过变分自编码器（VAEs）[55, 145, 58, 106] 生成图像。因此，理解与生成运行在两个截然不同的表示空间中：一个为语义抽象优化，另一个为像素级保真优化。这种分离虽然有效，却限制了感知、推理与生成在统一视觉框架内跨多种视觉创作形式的协调程度。

原生统一建模（native unified modelling）走了一条不同的路：直接从像素和文字中学习。SenseNova-U1 [29] 通过无编码器、无 VAE 的 NEO-unify [101] 架构确立了这一范式的可行性，将感知、推理与像素空间生成纳入单个端到端模型。然而，其刻意轻量化的视觉接口将每个视觉 token 独立地重建为一个 RGB 块（patch）。这种做法虽然高效，却阻止了图像形成最后阶段相邻块之间的信息交换，导致接缝（seams）、纹理不连续和几何不一致在高分辨率下愈发明显。

本文提出 SenseNova-U1.5，一个用于视觉理解、推理与生成的 8B-MoT 原生统一多模态模型。其核心是**第一个重大架构转变：从独立块预测转向空间联合重建（spatially joint reconstruction）**。我们不再将每个视觉 token 孤立地映射到像素，而是把 token 投影到二维特征场（two-dimensional feature field），并通过空间卷积与 Pixel Shuffle 上采样逐步重建图像。这使得相邻区域能够在像素最终确定之前交换信息，从而让颜色、纹理和几何被联合求解而非逐块求解。该设计在保持紧凑视觉序列高效性的同时，显著提升了空间连贯性，并支持最高 4K 的原生分辨率生成。

**第二个重大进展是：从联合奖励优化转向"先专后统"（specialize-then-unify）策略**。视觉创作横跨多种本质上不同的能力——从美学合成、双语文本渲染，到信息图设计与图像编辑——每一项都具有不同的奖励信号、采样（rollout）动态和优化挑战。在单一策略中联合优化它们会导致相互竞争的目标纠缠，并稀释任务特定的收益。因此我们先专门化再统一：为不同能力分别优化专用的强化学习（reinforcement learning, RL）专家，各自配备定制的数据、奖励、采样策略和正则化；随后通过多专家在策略蒸馏（multi-expert on-policy distillation）将它们的互补优势整合起来。通过沿着学生模型自身的生成轨迹进行蒸馏，该过程在保留各专家互补优势的同时，将其能力迁移进单一统一策略。

在大规模评测中，SenseNova-U1.5 进一步证明：单一的原生视觉表示可以作为理解、推理、生成与编辑的共享基底（shared substrate），消除并行视觉通路以及编码器特征与 VAE latent 之间的反复转换。尽管将每个 32×32 像素区域压缩为单个视觉 token，这种紧凑表示仍支持高效推理，并在图像保真度、双语排版、复杂构图、多参考编辑、交错生成、指令遵循、视觉保持（visual preservation）和细粒度控制上 delivering 强劲表现。更引人注目的是，尽管训练期间对固定生成模板的依赖有限，SenseNova-U1.5 仍能泛化到长篇、组合式、高度结构化的视觉指令。这表明通过多模态理解与推理获得的结构化知识与规划能力，可以自然地迁移到视觉创作。总之，这些结果表明原生统一不仅仅是架构上的简化：紧凑的共享视觉表示既能高效支撑"看"，也能高效支撑"创"，同时让一种视觉智能所学习的能力强化另一种。

## 2 相关工作

### 2.1 原生多模态统一模型

原生视觉-语言模型（native VLMs），包括 Fuyu-8B [3]、EVE [25, 27]、Mono-InternVL [84, 83]、NEO [26, 28]、Gemma4-12B [113] 和 Inkling [117]，直接处理视觉输入而无需外部编码器，并逐步缩小了与领先的模块化 VLM [126, 96, 104, 43] 的性能差距。视觉生成领域也出现了并行趋势：近期工作直接对像素建模 [18, 19, 148, 65]，证明高保真合成不必依赖重度压缩的隐空间 [55, 120]。在这些进展之上，原生统一多模态模型日益追求在单一框架内结合理解与生成。其中，离散原生模型（discrete native models）[111, 71, 127, 21, 68, 60, 115] 通过 token 级自回归统一多模态学习；而连续原生方法（continuous native approaches）[101, 29, 79, 10] 则追求无显式分词器或隐空间瓶颈的端到端建模。基于 NEO-unify [101]，我们的 SenseNova-U 系列进一步将这一方向扩展为一个完全原生的基座模型，让理解、推理与生成从共享的视觉基底中涌现。

### 2.2 扩散模型的强化学习

在语言建模中，基于人类反馈的强化学习（RLHF）确立了由学习到的奖励引导策略优化的通用后训练范式，PPO 通过参照策略稳定更新 [93, 98]。GRPO 与 DAPO 通过移除显式价值模型、引入组相对优势（group-relative advantages）和增强的在线优化策略，提升了效率与可扩展性 [102, 147]。在线 RL 也已扩展到视觉生成：ReFL、DDPO 和 DPOK 通过偏好奖励或策略梯度优化扩散模型 [140, 5, 35]；AlignProp 与 D3PO 提升了效率并降低了对显式奖励模型的依赖 [94, 144]。最近，Flow-GRPO 与 DanceGRPO 将组相对优化扩展到扩散与流匹配模型，改进了偏好对齐、组合准确性、文本渲染和视觉质量 [74, 142]。

对于流匹配（flow-matching）模型，在线 RL 需要超越确定性常微分方程（ODE）推断的随机探索。Flow-GRPO [73] 通过基于随机微分方程（SDE）的采样实现这种探索；系数保持采样（coefficients-preserving sampling, CPS）[121] 与 Precise [163] 则通过更好地保持底层流动力学并在探索与分布保真之间取得平衡，改进了有限步采样。除采样之外，GRPO-Guard [124] 通过受控裁剪（regulated clipping）和噪声感知梯度重加权缓解奖励过度优化。现有视觉 RL 还依赖能力特定的奖励：既包括针对感知质量和文-图对齐的偏好模型 [140, 133, 86, 76]，也包括针对排版与编辑的专用奖励 [52, 47]。受这些进展启发，我们采用任务相关的 RL 后训练，将 CPS 或 Precise 采样与交错/任务特定奖励相结合，以应对生成与编辑的不同优化需求。

### 2.3 统一模型的在策略蒸馏

近期，在策略蒸馏（on-policy distillation, OPD）[1, 81] 通过让学生在自身生成的轨迹上训练、同时接受教师模型的密集监督，缓解了传统知识蒸馏的分布失配问题。在此范式上，MOPD [85] 将 OPD 扩展为多教师能力整合：独立优化的领域专家监督学生的在策略采样，使多样化推理能力得以整合进单一模型。除语言建模外，OPD 已被探索用于多模态理解与推理 [6, 149]，由教师监督学生生成的多模态轨迹。其应用最近也扩展到了视觉生成：Flow-OPD、DiffusionOPD 和 DanceOPD 分别通过教师一致性信号、转移匹配和速度场回归，沿学生生成的去噪轨迹蒸馏任务专用生成器 [36, 64, 162]。此外，DiffusionOPSD 移除了外部教师，从可微奖励梯度构造有界的自蒸馏目标 [161]。我们的设定与之互补：不是把所有任务强行塞进同一个蒸馏配方，而是保留四个任务专用的外部专家，并将其监督硬路由（hard-route）到单一原生像素空间模型中。这一设计保留了每个专家的任务相关条件化、引导与分辨率策略，同时将其专门能力整合进统一模型。

## 3 方法

### 3.1 模型架构

（图 3：SenseNova-U1.5 总览。与 SenseNova-U1 相比，U1.5 在编码与解码两端进一步精细化了近无损视觉接口：分辨率感知噪声条件扩展到 4096×4096 范围，原有的逐块 MLP 头被带 Pixel Shuffle 与 3×3 卷积的轻量空间解码器取代。这些改进在保持紧凑的 32×32 视觉 token 化的同时，增强了空间连续性、高分辨率保真度和下游鲁棒性。）

**近无损视觉接口（Near-Lossless Visual Interface）**。SenseNova-U1.5 保留了 NEO [26] 提出的轻量原生视觉接口：直接将原始图像或加噪的视觉输入变换为紧凑的 token 序列，不依赖外部视觉编码器或 VAE。具体而言，两个带 GELU 激活的卷积投影分别以 16 和 2 的因子下采样输入，使每个 32×32 的图像区域对应一个视觉 token。二维正弦位置编码保留空间坐标，特殊的 `<img>` 与 `</img>` token 界定各个视觉块。文本使用原语言分词器分词，随后视觉与文本表示被投影到共享隐空间，由统一主干联合处理。该设计在保持视觉信息近无损的同时，使序列长度对大规模多模态建模保持可控。

对于生成，有效噪声幅度随图像分辨率变化，使分辨率成为去噪过程的重要条件信号。SenseNova-U1.5 因此显式引入分辨率相关的噪声尺度嵌入。SenseNova-U1 的归一化范围校准至 2048×2048，而我们将参考分辨率扩展到 4096×4096 以更好地支持原生高分辨率合成（图 3）。设 σ_R(H,W) 为与分辨率 (H,W) 关联的噪声尺度，归一化为 σ̄_R = σ_R(H,W)/σ_max，其中 σ_max 对应 4096×4096 参考分辨率，并用专用的正弦 MLP NSEmb(·) 编码。所得嵌入与扩散时间步表示相结合：

$$
\mathbf{s}_{t}=\bm{\tau}_{t}+\mathrm{NSEmb}\!\left(\bar{\sigma}_{R}\right),
$$

为去噪器提供对扩散时间与分辨率相关噪声统计的双重显式感知。这种条件化帮助模型更一致地适应多样图像分辨率与长宽比的变化。

**空间耦合解码器（Spatially Coupled Decoder）**。紧凑的块化（patchification）大幅降低了图像建模成本，但用 MLP 独立解码每个 32×32 token 会给输出带来不理想的逐块因子化。这在高分辨率下尤其成问题：局部图像连续性使得独立块预测容易出现接缝、网格伪影和纹理不连续。因此 SenseNova-U1.5 用轻量的空间耦合解码器取代原 MLP 头。给定主干隐状态 𝐇 ∈ ℝ^{B×hw×d}，先恢复其二维拓扑 𝐇_2D ∈ ℝ^{B×d×h×w}，然后通过 Pixel Shuffle 阶段以上采样因子 2、2 和 8 逐步重建全分辨率 RGB 图像（图 3）。在相继的上采样阶段之间，3×3 卷积使相邻 token 区域之间得以交换信息，让块边界附近的像素由联合而非独立决定。该解码器在像素合成之前恢复了局部空间交互，与紧凑的 token 空间建模形成互补，使全局语义、构图与细粒度结构能够在同一端到端框架内联合优化。它与主干在流匹配目标下共同训练，以适度的额外计算改进跨块一致性与局部连续性，大幅减少边界伪影，同时增强高分辨率生成与下游适配的稳定性。

**原生 Mixture-of-Transformers（Native MoT）**。SenseNova-U1.5 保留原生 MoT 设计 [29]，将理解与生成集成在单一 Transformer 主干中，而非将其完全分离为两个独立网络。干净的图文上下文与噪声条件化的视觉状态在统一序列中交错，使语义表示、视觉证据与生成动态能够通过共享自注意力直接交互。该设计让生成持续利用多模态理解过程中形成的表示，而无需引入辅助融合模块或跨空间特征转换。

注意力模式的结构旨在调和因果语言建模与双向视觉交互：文本 token 只关注前文；每个干净图像块内部的 token 双向交互以捕捉空间依赖；噪声条件化的生成 token 同样在其图像块内双向交互，并关注所有先前的干净多模态上下文。反向路径被显式掩蔽，防止干净表示访问随机生成状态。这种非对称信息流让生成暴露于丰富的语义与视觉上下文，同时保护用于理解和推理的表示的完整性。

关键在于，架构统一并不意味着处处参数共享。理解与生成保留各自独立的注意力投影、归一化层和前馈模块，在每层按 token 类型动态路由。因此，共享注意力充当跨流通信的接口，而流专属参数保留了感知与合成所需的差异化计算。这种"密集交互+参数专门化"的组合让两种能力受益于共同表示空间，而不必将其不同的优化目标强行压入同一计算路径。

**统一训练目标（Unified Training Objectives）**。SenseNova-U1.5 采用统一目标，联合耦合自回归语言建模、原生像素空间流学习和感知监督。对于多模态理解，优化目标文本序列的条件似然：

$$
\mathcal{L}_{\mathrm{AR}}=-\frac{1}{N}\sum_{n=1}^{N}\log p_{\theta}\left(x_{n}\mid x_{<n},\mathbf{c}\right), \tag{1}
$$

其中 x_n 是第 n 个目标 token，𝐜 表示先前的多模态上下文。

对于视觉生成，SenseNova-U1.5 遵循 𝐱-预测（x-prediction）[65]，直接在 RGB 空间学习像素空间流匹配（pixel-space flow matching）。为适应不同图像分辨率，我们用分辨率自适应噪声构造训练轨迹，采样 ε ∼ 𝒩(0, 𝐈) 和 t ∈ [0,1] 以构成：

$$
\mathbf{z}_{t}=t\mathbf{x}+(1-t)\sigma_{R}(H,W)\bm{\epsilon}, \tag{2}
$$

其中 σ_R(H,W) 根据目标分辨率调整噪声幅度。随后模型尝试预测干净端点 𝐱̂_θ，由此诱导出速度估计：

$$
\mathbf{v}_{\theta}=\frac{\hat{\mathbf{x}}_{\theta}-\mathbf{z}_{t}}{1-t},\qquad\mathbf{v}^{\star}=\frac{\mathbf{x}-\mathbf{z}_{t}}{1-t}. \tag{3}
$$

最后，用像素空间流匹配损失监督该轨迹：

$$
\mathcal{L}_{\mathrm{Flow}}=\mathbb{E}\left[\left\|\mathbf{v}_{\theta}-\mathbf{v}^{\star}\right\|_{2}^{2}\right]. \tag{4}
$$

在像素空间轨迹监督之外，SenseNova-U1.5 进一步引入感知目标以改进结构一致性与局部视觉连贯性：

$$
\mathcal{L}_{\mathrm{Perc}}=\mathrm{LPIPS}\left(\hat{\mathbf{x}}_{\theta},\mathbf{x}\right), \tag{5}
$$

其中 LPIPS [154] 提供与 RGB 空间流目标互补的特征空间监督。整个训练过程在统一目标下联合优化：

$$
\mathcal{L}=\lambda_{\mathrm{AR}}\mathcal{L}_{\mathrm{AR}}+\lambda_{\mathrm{Flow}}\mathcal{L}_{\mathrm{Flow}}+\lambda_{\mathrm{Perc}}\mathcal{L}_{\mathrm{Perc}}. \tag{6}
$$

这为单一原生模型带来三种互补信号：自回归监督建立语义理解与多模态推理；流匹配直接在像素空间学习从噪声到图像的连续变换；感知监督进一步将生成端点正则化为连贯的全局结构、忠实的局部纹理和视觉上合理的外观。三者将高层语义与低层视觉形成耦合，使理解与生成得以在统一表示中学习。

**阶段 1：生成预训练（Generation Pre-Training）**。在预训练好的理解分支基础上，随机初始化生成分支，以冻结理解分支的表示为条件，通过像素空间流匹配进行训练。SenseNova-U1.5 增加了计算预算，并引入专门的原生 4K 训练阶段。训练先从 256×256 到 1024×1024 分辨率的文生图数据开始：180K 步、常数学习率 2×10⁻⁴、序列长度 8,196。随后扩展到 512×512 至 4096×4096 的更高分辨率文生图数据，强化原生 4K 生成能力：该阶段 100K 步、常数学习率 1×10⁻⁴、序列长度增至 20,480。最后阶段引入图像编辑与交错生成任务，再训练 185K 步，拓宽模型在多样下游场景中的生成能力。训练混合比例为 60% 文生图、30% 图像编辑、10% 交错图文数据；学习率从 1×10⁻⁴ 余弦衰减到 2×10⁻⁵，序列长度保持 20,480。从该阶段起，我们在流匹配目标上叠加权重为 0.1 的 LPIPS 感知损失 [154]，以改进细粒度视觉细节和局部视觉连贯性；此组合生成目标在后续统一中训与监督微调阶段全程保持。

**阶段 2：统一中训（Unified Mid-Training）**。联合优化两个分支，共享注意力促进跨分支信息交换，同时保留任务特定表示。为平衡通用多模态能力与多样生成能力，构造混合语料：30% 纯文本与多模态理解数据、40% 文生图、20% 图像编辑、10% 交错图文数据，使模型在统一训练阶段中接触感知、合成、编辑与多模态交互的互补形式。训练 80K 步、最大序列长度 32,768、常数学习率 2×10⁻⁵。理解与生成损失权重分别为 0.1 与 1.0，该加权有助于保留预训练理解能力，同时把更多优化重心分配给更具挑战性的生成目标，实现稳定的联合训练与更有效的能力整合。

**阶段 3：统一监督微调（Unified SFT）**。在精选的高质量指令遵循数据上进一步微调，任务组成与阶段 2 类似。该阶段进一步增强指令遵从，并将早期训练获得的能力巩固到统一模型中。训练 10.5K 步、学习率从 2×10⁻⁵ 余弦衰减至 0，损失系数与阶段 2 相同，以保持理解与生成目标之间的平衡。

（图 4：SenseNova-U1.5 的后训练过程，包括多专家强化学习与在策略蒸馏。）

**阶段 4：多专家强化学习（Multi-Expert RL）**。如图 4 所示，我们训练四个专家——美学、文本渲染、信息图生成与图像编辑——各自配备任务特定的数据、奖励、采样和正则化。

**（1）美学专家（Aesthetic Expert）**。单独优化视觉偏好虽可改善整体外观，却会牺牲文字可读性。因此我们在不同轮次（epoch）之间交错使用美学偏好数据与排版数据。每个分区的样本被路由到任务特定奖励：HPSv3++ [76] 评估感知质量与提示-图像对齐；基于 PaddleOCR [32] 的双语 OCR 奖励衡量文字保真度。这种路由避免了混合不同尺度与语义的奖励，同时在偏好优化中保持排版准确性。

每个提示用 30 步轨迹、引导尺度（guidance scale）4.0、时间步移位（timestep shift）3 生成 16 个候选。采用 η=0.7 的系数保持采样（CPS）[121] 引入随机探索，同时减少常规 SDE 采样的有限步伪影。每次更新从轨迹前 10 步中均匀采样一个连续 5 步窗口，把优化集中于基本决定全局内容与构图的早期去噪阶段。训练使用动态分辨率与长宽比、常数学习率 2×10⁻⁵、参考策略 KL 系数 0.01。为降低奖励引起的漂移，RL 过程中冻结最后一个生成 Transformer 块、流匹配输出头及其输出归一化层。

**（2）OCR 专家**。OCR 专家使模型专门化于精确的双语文本渲染。对每个提示，提取图中预期文字作为目标，用 PaddleOCR [32] 识别生成内容，然后在识别文本与目标文本之间计算归一化的多重集交并比（multiset IoU）分数，英文按词级、中文按字级匹配。相比精确匹配，这种分级奖励更好地捕捉部分正确的生成，同时对遗漏、重复和渲染错误保持敏感。

每个提示用 30 步轨迹、引导尺度 4.0、时间步移位 3 生成 16 个候选，并从前 10 步采样连续 5 步优化窗口。采样采用 η=1.5 的 Precise 采样 [163]，同时用 GRPO-Guard [124] 在稀疏高值 OCR 奖励下稳定优化。训练使用动态分辨率与长宽比、常数学习率 2×10⁻⁵、参考策略 KL 系数 0.02，同样在 RL 期间冻结最后一个生成 Transformer 块、流匹配输出头和输出归一化层。

**（3）编辑专家（Editing Expert）**。有效的图像编辑需要平衡三个目标：指令遵从、未编辑内容的保持、以及编辑区域的视觉质量 [131, 123]。编辑不足会使指令只被部分执行，编辑过度则可能改变本应保持不变的内容。编辑专家必须学习"改什么、保什么、以及如何把请求的修改自然融入源图像"。

编辑专家以常数学习率 4×10⁻⁵、KL 系数 0.01、采样规模（rollout size）24、噪声尺度 0.7 训练，并采用指数移动平均（EMA）。我们避免基于 SDE 的轨迹采样，因为过度随机扰动会引入残余噪声与视觉伪影。在此设置下，进一步引入两个编辑专用策略以实现有针对性的奖励监督和更有效的优化：

- **（i）多维奖励（Multi-dimensional reward）**。采用基于 VLM 的奖励框架，从五个维度评估编辑质量：指令完成度（instruction fulfillment）、编辑执行（edit execution）、整体视觉质量、适用时的文本编辑质量、以及未编辑区域的保持（preservation of unedited regions）。这些互补信号针对不同失败模式提供定向监督，同时联合平衡编辑准确性、视觉保真与内容保持。
- **（ii）渐进式训练（Progressive training）**。采用渐进式滑动窗口策略，把优化从建立语义的早期阶段逐步转移到精修纹理的后期阶段。这种由粗到细的推进先确保预期的结构改变，再提升局部保真度与同周边内容的视觉融合。

**（4）信息图专家（Infographic Expert）**。信息图生成要求准确的文字渲染、连贯的密集布局、清晰的信息层级和强大的整体视觉质量。信息图专家先经历从面向信息图的中训到任务特定 RL 的完整训练流程，以求在小文字渲染及相关能力上获得更大幅度的提升。中训阶段引入高质量真实与合成数据，并重新平衡信息图子类别之间以及信息图与其他类别数据的混合比例，进一步改进小文字渲染、复杂布局处理、信息组织与整体视觉设计质量。

在此基础上，我们分三个阶段进一步精细化信息图专家。第一阶段使用与 OCR 专家相同的训练数据和文字保真度奖励改进文本渲染。第二阶段对精选偏好对应用直接偏好优化（direct preference optimization, DPO）[61]（Linear-DPO）以增强整体视觉质量，使用常数学习率 5×10⁻⁶、DPO 损失系数 β=10，每次更新从第 1–20 步中采样一个时间步。最后阶段交替使用文本渲染数据与美学数据，分别路由到文字保真度奖励与 HPSv3++ [76]，而非合并两个分数。

第一与最后阶段使用组相对策略优化（group relative policy optimization, GRPO），每个提示在 30 步轨迹上用系数保持采样（CPS）[121] 生成 16 个候选。无分类器引导（classifier-free guidance, CFG）仅在采样收集阶段用于奖励评估，而策略目标仅由条件预测计算。两阶段均使用常数学习率 2×10⁻⁵ 和参考策略 KL 系数 0.01。

**阶段 5：多专家在策略蒸馏（Multi-Expert On-Policy Distillation）**。如图 4 所示，我们应用在策略速度场蒸馏（on-policy velocity-field distillation），把美学质量、文本渲染、信息图生成与图像编辑四个专门专家整合进单一统一模型。每个训练样本被硬路由（hard-routed）到与其能力对应的冻结专家。给定来自能力 m 的纯文本或图文条件 𝐜，学生先生成自身轨迹 {𝐱̂_{θ,t}}_{t=0}^{1}；然后在学生生成的相同状态、时间步与条件下，同时评估学生与被路由的专家：

$$
\mathcal{L}_{\mathrm{OPD}}=\mathbb{E}\!\left[\left\|\mathbf{v}_{\theta}\!\left(\operatorname{sg}(\hat{\mathbf{x}}_{\theta,t}),t,\mathbf{c}\right)-\mathbf{v}_{m}\!\left(\operatorname{sg}(\hat{\mathbf{x}}_{\theta,t}),t,\mathbf{c}\right)\right\|_{2}^{2}\right].
$$

其中 sg(·) 表示停止梯度（stop-gradient），防止梯度沿整个采样轨迹传播。每个轮次使用单一能力分区及其配对的冻结专家，并按固定顺序轮换。

文生图与图像编辑均使用固定 30 步的确定性 ODE 去噪，每条轨迹查询一个时间步。为同时学习建立全局结构的高噪声状态和决定局部细节的低噪声状态，我们在训练中渐进移动查询分布。在第 n 个轮次，连续查询位置及其离散的 0 基索引由下式确定：

$$
t_{e}\sim\operatorname{Beta}\!\left(2+3n/N,\,5-3n/N\right),
$$

其中 N 为总轮次数。该分布因此从强调轨迹早期高噪声部分的 Beta(2,5) 平滑移动到强调后期低噪声状态（即精细细节与文字保真）的 Beta(5,2)。为对齐训练与推断，我们直接在无分类器引导（CFG）下优化速度：美学、OCR 与信息图专家使用尺度 s=4 并配合全局范数裁剪（global-norm clipping），编辑专家使用 s=1。

对于文生图，先从 𝒜 = {1024², 1536², 2048², 3072², 4096²} 中选择目标面积，再从 {1:1, 16:9, 9:16, 4:3, 3:4, 3:2, 2:3, 1:2, 2:1} 中选择目标长宽比；最终宽高在保持面积的前提下计算，并取整到最近的 32 的倍数。对于图像编辑，生成分辨率跟随源图像，仅取整到最近的 32 像素倍数。

学生模型训练 800 个优化器步，全局批大小 128、梯度累积 1，每个领域使用 25,600 个样本。采用 AdamW：学习率 2×10⁻⁵、β₁=0.9、β₂=0.999、权重衰减 10⁻⁴、最大梯度范数 1、BF16 混合精度。理解分支、最后三个生成层和生成输出头被冻结。整个训练采用 30 步轨迹，但在采样到的查询转移之后立即终止，避免计算未被使用的轨迹后缀。

### 3.3 奖励建模

**美学奖励（Aesthetic Reward）**。美学质量难以用手工目标刻画，因为它同时反映构图、视觉保真、语义一致性、风格连贯与更广泛的人类偏好。因此我们采用 HPSv3++ [76] 作为偏好奖励 R_HPSv3++。其"能力感知+迭代感知"的训练方式使其特别适合 RL 后训练——因为随着生成质量提升，模型分布会持续变化。相比在固定生成分布上训练的评分器，它提供更鲁棒、更具适应性的偏好监督，帮助模型追求感知改进而不狭隘地过拟合到某个奖励面。

**OCR 奖励**。仅靠偏好奖励不足以处理排版问题：视觉上看似合理的图像仍可能包含缺失、重复或畸形的文字。为此引入显式 OCR 奖励。目标转写从提示中指定的文本片段提取，生成图像则用 PaddleOCR [32] 识别。在归一化大小写、标点和空白后，英文文本切分为词、中文切分为字。设 g_t 和 o_t 分别为 token t 在目标转写与 OCR 转写中的多重数（multiplicity），定义：

$$
R_{\mathrm{ocr}}=\frac{\sum_{t}\min(g_{t},o_{t})}{\sum_{t}\max(g_{t},o_{t})}. \tag{7}
$$

该多重集 IoU 奖励正确的 token 出现，同时对称地惩罚遗漏、幻觉和重复文本中的错误；对密集或多区域布局中不可靠的 OCR 阅读顺序也具有鲁棒性。在后训练中，美学与 OCR 提示各自使用对应奖励，并在轮次级别交错，从而无需在每个样本内合并异构的奖励尺度。

**信息图奖励（Infographic Reward）**。我们没有引入额外的信息图专用奖励模型，而是让信息图专家通过阶段条件化与任务条件化的路由复用上述 OCR 与美学奖励。第一阶段训练只用 OCR 奖励做热身（warmup）：

$$
R_{\mathrm{info}}^{warmup}(\hat{\mathbf{x}}_{\theta},\mathbf{c})=R_{\mathrm{ocr}}(\hat{\mathbf{x}}_{\theta},\mathbf{c}), \tag{8}
$$

其中 𝐱̂_θ 是生成图像，𝐜 为对应文本提示。在最后训练阶段，设 m ∈ {ocr, aesthetic} 标识提示分区，奖励按下式分配：

$$
R_{\mathrm{info}}^{final}(\hat{\mathbf{x}}_{\theta},\mathbf{c},m)=\begin{cases}R_{\mathrm{ocr}}(\hat{\mathbf{x}}_{\theta},\mathbf{c}),&m=\mathrm{ocr},\\ R_{\mathrm{HPSv3++}}(\hat{\mathbf{x}}_{\theta},\mathbf{c}),&m=\mathrm{aesthetic}.\end{cases} \tag{9}
$$

因此 OCR 分数与 HPSv3++ 分数既不相互求和，也不相互归一化。这种路由保留了它们各自的尺度与语义，同时为文本保真与感知质量提供互补监督。

**编辑奖励（Editing Reward）**。图像编辑的强化学习需要这样的奖励信号：不仅评估请求的修改是否成功完成，还要评估结果是否视觉可信、无关源内容是否被保持。单一的整体分数会掩盖这些不同的失败模式，让某一方面的强度弥补另一方面的关键错误。因此我们采用一组维度专属奖励：（i）指令完成度衡量编辑结果的语义正确性与请求修改的完整性；（ii）编辑执行质量评估目标区域的视觉质量及其与周边上下文的融合自然度；（iii）整体视觉质量捕捉全局技术质量与预期风格的连贯性；（iv）当涉及可见文字修改时，文本编辑质量进一步评估文字正确性与渲染质量；（v）未编辑区域保持比较源图与编辑图，惩罚目标区域之外的意外语义、结构或视觉变化。对于有多个子维度的准则，保留最小子维度分数以暴露最弱的一面。归一化后，适用分数按下式聚合：

$$
R_{\mathrm{edit}}=\min\!\left(\left\{R_{\mathrm{inst}},R_{\mathrm{exec}},R_{\mathrm{visual}},R_{\mathrm{pres}}\right\}\cup\left\{R_{\mathrm{text}}\ \middle|\ \mathrm{text\ edit\ is\ applicable}\right\}\right). \tag{10}
$$

对不涉及文字修改的指令省略文本编辑准则；当请求的修改没有可见实现时，编辑执行分数置零。这种瓶颈式聚合（bottleneck-style aggregation）强调每次编辑的最弱方面，防止某一维度的强势表现掩盖另一维度的关键失败。因此，该奖励对不完整编辑、意外修改和局部质量缺陷保持敏感，为图像编辑 RL 提供更平衡、更可靠的监督。

如图 5 所示，SenseNova-U1.5 大幅扩展了 SenseNova-U1 [29] 的训练语料，重点提升数据多样性、视觉质量、高分辨率生成、复杂指令遵循和细粒度图像编辑。除扩大规模外，我们还通过质量感知过滤、分布再平衡、更强的图文对齐以及针对欠表现能力的定向合成，系统性地改进数据治理。

### 4.1 图像生成数据

图像生成语料结合了大规模真实图文对、精心筛选的公开与专有来源，以及高质量合成数据。相比 SenseNova-U1，我们从 78 个来源新增约 5900 万（59M）文图对，大幅拓宽了通用场景、人物中心内容、物体与材质、富文本图像、信息图及其他专门视觉领域的训练分布。重要的是，高分辨率样本占训练混合的很大比例：约 88.2% 的有效训练量超过 1024² 分辨率，64.4% 超过 2048²。这使模型接触多空间尺度的丰富视觉统计，既为全局连贯的场景构图与布局提供监督，也为细粒度局部结构、纹理、材质及其他高频视觉细节提供监督。

为改进指令对齐，描述（caption）在多个粒度上构建，从长篇详细描述到简洁说明再到轻量语义标签。我们进一步加强中英双语覆盖——尤其针对富文本图像——并显式校验提示中指定的语言/文字与图中渲染文字的一致性。为补充真实数据，我们收集网络规模数据，并针对稀有概念、复杂布局和文字密集型设计引入定向合成。合成与真实样本经过共享过滤管线，联合评估感知质量、提示保真、文字正确性、布局质量与视觉多样性，确保高质量且均衡的训练分布。

### 4.2 图像编辑数据

图像编辑语料约 3800 万（38M）样本，覆盖四种互补设定：通用图像编辑、信息图编辑、参考条件编辑（reference-conditioned editing）与空间控制编辑（spatially controlled editing）。这些设定共同覆盖广泛的编辑场景，包括局部属性修改、物体插入与删除、场景级变换、姿态与动作编辑、修复与增强、文字与布局操控、参考引导定制，以及区域控制操作。为提升对固定指令模式之外的鲁棒性，我们同时多样化底层视觉内容与编辑指令的表述、粒度和复杂度。对于具有挑战性的多目标或多约束编辑，我们进一步引入结构化提示增强与思维链（chain-of-thought）样本，显式刻画编辑意图、目标区域、期望属性、空间或语义约束以及应保持不变的内容。这种结构化监督减少了指令歧义，为精确、忠实、保持感知的编辑提供了更强引导。

语料由约 43% 通用编辑、约 42% 空间控制的信息图编辑样本，以及约 15% 支持单参考与多参考编辑的参考条件子集构成。信息图数据结合程序化渲染的源-目标对与模型生成样本，能够精确操控文字、视觉元素、布局结构与整体风格。参考条件数据强调主体与身份保持、属性迁移、构图整合，以及跨视角、姿态、几何与光照的受控变换，每个样本最多包含十张参考图。空间控制数据进一步通过边界框与视觉标记引入显式的区域级引导，支持更精确、更交互式的操控。在所有编辑设定中，数据治理联合评估指令完成度、目标质量、参考/身份保真（如适用）以及预期编辑区域之外的内容保持。

### 4.3 交错数据

语料大部分来自生活方式导向的轨迹（约 44%），包括程序性教程、日常场景与绘本叙事。这些样本为维持长程语义连贯、视觉一致性和跨交替文本-图像段的跨模态依赖提供丰富监督。信息图数据贡献约 29%，强调结构化构图、密集文本内容以及语言与视觉元素的协调生成。视频衍生序列约占 19%，引入时间演化、状态转移与跨帧依赖。其余约 8% 为推理密集型样本，附带显式中间推理，用于复杂多步理解与生成。

我们不是把这些来源当作孤立的任务集合，而是将其转换为统一的轨迹格式（unified trajectory format），其中文本与视觉状态渐进交错 [21, 139]。这种统一表述让模型接触从局部图文接地（grounding）到长程语义推进、时间连续性与推理条件化多步生成的广泛多模态依赖。值得注意的是，所有轨迹都通过共享管线构建——源预处理、领域特定变换或合成、轨迹级验证——并对语言有效性、视觉质量、跨模态一致性以及完整多模态递进的连贯性与正确性进行联合过滤。

### 4.4 RL 训练数据

**美学、OCR 与信息图样本**。美学样本方面，我们通过组合 HPSv3++ [76]、Pick-a-Pic [56]、经 Cosmos3PE [89] 扩展的双语提示，以及覆盖多样主题、风格、构图与空间配置的内部生成提示，构造约 28 万（280K）条提示。每条提示生成多张图像并用 HPSv3++ 评分；移除奖励变化弱的提示组，以保留能提供更具判别性相对监督的样本。OCR 语料包含约 6 万（60K）条双语文本渲染提示，中英文覆盖均衡；其中包括从 Flow-GRPO [74] 收集约 2 万（20K）条短文本提示，经改写扩展为约 4 万（40K）条文字更密、渲染要求更复杂的长提示；指定文字被提取为参考转写用于在线 OCR 奖励计算。信息图样本方面，第一个 GRPO 阶段复用 OCR 语料，后续 GRPO 阶段按任务特定奖励联合迭代 OCR 与美学提示。我们进一步从 Linear-DPO 语料 [61] 引入约 12 万（120K）对经过过滤的偏好对用于 DPO，并对人像/非人像内容与中英提示做额外平衡，以改进整体视觉偏好对齐。

**图像编辑样本**。编辑专家在约 12 万（120K）样本上训练，局部与全局编辑分别约占 80% 与 20%。局部编辑覆盖信息图与文档操控、场景与对象级编辑、人物动作与姿态调整、人像修饰、文字替换、图像修复与增强、以及边界框或掩码条件编辑；全局编辑聚焦连贯的图像级变换。指令涵盖中文、英文与混合语言，指令长度在预定义区间内均衡，训练分辨率从 512×512 到 2048×2048。数据治理分三阶段：首先移除损坏、重复、低分辨率或视觉退化的样本，保留多样的常见长宽比；然后验证每条指令指定的实体、文字、空间区域与视觉属性确实存在于源图像中，且目标图像忠实实现所请求的修改；最后对源图与编辑图评估美学、技术质量、结构与纹理丰富度，用保守的成对聚合暴露任一图像的缺陷。保留样本再按任务类别与分辨率级别重新平衡，形成多样且具挑战性的分布。

## 6 结论

我们提出 SenseNova-U1.5，作为迈向原生多模态系统的又一步——在这样的系统中，视觉理解与生成在共同的计算基底中学习，而非通过分离的感知与生成流水线相连。我们的大量结果表明，这一方向可以扩展到超越基础图像合成：紧凑的原生表示既能持续支撑强大的理解能力，又能令人印象深刻地支持高保真生成、编辑、交错生成与推理密集的视觉任务。

更广泛地看，SenseNova-U1.5 表明多模态统一的核心机遇不是架构简化，而是**能力交互（capability interaction）**。推理可以改进视觉内容的创作与变换方式，而生成本身可以成为模型解决视觉问题的内部过程的一部分。这模糊了感知与创造之间的传统边界，并指向一类新的基座模型：看、推理与生成不再作为松耦合的函数分别训练，而是作为共享视觉智能的不同表达而涌现。我们将此视为迈向"不仅组合模态、而且发展出解释、想象并作用于视觉世界的统一机制"的多模态模型的重要一步。

## 创新点提炼

1. **空间联合重建的视觉解码接口**。U1.5 把 SenseNova-U1 的"逐 token 独立 MLP 块预测"升级为空间耦合解码器：将 token 恢复为二维特征场后，经 Pixel Shuffle（2×/2×/8×）与 3×3 卷积逐步重建全分辨率图像，使相邻块在像素定稿前交换信息。这以极小的计算开销解决了高分辨率下的接缝、网格伪影与纹理不连续问题，是实现 4K 原生生成的关键架构基础。

2. **"先专后统"的多专家后训练范式**。不同于把美学、OCR、信息图、编辑四种异质能力塞进单一奖励联合优化，U1.5 先为每项能力训练定制化的 RL 专家（各自的数据、奖励、采样策略、冻结策略与正则化），再通过多专家在策略蒸馏把四个专家整合进单一模型。硬路由机制保留了每个专家的任务相关条件化与引导策略，避免了目标纠缠与能力稀释。

3. **面向流匹配原生模型的多专家在策略蒸馏设计**。学生沿自身 30 步确定性 ODE 轨迹生成，在相同状态与时间步下向被路由的冻结专家做速度场回归（带停止梯度）；查询时间步的分布随训练从 Beta(2,5) 平滑过渡到 Beta(5,2)，先学全局结构后学细节与文字保真；并在 CFG 尺度下直接优化速度以对齐推理。这是 OPD 思想在原生像素空间统一模型上的系统性落地。

4. **任务/阶段条件化的奖励路由与瓶颈式奖励聚合**。OCR 奖励采用多重集 IoU（对称惩罚遗漏、幻觉与重复），与 HPSv3++ 美学奖励按任务分区路由而非混合归一；信息图专家完全复用这两类奖励、无需新增奖励模型；编辑奖励则以五个维度的最小值做瓶颈式聚合，防止单一维度强势掩盖关键失败。这些设计共同解决了多能力 RL 中奖励尺度与语义异构的难题。

5. **紧凑表示下的"理解-生成"双向增益**。每个 32×32 区域仅一个视觉 token，却同时支撑 SOTA 级理解与生成：理解能力（结构知识、规划）迁移到视觉创作（VBVR-Pro 68.2 超越 Nano-Banana-Pro 与 GPT-Image-2、WISE/RISEBench 上 CoT 显著增益），而生成本身又成为推理的中间表示（RealUnify-GEU 56.3 领先）。这验证了"共享视觉基底上能力相互强化"的核心论点。

6. **大规模高分辨率数据体系与原生 4K 训练**。新增 59M 文图对（88.2% 超过 1024²、64.4% 超过 2048²）、38M 编辑样本（含参考条件与空间控制子集）与统一轨迹格式的交错语料，配合分辨率感知噪声条件扩展至 4096×4096，使模型在不依赖 VAE 隐空间的前提下原生掌握 4K 合成、双语密集文本渲染与复杂信息图布局。
