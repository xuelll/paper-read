## 一句话核心总结

SpatialReward 通过"Think-with-Boxes"机制——先预测编辑区域的边界框，再以交错 token（interleaved tokens）把文本推理锚定到这些区域，迫使评测模型在源图与编辑图的对应区域之间执行像素级交叉验证——修复了 MLLM 评测器中"注意力坍缩"（Attention Collapse）这一感知鸿沟，使一个 8B 开源奖励模型在 MMRB2 与 EditReward-Bench 上达到 SOTA，并作为在线 RL 奖励把 OmniGen2 在 GEdit-Bench 上提升 +0.90（约为 GPT-4.1 增益的两倍）。

## 摘要

在线强化学习（Online Reinforcement Learning, RL）为复杂图像编辑提供了一条颇具前景的途径，但目前受制于可靠、细粒度奖励信号的稀缺。现有评测器普遍受困于一个本文称之为**"注意力坍缩"（Attention Collapse）**的关键感知鸿沟：模型忽视跨图像比较、无法捕捉细粒度细节，导致感知失真与分数失准。为解决这些局限，本文提出 **SpatialReward**——一个通过显式空间推理强制执行精确验证的奖励模型。通过将推理锚定到预测出的编辑区域，SpatialReward 把语义判断落实在像素级证据之上，显著提升了评估准确性。在精心构建的 26 万条（260k）空间感知数据集上训练后，该模型在 MMRB2 与 EditReward-Bench 上取得最先进性能，并在本文提出的 MultiEditReward-Bench 上超越专有评测器。此外，SpatialReward 在在线 RL 中充当稳健信号，使 OmniGen2 在 GEdit-Bench 上提升 **+0.90**——超过领先的判别式模型，且为 GPT-4.1 增益（+0.45）的两倍。这些结果表明，空间推理是释放图像编辑有效对齐能力的关键。

## 1 引言

指令引导的图像编辑（instruction-guided image editing）（Brooks et al., 2023; Zhang et al., 2023; Xu et al., 2025）发展迅速，已从简单的风格迁移走向对复杂场景的精确编辑。这类任务要求模型在保持非目标区域的同时，可靠地执行多条指令。然而，当前模型常常陷入一种两难境地：成功执行了编辑，却在不经意间损害了源图像的身份或一致性，例如改变原始结构或背景风格。这一问题暴露了纯监督微调（Supervised Fine-Tuning, SFT）的局限——它倾向于拟合数据均值，在长尾或组合式案例上表现不佳。

与之相反，在线强化学习（Online RL）将编辑视为一个交互式试错过程，允许策略探索分布外数据并与人类偏好对齐。这一范式已在 LLM 中得到成功验证（Ouyang et al., 2022; Touvron et al., 2023; Guo et al., 2025），并近期被 Flow-GRPO（Liu et al., 2025a）与 Dance-GRPO（Xue et al., 2025）等方法推进到生成模型。然而，这些强大优化器的有效性，在很大程度上依赖一个**可靠、高效、可解释且具备细粒度空间感知能力**的奖励模型。

当前奖励机制在用于图像编辑的交互式在线 RL 训练时，暴露出三个关键局限。

**第一，成对（pairwise）奖励只关注相对排序**。尽管 MMRB2（Hu et al., 2025）等基准显示闭源模型具有强大的零样本性能，但这种相对比较无法提供在线 RL 所必需的绝对标量信号。排序的转换会引入歧义，且所需的成对推理带来高昂的计算负担（通常为 $O(N^2)$），对在线优化造成不可接受的延迟。

**第二，逐点（pointwise）判别式模型**（如 EditReward，Wu et al., 2025d）在 VLM 嵌入之上训练一个线性头来回归偏好分数。这类模型缺乏显式推理路径，且依赖昂贵的人工标注，可扩展性受限。

**最后，逐点生成式"MLLM-as-a-judge"方法**通过显式建模推理链提供了有前景的方向。然而，它们难以满足图像编辑的独特需求：**严格的跨图像区域比较**。缺乏锚定这一比较的显式空间引导，即便是 GPT-5 这样的先进模型也存在根本性的感知鸿沟（perception gap）：它们难以对齐并验证跨图像的细粒度细节。这一缺陷在蒸馏过程中传播并放大，尤其体现在 EditScore（Luo et al., 2025）这类定制奖励模型中。如图 1(b) 所示，其表现为**"注意力坍缩"**——模型的注意力不再关注源图语境，而是坍缩进一种盲目的沉没（sink）状态。这实际上使源图像"不可见"，令跨图像比较这一关键任务退化为单图评估，与源语境的不一致之处极易被忽略，导致评分显著偏离人类偏好。

> **图 1**：跨图像注意力鸿沟可视化。(a) 输入对：编辑指令（"把面料改成丝绸"）被执行，但存在细微不一致。(b) 基线（注意力坍缩）：由于忽视源图，基线未能关注参考图像，做出错误批准该编辑的盲目判断。(c) SpatialReward（交叉验证）：通过将推理锚定到显式空间区域（红框），本文模型恢复了跨图像注意力，使有据可依的验证正确检测出风格偏差。

为弥合这一感知鸿沟，本文主张：**可靠的奖励建模必须建立在显式空间推理之上**——以锚定感知来保证精确验证与准确评分。为此，本文提出 **SpatialReward**：首个将显式空间推理融入图像编辑生成式逐点评估的框架。其核心**"Think-with-Boxes"**机制（图 2）通过预测编辑相关的空间坐标并利用交错 token 锚定文本推理，打破了注意力坍缩。该策略迫使模型在原图与编辑图的对应区域之间执行像素级验证，从而确保最终标量奖励忠实反映细粒度编辑质量。如图 1(c) 所示，这种被矫正的注意力分布能够精确检测此前被隐式基线忽略的细微不一致——例如无意的样式改动。

> **图 2**：SpatialReward 概览及与基线的比较。（左）基线（EditScore）缺乏空间引导，导致注意力坍缩与幻觉式判断；具体而言，它忽略了医生口罩的移除与患者姿态的改变。（右）SpatialReward 采用 Think-with-Boxes 机制：先预测边界框（编辑区域），并将其作为交错 token 注入以锚定后续推理。这强制了交叉验证（以矫正后的注意力图可视化），能够精确检测细粒度不一致（如口罩缺失、姿态改变）并确保评分对齐。

为支撑该框架，本文构建了 **SpatialReward-260k**。通过显式空间坐标对教师模型的推理施加空间先验，蒸馏出高质量的区域级推理轨迹；随后分阶段训练——从 SFT 到 GRPO——以强化空间推理并强制评分一致性。

本文在三个图像编辑奖励基准上评估 SpatialReward：MMRB2（Hu et al., 2025）、EditReward-Bench（Luo et al., 2025）以及新提出的 MultiEditReward-Bench（MER-Bench）。SpatialReward（8B）在所有指标上展现优越性能：相对生成式基线 EditScore-8B，其在 EditReward-Bench 上提升 +11.3%、在 MMRB2 上提升 +9.1%，超越领先判别式评测器 EditReward 与所有先进专有模型。此外，它在线上 RL 中具有重要实用价值：将 OmniGen2（Wu et al., 2025b）在 GEdit-Bench（Liu et al., 2025b）上的性能提升 +0.90，这一幅度接近 GPT-4.1（+0.45）的两倍。这些结果表明，具备显式空间感知的细粒度反馈，是高效增强图像编辑在线 RL 效能的关键。

**本文主要贡献**如下：

1. 识别出基于 MLLM 的评测器中的感知鸿沟，发现缺乏空间锚定会导致注意力坍缩，并论证显式空间接地（spatial grounding）是弥合该鸿沟的必要条件；
2. 提出 SpatialReward——首个将显式空间推理融入图像编辑生成式逐点评估的框架；为此构建 SpatialReward-260k，一个包含高质量空间推理轨迹的大规模数据集；
3. 发布 MultiEditReward-Bench（MER-Bench）——一个构建复杂多区域组合、严格考验奖励模型空间感知与验证能力的基准；
4. 大量实验表明：SpatialReward 在公开基准上取得最先进结果，并通过在线 RL 显著提升下游编辑性能，超越专有评测器。

## 2 相关工作

### 2.1 指令引导的图像编辑与对齐

早期指令跟随编辑模型主要依赖在合成数据集上的 SFT。InstructPix2Pix（Brooks et al., 2023）与 MagicBrush（Zhang et al., 2023）等先驱证明了在成对数据上训练扩散模型的有效性。近期进展集成了多模态 LLM（MLLM）以增强指令理解，如 MGIE（Fu et al., 2023）与 OmniGen（Wu et al., 2025b）（译注：原文此处引用指向 OmniGen2 一文）。虽然有效，基于 SFT 的方法倾向于坍缩到训练数据的众数，常难以处理复杂的组合式指令。为此，强化学习被引入以将生成模型与人类偏好对齐。文生图领域的开创性工作，如 ImageReward（Xu et al., 2023）与 DPOK（Fan et al., 2023），利用 RLHF 提升美学质量。近期，DDPO（Black et al., 2023）与 D3PO（Yang et al., 2024）等算法实现了对扩散模型的直接优化。这一范式正扩展到编辑领域：Flow-GRPO（Liu et al., 2025a）与 Dance-GRPO（Xue et al., 2025）利用随机探索逃离局部最优。然而，若缺乏可靠、细粒度的奖励模型，即便强大的优化器也容易发生奖励作弊（reward hacking）或次优收敛。

### 2.2 生成与编辑的奖励建模

CLIP-Score（Radford et al., 2021）与 PickScore（Kirstain et al., 2023）等标准 T2I 指标评估整体对齐，但缺乏粒度。近期工作通过将评估分解为源自人类偏好的多维子准则（如美学、语义）来解决这一问题，如 MPS（Zhang et al., 2024）、VisionReward（Xu et al., 2024）与 HPSv3（Ma et al., 2025）。在编辑领域，方法还需要跨图像验证。EditReward（Wu et al., 2025d）训练一个判别式回归头。为利用强模型的推理能力，UniPic 2.0（Wei et al., 2025）通过 VIEScore（Ku et al., 2024）使用 GPT-4.1，EditScore（Luo et al., 2025）则蒸馏了这一能力。另一新兴范式（如 RewardDance，Wu et al., 2025c；OneReward，Gong et al., 2025）从生成式"Yes/No"回复的 token 概率中直接导出标量奖励。尽管有这些进展，大多数方法依赖**隐式特征匹配而无显式空间接地**，导致复杂编辑场景下的注意力坍缩与不可靠评估。

### 2.3 视觉推理与空间接地

Shikra（Chen et al., 2023）、Qwen-VL（Bai et al., 2023）、Kosmos-2（Peng et al., 2023）与 Ferret（You et al., 2023）等视觉-语言模型（VLM）已经证明，预测显式空间坐标能够强化物体-属性绑定。尽管思维链（Chain-of-Thought, CoT）推理已减少了 VQA 中的幻觉，当前的图像编辑奖励模型尚未利用这些进展来实现稳健评估。

## 3 方法

本文提出 SpatialReward——一个基于细粒度空间推理的奖励模型。本文将奖励建模形式化为条件生成任务：模型将输入 $X$ 映射为结构化输出序列 $Y$。方法由四部分组成：评估协议（3.1 节）、"Think-with-Boxes"架构（3.2 节）、数据流水线（3.3 节）与训练策略（3.4 节）。

### 3.1 评估协议

为实现细粒度评估，本文扩展 VIEScore（Ku et al., 2024），将质量分解为**语义一致性**（Semantic Consistency, SC，含指令遵循 $s_{if}$ 与源一致性 $s_{con}$）与**感知质量**（Perceptual Quality, PQ，含自然度 $s_{nat}$ 与伪影 $s_{art}$）。最终奖励通过层级聚合（hierarchical aggregation）构造：维度内分数为加权和（如 $S_{SC}=w_1 s_{if}+w_2 s_{con}$），而全局奖励用几何平均平衡保真与真实感：

$$
R_{final}=(S_{SC})^{\alpha}\cdot(S_{PQ})^{1-\alpha}.
$$

该加权形式确保奖励信号在各维度上保留密集信息，同时重罚不均衡的质量。详细参数见 5.4 节。

### 3.2 "Think-with-Boxes"架构

遵循分解式评估范式，本文将推理定制为两条流（stream）。为形式化空间先验，将模型输出定义为结构化元组 $Y=(B,\mathcal{T},\mathbf{s})$，包含空间坐标 $B$、文本理由 $\mathcal{T}$ 与标量分数 $\mathbf{s}$。

**SC 流**模仿人类验证编辑的方式：**先定位、再检查**。本文相信，准确的评估始于知道该看哪里。显式定位将文本指令链接到具体图像区域，引导模型注意力聚焦相关区域，防止"注意力坍缩"。

具体而言，该过程分三步展开：首先，模型预测边界框 $B$ 以索引所有被编辑物体（**定位**，Localization）。接着，生成理由 $\mathcal{T}$（**锚定验证**，Anchored Verification）：引用框 token（如 `<|bbox_id|>`）显式触发对物理像素的"回看"（look-back）以减少幻觉，而 `<|global|>` token 则强制一次上下文扫描。最后，输出 SC 分数 $\mathbf{s}_{sc}=[s_{if},s_{con}]$（**评分**，Scoring）。

**PQ 流**采用感知解耦（perceptual decoupling）策略。通过仅向模型输入编辑图 $I_{out}$ 实现**输入隔离**，强制进行无参考的全局扫描以评估绝对视觉保真度。此模式下，输出仅含纯文本理由 $\mathcal{T}$（此时 $B=\emptyset$）与 PQ 分数 $\mathbf{s}_{pq}=[s_{nat},s_{art}]$。

> **图 3**：空间先验引导数据流水线示意。本文利用空间先验构建高度结构化的数据集：包括基于 Qwen-3-VL 的空间定位、面向推理标注的专家路由（使用 Gemini 与 GPT 系列），以及严格的比对验证过程。

### 3.3 空间先验引导的数据流水线

高质量推理数据是 SpatialReward 的基石。为确保空间精度与领域专业性，本文设计了一条融合**类别专属专家路由**（Category-Specific Expert Routing）的空间先验引导（Spatial-Prior-Guided）流水线，渐进地生成并组装 $Y$ 的各组件（译注：原文此处写"提示见附录 A"，但提示模板实际收录于附录 D）。

**步骤 I：空间定位（生成 $B$）**。使用一个鲁棒的 VLM（如 Qwen-3-VL-235B-A22B-Instruct）为所有样本生成边界框，产出空间先验 $B$ 作为后续步骤的聚焦点。

**步骤 II：专家路由与标注（生成 $\mathcal{T}_{raw}$ 与 $\mathbf{s}$）**。依据模型强项路由样本：以人为中心的编辑被导向 Gemini-2.5-Pro（在面部细节上更强）并配合裁剪聚焦的提示；一般物体编辑则路由至 GPT-5，并以可视化边界框叠加（bounding box overlays）增强以强制空间聚焦。这些专家生成初始理由 $\mathcal{T}_{raw}$ 与分数 $\mathbf{s}$。视觉感知质量（PQ）由 GPT-5 独立评估。

**步骤 III：比对与验证（精炼 $\mathcal{T}$）**。该步骤统一格式并去除幻觉。在比对（alignment）阶段，标注被回传给 Qwen-3-VL-235B-A22B-Instruct：对 SC 数据，模型将 $B$ 与 $\mathcal{T}_{raw}$ 融合，把理由改写为交错格式 $\mathcal{T}$；在一致性检查阶段，若 $\mathcal{T}$ 与 $B$ 中的视觉证据矛盾，该样本被标记为幻觉并丢弃。

最终的 **SpatialReward-260k** 数据集由三个来源编译：(1) 精炼的 EditScore 数据（100k；清洗有噪声的 $\mathcal{T}/\mathbf{s}$ 并注入空间先验 $B$）；(2) 再利用的 EditReward 数据（100k；丢弃原始粗粒度分数，重新生成细粒度推理组件）；(3) 自建的 Multi-Edit 集（60k；遵循 4.2 节定义的多样任务分类法构建）。

### 3.4 两阶段训练策略

本文采用渐进式训练范式，以确保能力对齐与稳健评估。

**阶段 1 为 SFT**。在合成数据集上微调 Qwen-3-VL-8B-Instruct 主干，目标为最大化目标序列 $Y$ 的概率，即最小化负对数似然：

$$
\mathcal{L}_{SFT}=-\sum_{t=1}^{T}\log P_{\theta}(y_t\mid y_{<t},X),
$$

其中 $Y$ 对 SC 任务按 $(B,\mathcal{T},\mathbf{s})$ 展开，对 PQ 任务按 $(\mathcal{T},\mathbf{s})$ 展开。

**阶段 2 为在线一致性 RL**。为抑制幻觉，本文采用组相对策略优化（Group Relative Policy Optimization, GRPO）（Guo et al., 2025）。从训练集中挖掘 7k 条 SFT 模型表现挣扎的低分困难样本，以 Gemini-3.0-Flash 作为**在线监督者**（Online Supervisor），生成一致性分数（0~1）作为奖励。其目标是增强稳定性并惩罚无依据的推理：

$$
\mathcal{J}_{GRPO}=\mathbb{E}\Big[\frac{1}{G}\sum_{i=1}^{G}\frac{\pi_{\theta}(o_i\mid q)}{\pi_{\theta_{old}}(o_i\mid q)}\hat{A}_i\Big]-\beta\,\mathbb{D}_{KL}(\pi_{\theta}\,\|\,\pi_{ref}), \tag{1}
$$

其中优势基于组奖励计算：$\hat{A}_i=(r_i-\mathrm{mean}(\{r_j\}))/\mathrm{std}(\{r_j\})$。

## 4 MultiEditReward-Bench

### 4.1 概述

MultiEditReward-Bench（MERBench）是一个系统性基准，旨在严格考验开源与专有模型在复杂编辑任务上的评估与空间推理能力。它整合 15 个多样子任务，并利用 11 个最先进的生成系统来模拟真实、高方差的编辑场景。通过整合复杂人类偏好，MERBench 在模糊直觉与精确评估之间架起桥梁，提供一个超越简单单轮评估、要求细粒度空间验证的综合测试床。

### 4.2 基准构建

为确保稳健性与真实性，本文设计了一条强调源数据、编辑指令与生成模型三个层面多样性的完整流水线（完整构建流程见附录 A，详细统计见附录 A.2）。

**来源与指令**。从 laion2B-en-aesthetic（Schuhmann et al., 2022）、CC12M（Changpinyo et al., 2021）与 headshot_pexels_v1 采样多样图像。使用 Qwen-3-VL-235B-A22B-Instruct（Bai et al., 2025）生成含 2–5 个操作的指令，划分为三类：(1) 通用编辑（General Editing，属性、背景）；(2) 以人为中心的基础编辑（Human-Centric Basics，姿态、服装）；(3) 以人为中心的细节编辑（Human-Centric Fine Details，微表情、纹理）。由此得到 15 个细粒度子任务，并以 2:1:1 的均衡比例组成。

**基于模型的生成**。每条指令从 11 个系统的多样池中采样 6 个输出，覆盖开源到 SOTA 专有模型：Step1X（v1.0/v1.1）（Liu et al., 2025b）、Qwen-Edit（Std/2509）（Wu et al., 2025a）、OmniGen（v1/v2）（Xiao et al., 2025）、FLUX（Dev/Pro）（Labs et al., 2025）、Bagel（Deng et al., 2025）与 seedream（v4.0/v4.5）（Seedream et al., 2025）。这确保了具有挑战性的质量分布。

### 4.3 标注流水线

为确保可靠性，本文实施了由受训人类专家独力执行的严格流水线（详见附录 A.1）。标注前，专家先经校准以统一标准。流程遵循**分层排序协议**（Hierarchical Ranking Protocol）：

（1）**标注**：对每个样本，五名标注者独立评估语义一致性（SC）与感知质量（PQ）作为辅助参考，再给出最终的整体质量层级（Good、Medium、Poor）。最终标签由多数投票加共识讨论得出。

（2）**排序与组合**：整体质量作为主排序键，并用 SC 与 PQ 消解并列。最终基准由随机采样构造的 600 个评估组（1,800 个样本）构成，以测试区分精度：200 个（2-Pair）集合用于基础比较；200 个（3-Pair）集合各含 Good、Medium、Poor 三个样本，用于粗粒度排序；200 个（4-Pair）集合在 3-Pair 基础上引入第四个**仅能通过细粒度子维度（SC/PQ）区分**的样本。该设计严格检验奖励模型能否产生细粒度的精确分数并将其转化为正确排序。

## 5 实验

### 5.1 实现细节与配置

本文在 Qwen-3-VL-8B-Instruct 上实现 SpatialReward，经 SFT（260k 样本）与 GRPO（7k 复杂样本）训练。遵循 EditScore（Luo et al., 2025），采用 VIEScore（范围 $[0,25]$）作为回归目标。聚合时使用在验证集上确定的校准权重：$\alpha=0.80$，SC 为 $w_{SC}=\{0.6,0.4\}$，PQ 为 $w_{PQ}=\{0.5,0.5\}$。这些参数在所有实验中统一应用。5.4 节针对标准聚合基线验证了该配置的有效性。

### 5.2 奖励基准上的性能

本文在三个基准上评估 SpatialReward：用于通用奖励建模的 EditReward-Bench（Luo et al., 2025）、用于图像编辑评估的 MMRB2（Hu et al., 2025），以及用于复杂多约束推理的 MER-Bench。对比对象为最先进专有模型（GPT-4.1、GPT-5、Gemini-2.5-Pro（Comanici et al., 2025）、Gemini-3.0-Flash）与领先开源评测器（EditScore-8B、EditReward）。为保证公平，所有专有模型均在逐点 VIEScore 设定下评估（表 1）。

相对直接的生成式基线 EditScore-8B，SpatialReward 在 EditReward-Bench 上取得 +11.3% 的显著提升（0.803 对 0.690），在 MMRB2 上取得 +9.1% 的提升（0.661 对 0.570），验证了空间接地有效"激活"了 8B 模型的推理潜能。

值得注意的是，尽管 EditReward 取得了有竞争力的总分，其判别式形式存在一个关键局限：人工标注仅关注指令遵循，完全忽略了源一致性建模。因此 EditReward-Bench 无法评估其一致性维度（表 1 中标为"–"）。这一结构性缺陷导致其在下游 RL 应用中的明显短板——缺乏一致性约束会引起严重的内容漂移与过度修改（见图 5）。相比之下，SpatialReward 的显式一致性建模（0.672）保证了均衡的优化。在 MMRB2 上，SpatialReward 尽管未经专门训练，仍在多图（Multi-Image）子集上表现出色（0.608），展现了强跨图像泛化能力。

**MER-Bench 上的性能**。如表 1（右）所示，SpatialReward 取得 48.3% 的总体准确率，大幅超越 EditScore-8B 基线（35.0%），并与 Gemini-2.5-Pro（46.2%）接近。更关键的是，本文模型对复杂度表现出更强的韧性：在最具挑战的 4-Pair 设定中，SpatialReward 取得 21.5% 的最高准确率，甚至超过 Gemini-3.0-Flash（19.5%）。这证实显式空间先验能在复杂多约束推理中有效防止"注意力坍缩"。

### 5.3 在线 RL 中的应用

**基线对齐**。本文在 GEdit-Bench 与 ImageEdit-Bench 上微调模型，以 GPT-4.1 作为"真值"标准评测器。由于 EditScore 报告的基线分数与 OmniGen2 官方结果（6.42/3.44）略有出入，本文通过官方 API 复现测试以对齐后者作为起点，确保所有报告的增益（$\Delta$）都基于一致且透明的基准。

### 5.4 消融与分析

**空间定位与 RL 的影响**。表 4(I) 把架构设计的贡献与 RL 优化的贡献解耦。严格限定在 SFT 阶段内：加入框预测（Box Only）把基线从 0.743 提升到 0.761，而 Think-with-Box 策略进一步把准确率提升到 0.778。这证实：以交错空间锚点驱动主动"思考"，比单纯的检测更有效。在此推理能力之上施加在线 RL 得到最佳性能（0.803），表明 RL 对于把模型分布微调至匹配人类偏好至关重要。

**奖励聚合策略**。评估结果汇总于表 4(II)。（1）**算术平均**简单地对所有子指标取平均，无法捕捉视觉错误的非线性"一票否决"（deal-breaker）特性。（2）**木桶原理（取最小值）**取各维度内最小值的几何平均（$R=\sqrt{\min(S_{SC})\cdot\min(S_{PQ})}$），与 VIEScore（Ku et al., 2024）一致；虽然能惩罚"最短板"，却造成稀疏梯度。（3）**加权几何平均（本文）**提供密集而敏感的信号。

## 6 结论

本文识别并弥合了图像编辑评估中的感知鸿沟——一个导致"注意力坍缩"与评估失准的关键瓶颈。本文提出 SpatialReward，引入显式空间推理实现细粒度验证；构建了空间先验引导的数据流水线，并提出 MER-Bench 以复杂多约束场景挑战模型。实验表明，SpatialReward 达到与人类偏好的最先进对齐，并为在线 RL 提供稳健信号。这些发现证实：**显式空间推理是实现可靠自主图像编辑的关键**。

5. **超参数网格搜索（附录 B.1.3）**：在 2,000 条不相交验证集上以 0.05 步长搜索 $\alpha\in[0.60,0.95]$ 与源一致性权重 $w_{SC}^{(0)}\in[0.40,0.75]$（$w_{PQ}$ 固定 $\{0.5,0.5\}$，$w_{SC}^{(1)}=1-w_{SC}^{(0)}$ 为指令遵循权重）；峰值准确率 **0.736** 出现在 $\alpha=0.80$、$w_{SC}^{(0)}=0.60$——SC 对最终分数贡献更大，但源一致性上的显著权重对稳健评估至关重要。
6. **生成策略训练配置（附录 B.2.1）**：OmniGen2 + Flow-GRPO，LoRA（rank 32，alpha 64）、学习率 4e-4、全局批大小 576、32×GPU（4 节点）；SpatialReward 以 vLLM 部署于独立 8×GPU 节点保障低延迟反馈；采样组 $G=12$、采样步 $T=20$、KL 惩罚权重 $\beta=0.04$、优势裁剪范围 5.0；共训练 1,000 步，发现超过某一点会出现奖励作弊，最终选择 800 步 checkpoint。
7. **聚合策略下游消融（附录 B.2.2，图 11）**：Min 聚合（木桶原理）初期奖励上升快但"早饱和"（VIEScore=7.12）；SpatialReward 的加权聚合提供持续细粒度反馈，实现持续改进（VIEScore=7.32）。
8. **奖励延迟分析（附录 B.2.3，表 7）**：在 8×GPU、批 576 上，SpatialReward 达 72.7 ms/图（批延迟 41.85 s、吞吐 13.8 img/s），较 EditReward（110.5 ms/图、61.89 s、9.3 img/s）**提速 1.5×**；这一反直觉的结果源于系统级优化——作为生成式 VLM，SpatialReward 可无缝接入 vLLM（Kwon et al., 2023）与 PagedAttention，且 Flow-GRPO 中同组（$G=12$）样本共享相同系统提示与指令上下文，支持大规模前缀缓存与连续批处理。
9. **注意力图方法与指标定义（附录 C.1）**：聚合 VLM 主干最后 5 层 transformer 的注意力，提取生成推理 token（query）到图像 token（key）的跨模态注意力（深层承载高度语义化信息），跨层跨头平均后归一化到 $24\times24$ 网格；形式化定义：熵 $H(A)=-\sum_{i,j}A_{ij}\log A_{ij}$、熵差 $|\Delta H|=|H(A_{src})-H(A_{edit})|$、集中度（top-10% token 的累计概率质量）、稳定性（不同样本展平注意力图间的平均 Pearson 相关）。
10. **注意力定性案例（附录 C.1，图 12）**：EditScore 缺乏显式空间接地，注意力分散且产生幻觉（如把未受影响区域的过度编辑视为合理）；SpatialReward 凭"Think-with-Box"显式定位目标物体，保持聚焦而平衡的注意力分布，实现对编辑输入的精确感知与评估。
11. **在线 RL 定性结果（附录 C.2，图 13–15）**：覆盖物体添加、属性修改与风格迁移等编辑类型；未对齐策略、EditReward 引导策略与 SpatialReward 引导策略的对比显示后者在忠实执行编辑的同时保留源语境。
12. **提示模板（附录 D）**：给出完整系统提示——推理阶段（SC/PQ 评分，输出 JSON 含 `edit_region` + `reasoning` + `score`，坐标归一化到 [0,1000]，0–25 打分制）；数据构建（定位、通用/人像域推理生成、一致性检查与 token 交错插注——要求全文恰好一个 `<|global|>` token、每个 edit_region 对应一个 `<|bbox_id|>` token、缺失区域需补一句极简描述）；MER-Bench 指令合成（通用域/人像域，含图像可编辑性判断与可编辑区域标注）；以及 RL 阶段 Oracle 验证提示（SC/PQ 各一套，输出 0–1 一致性/质量分：无问题给 1、轻微问题 −0.5、严重问题 0）。

## 创新点提炼

1. **首次识别并以定量证据诊断 MLLM 评测器的"注意力坍缩"感知鸿沟**。论文指出：缺乏空间锚定时，评测模型的注意力会坍缩进盲目沉没状态，源图"不可见"，跨图像比较退化为单图评估；并在 776 个样本上用熵差（3.48→1.16）、源图熵（2.88→5.71）、集中度（0.84→0.37）、稳定性（0.04→0.12）四项指标给出可测量的定量证据，把一个现象学观察变成可诊断、可优化的对象。

2. **Think-with-Boxes 双流架构：显式空间推理 + 交错 token 锚定**。SC 流按"定位→锚定验证→评分"三步，先预测编辑区域边界框，再以 `<|bbox_id|>`（触发像素回看）与 `<|global|>`（强制上下文扫描）token 锚定文本推理；PQ 流做输入隔离（只看编辑图）实现感知解耦。这是首个把显式空间推理融入图像编辑生成式逐点评估的框架，使 8B 模型在 EditReward-Bench / MMRB2 上分别提升 +11.3% / +9.1%。

3. **空间先验引导的 260k 数据流水线与类别专属专家路由**。三步流水线：Qwen-3-VL-235B 生成边界框空间先验 → 按领域路由专家（人像编辑交 Gemini-2.5-Pro 配裁剪聚焦提示，通用编辑交 GPT-5 配边界框叠加）生成推理与分数 → 回传 Qwen-3-VL 做格式统一与幻觉校验（与视觉证据矛盾即丢弃）。数据由精炼 EditScore（100k）+ 再利用 EditReward（100k）+ 自建 Multi-Edit（60k）三源构成，兼顾空间精度与领域专业性。

4. **SFT→GRPO 渐进式两阶段训练与在线 Oracle 一致性 RL**。先以结构化序列 $(B,\mathcal{T},\mathbf{s})$ 做 SFT 建立空间推理能力，再从 7k 困难样本上以 Gemini-3.0-Flash 的 0~1 一致性分为奖励做 GRPO，惩罚无依据推理、抑制幻觉（消融显示 RL 在 Think-with-Box 之上再贡献 0.778→0.803 的提升）。

5. **加权几何平均的层级奖励聚合**。$R_{final}=(S_{SC})^{\alpha}\cdot(S_{PQ})^{1-\alpha}$（$\alpha=0.80$、$w_{SC}=\{0.6,0.4\}$、$w_{PQ}=\{0.5,0.5\}$，由 2k 验证集网格搜索确定）：维度内加权和保留密集信号，几何平均强罚不均衡质量。相比木桶原理（梯度稀疏、早饱和于 7.12）与算术平均（无法刻画视觉错误的"一票否决"性），在线 RL 奖励曲线持续爬升至更高峰值（7.32）。

6. **MER-Bench 基准与"生成式奖励更快"的系统级发现**。MER-Bench 以 15 个子任务、11 个生成系统、2–5 步复合指令、600 评估组/1,800 样本的 2/3/4-Pair 分层排序设计，专测细粒度区分力（4-Pair 上 SpatialReward 21.5% 超越 Gemini-3.0-Flash 的 19.5%）；同时论文证明生成式奖励模型借助 vLLM 前缀缓存反而比判别式 EditReward 快 1.5×（72.7 对 110.5 ms/图），并以 +0.90 的 GEdit-Bench 增益（约为 GPT-4.1 监督的两倍）验证了显式空间感知奖励在在线 RL 中的实用价值。
