本文在两个可控的规则推理任务（自建的算术卡牌游戏 GeneralPoints 与真实世界导航环境 V-IRL，均含纯文本与视觉-语言两种模态、规则与视觉两类分布偏移）上以等计算量对比 SFT 与 RL：基于结果奖励的多轮 RL 能将同分布（in-distribution, ID）收益迁移到未见规则与未见视觉分布，而 SFT 倾向于记忆训练数据、在分布外（out-of-distribution, OOD）持续退化；同时 SFT 仍是 RL 的必要前置——它稳定输出格式，使后续 RL 得以奏效。

## 摘要

监督微调（Supervised Fine-Tuning, SFT）与强化学习（Reinforcement Learning, RL）是基础模型广泛使用的后训练（post-training）技术。然而，它们在增强模型于基于规则的推理任务上的泛化能力方面各自扮演何种角色，仍不清楚。本文研究 SFT 与 RL 对泛化与记忆化（memorization）的比较效应，聚焦于基于文本的与基于视觉的推理任务。我们提出了 GeneralPoints——一个算术推理卡牌游戏，并同时采用 V-IRL——一个真实世界导航环境，以评估经 SFT 与 RL 训练的模型如何泛化到新颖文本规则与视觉域这两类未见变体上。我们表明：RL，尤其是以基于结果的奖励（outcome-based reward）训练时，在基于规则的文本环境与视觉环境中均能泛化；相比之下，SFT 倾向于记忆训练数据，在两种场景下都难以实现分布外泛化。进一步的分析揭示，RL 改进了模型底层的视觉识别能力，这促成了其在视觉域中泛化能力的提升。尽管 RL 的泛化能力更优，我们仍表明 SFT 对有效的 RL 训练是有帮助的：SFT 稳定了模型的输出格式，使后续 RL 能够取得其性能增益。这些发现展示了 RL 在复杂多模态任务中习得可泛化知识的优势。

## 1 引言

尽管 SFT 与 RL 都被广泛用于基础模型训练（OpenAI, 2023b; Google, 2023; Jaech et al., 2024; DeepSeekAI et al., 2025），它们对泛化（generalization）（Bousquet & Elisseeff, 2000; Zhang et al., 2021）各自产生的不同影响仍不清楚，这使得构建可靠、鲁棒的 AI 系统颇具挑战。分析基础模型（Bommasani et al., 2021; Brown et al., 2020）可泛化性的一个关键挑战，在于将**数据记忆化**与**可迁移原理的习得**区分开来。本文对"记忆化"的定义是：模型基于训练数据集中存在的信息、在提示下生成与训练样本近乎完全一致副本的能力；该定义明确排除了模型内部对训练数据的逐位或逐代码复制（Allen-Zhu & Li, 2023a; Ye et al., 2024; Kang et al., 2024）。由此，本文研究核心问题：SFT 与 RL 究竟主要是记忆训练数据，还是学得了能适应新颖任务变体的可泛化规则？

### 1.1 两类泛化与两个任务

为回答上述问题，本文聚焦泛化的两个方面：**文本规则泛化**（textual rule-based generalization）与**视觉泛化**（visual generalization）。对文本规则而言，本文研究模型将学得的规则（以文本指令给出）应用于这些规则之变体的能力（Zhu et al., 2023; Yao et al., 2024; Ye et al., 2024）；对视觉-语言模型（Vision-Language Model, VLM）而言，视觉泛化衡量在给定任务内、性能随视觉输入变化（如颜色与空间布局）的一致性。

- **GeneralPoints（本文自建）**：一个类似于 RL4VLM 中 Points24 的原创卡牌游戏任务（Zhai et al., 2024a），用于评估模型的算术推理能力。模型接收四张卡牌（以文本描述或图像呈现），并被要求用每张卡牌的数值**恰好一次**地计算出一个目标数（默认为 24）。
- **V-IRL**（Yang et al., 2024a）：一个真实世界导航任务，聚焦模型的空间推理能力。

> **图 1**：在视觉导航环境 V-IRL 上对 RL 与 SFT 的 OOD 泛化比较研究。OOD 曲线表示同一任务、采用不同文本动作空间下的性能。

### 1.2 实验设计与关键发现

本文采用与 Zhai et al. (2024a) 类似的多步 RL 框架：先在主干模型（Dubey et al., 2024）上运行 SFT，再以序贯修正（sequential revision）形式（Snell et al., 2024）实例化 RL。核心实验设计是：在单一规则上分别扩大 SFT 与 RL 的训练计算量，将在已训练规则上的结果视为同分布（ID）性能，在未见规则上的结果衡量分布外（OOD）泛化；再以视觉变体（卡牌颜色、导航城市）构造另一维度的分布偏移。主要发现有四：

1. **RL 泛化，SFT 记忆**：在 GeneralPoints 与 V-IRL 上，RL 学得可泛化的（以文本表达的）规则，其同分布性能增益可迁移到未见规则；SFT 则表现为记忆训练规则、无法泛化。在视觉域中，RL 同样能泛化到视觉 OOD 任务，而 SFT 持续挣扎。
2. **视觉 OOD 的副产品**：得益于视觉 OOD 泛化能力，本文的多轮 RL 方法在 V-IRL mini 基准上取得当时最优（state-of-the-art）结果，提升 +33.8%（44.0%→77.8%）（Yang et al., 2024a）。
3. **RL 提升视觉识别**：对 GeneralPoints 的额外分析表明，以基于结果的奖励函数（Cobbe et al., 2021）训练 RL 会改进视觉识别能力。
4. **SFT 对 RL 的必要性**：尽管 RL 泛化能力优于 SFT，SFT 仍必要——它稳定模型输出格式，使 RL 得以取得其性能增益。此外，扩大推理时计算（增加最大验证步数）能带来更好的泛化。

## 2 相关工作

**后训练（Post-training）**。后训练对增强模型性能至关重要，通常采用大规模 SFT（Radford et al., 2018; Brown et al., 2020; Wei et al., 2022a; Chung et al., 2022; Zhou et al., 2024a 等）和/或 RL（Ziegler et al., 2019; Ouyang et al., 2022; Sun et al., 2024; Abdulhai et al., 2023; Zhou et al., 2024b; Zhai et al., 2024a 等）。SFT 通过在任务专属、常为指令格式的数据集上训练，使预训练模型适配下游任务：FLAN（Wei et al., 2022a）表明在多样指令微调数据集上微调可显著提升未见任务上的零样本性能；LIMA（Zhou et al., 2024a）则表明 SFT 充当"格式教师"（format teacher），在利用预训练 LLM 能力的同时有效将模型响应适配到期望格式。相比之下，RL 主要用于将模型与人类偏好对齐、或训练基础模型求解特定任务。与既有研究不同，本文旨在对 SFT 与 RL 在 LLM 与 VLM 上的泛化与记忆化进行**比较分析**，而先前研究多只聚焦其中一种后训练方法（或只研究 LLM 或 VLM 之一）。

**LLM/VLM 中的记忆化与泛化**。若干研究考察了神经网络中记忆化与泛化的相互作用（Han et al., 2022; Carlini et al., 2022; Yang et al., 2023）。在 LLM 中，记忆化可表现为模型记住训练数据（Carlini et al., 2022; Jiang et al., 2024; Kang et al., 2024），而泛化反映模型输出分布与预训练数据分布的偏离（Zhang et al., 2023）。既有研究表明：LLM 在较简单的知识密集型任务上表现出更多过拟合，而在更复杂的推理密集型任务上泛化更强（Wang et al., 2024; Qi et al., 2024）。例如，近期研究（Ye et al., 2024; Allen-Zhu, 2024; Allen-Zhu & Li, 2023a,b, 2024; Tong et al., 2024b）证明 LLM 通过在自回归生成之前预计算推理图（reasoning graph），发展出超越其训练数据的推理技能集，为泛化提供了有力证据。本文的切入点不同：在文本规则与视觉变体的语境下，研究不同后训练范式对记忆化与泛化的作用，并在单模态（LLM）与多模态（VLM）两种设置下进行比较，证明 RL 比 SFT 带来更好的泛化性能。

**扩大推理时计算（inference-time compute）**。近期研究日益关注通过扩大推理时计算来提升模型性能（Wei et al., 2022b; Yao et al., 2024; Snell et al., 2024; Jaech et al., 2024）。早期工作提示模型先生成中间推理步骤再给出最终答案；后续工作（Zelikman et al., 2022; Feng et al., 2023; Tian et al., 2024; Chen et al., 2024a; Snell et al., 2024）证明在推理时微调验证器（verifier）可提升准确率；近期发现（Jaech et al., 2024; DeepSeekAI et al., 2025）揭示了推理时计算的"缩放定律"。本文在两方面建立于此：其一，将推理时验证的洞见整合进多轮 RL 形式化，使模型能识别并纠正自身错误；其二，考察推理时验证对 RL 泛化的影响，证明扩大推理时验证（以最大验证步数计）是 RL 泛化的关键。

**提升 VLM 的视觉能力**。VLM 虽在众多挑战性任务上表现出色（Lu et al., 2023; Yue et al., 2024a,b; Yang et al., 2024a,b），但在视觉感知上存在局限（Zhai et al., 2024a,b; Tong et al., 2024c,d; Rahmanzadehgervi et al., 2024）。既有努力包括：组合多个视觉编码器、策划高质量 SFT 数据、以及通过解冻视觉主干改进 SFT 训练配方（Liu et al., 2023; Tong et al., 2024a,d; Kar et al., 2025; Chen et al., 2023; Liu et al., 2024）。这些工作主要聚焦 SFT 阶段的实验，而本文证明 **RL 也能改进视觉感知**。

## 3 预备知识

**标准 RL 术语**。考虑有限时域（finite horizon）决策，采用经典 RL 文献的标准记号（Sutton & Barto, 2018; Agarwal et al., 2019）：$\mathcal{S}$ 为状态空间，$\mathcal{A}$ 为动作空间，$r:\mathcal{S}\times\mathcal{A}\rightarrow\mathbb{R}$ 为奖励函数，$T$ 为每个回合（episode）的最大步数。目标是学习策略 ${\pi:\mathcal{S}\rightarrow\mathcal{A}}$，最大化总体回报

$$
{\max_{\pi\in\Pi}\mathbb{E}_{\pi}\left[\sum_{t=0}^{T}r_{t}\right]}, \tag{1}
$$

其中 $r_{t}$ 表示 $r(s_{t},a_{t})$；$\pi(a|s)\in[0,1]$ 表示策略在状态 $s$ 下选择动作 $a$ 的概率。

**面向带验证器的 LLM/VLM 的 RL 术语适配**。本文采用面向基础模型训练的多轮 RL 设置（Zhai et al., 2024a）。令 $\mathcal{V}$ 为离散有限的词表（token）空间，输入、输出文本空间分别为 $\mathcal{V}^{m}$ 与 $\mathcal{V}^{n}$（$m$、$n$ 为输入序列 $\mathbf{v}^{\text{in}}$ 与输出序列 $\mathbf{v}^{\text{out}}$ 的最大 token 长度）。对需要视觉输入的模型（VLM），定义 $\mathcal{O}$ 为所有 RGB 图像的空间；状态空间定义为 VLM 时 $\mathcal{S}:=\mathcal{V}^{m}\times\mathcal{O}$、LLM 时 $\mathcal{S}:=\mathcal{V}^{m}$；动作空间 $\mathcal{A}:=\mathcal{V}^{n}$。用 $\mathsf{VER}:\mathcal{V}^{n}\rightarrow\mathbb{R}\times\mathcal{V}^{k}$ 表示**验证器**（verifier）：它评估输出 $\mathbf{v}^{\text{out}}$ 的结果，并生成基于结果的奖励函数（Cobbe et al., 2021; Hosseini et al., 2024; Snell et al., 2024; Setlur et al., 2024）$r$ 与文本信息 $\mathbf{v}^{\text{ver}}$，即时刻 $t$ 处 $\mathsf{VER}(\mathbf{v}^{\text{out}}_{t})\mapsto(r_{t},\mathbf{v}^{\text{ver}}_{t})$。与 Zhai et al. (2024a) 类似，将参数为 $\theta$ 的模型视为策略网络 $\pi_{\theta}:\mathcal{S}\rightarrow\mathcal{V}^{n}$，并采用 PPO（Schulman et al., 2017）作为骨干 RL 算法更新 $\pi_{\theta}$。

**序贯修正（Sequential Revision）**。为建模状态-动作转移，本文采用序贯修正形式化（Snell et al., 2024）：$t=0$ 时初始输入 $\mathbf{v}^{\text{in}}_{0}$ 由系统提示（system prompt）组成；$t\geq 1$ 时，输入提示由系统提示与此前所有模型输出、验证器输出拼接而成：

$$
\mathbf{v}^{\text{in}}_{t}=\text{concat}\left(\mathbf{v}^{\text{in}}_{0},[\mathbf{v}^{\text{out}}_{k},\mathbf{v}^{\text{ver}}_{k}]_{k=0}^{t-1}\right). \tag{2}
$$

> **图 2**：带验证器的序贯修正形式化示例。模型以验证器给出的全部历史答案与信息 $(\mathbf{v}^{\text{out}}_{i},\mathbf{v}^{\text{ver}}_{t},0\leq i\leq t)$ 为条件，生成下一个答案 $\mathbf{v}^{\text{out}}_{t+1}$。

> **图 3**：构造 $\mathbf{v}^{\text{in}}_{t+1}$ 的提示更新模板。棕色部分标记任务及相关信息，紫色部分表示状态（$s_{t}$）专属信息，蓝色与红色分别描述模型与验证器的输出。

## 4 评估任务

为评估不同后训练方法的泛化能力，本文选择两个各自提供规则变体与视觉变体的任务：GeneralPoints（第 4.1 节，评估算术推理）与 V-IRL（第 4.2 节，考察开放世界视觉导航域中的推理能力）。

### 4.1 GeneralPoints 环境

GeneralPoints 在 Points24 环境（Zhai et al., 2024a）之上实例化，用于评估算术推理的泛化。每个状态 $s$ 包含 4 张卡牌：以文本描述（GP-L 变体）或以图像呈现（GP-VL 变体）。目标是产出一条等于目标数（默认 24）的等式，且 4 个卡牌数字须各用**恰好一次**。当输入以图像呈现（GP-VL）时，任务天然引入额外视觉挑战——VLM 须先识别全部卡牌、再求解等式。

**规则变体（rule variations）**。为研究模型究竟习得了算术运算、还是仅仅记忆了后训练数据，本文引入规则变体：将符号 'J'、'Q'、'K' 或全部解释为 '10'，或分别解释为 '11'、'12'、'13'。每条规则以文本形式在输入提示中指定（见图 3 的 {tasks rules} 部分）。研究规则泛化时，用一条规则后训练模型，再用另一条规则评估。

**视觉变体（visual variations）**。由于主要视觉挑战是识别每张卡牌的数字（与卡牌颜色无关），本文将不同颜色的卡牌视为任务的视觉变体：用一种颜色训练，用另一种颜色测试 OOD 性能。

### 4.2 V-IRL 环境

V-IRL（Yang et al., 2024a）用于研究开放世界导航域中的空间推理能力，采用真实感视觉输入。与 GeneralPoints 一致，考虑两个版本：纯语言描述版（V-IRL-L，视觉输入可解析为纯文本描述）与视觉-语言输入版（V-IRL-VL）。V-IRL 的主要视觉挑战在于**在采取动作前从视觉观测中识别不同地标**（如 The Dutch、Lola Taverna、Shuka），并将这些地标与文本指令关联以采取正确动作。目标是遵循一组含空间信息的指令导航到目标地点。

**规则变体**。为评估模型是否具备空间知识、还是仅仅记忆了后训练数据，考虑两种动作空间（action space）配置：其一是**绝对方位**动作空间 {'north', 'northeast', 'east', 'southeast', 'south', 'southwest', 'west', 'northwest'}；其二是**相对方位**动作空间 {'left', 'right', 'slightly left', 'slightly right'}，后者分别将当前朝向调整 90 度或 45 度。

> **图 4**：V-IRL 中一个导航任务的演示。智能体遵循给定语言导航指令在地点之间移动。上方为导航过程，下方为导航指令；绿色高亮为视觉观测相关信息，橙色为动作相关信息。

**视觉变体**。由于 V-IRL 包含来自不同城市的视觉观测，可通过在一个地点训练、再在不同地点评估来考察视觉泛化。

## 5 实验结果

本文采用 Llama-3.2-Vision-11B（Dubey et al., 2024）作为主干模型，遵循 RLHF（Ouyang et al., 2022）与 RL4VLM（Zhai et al., 2024a）的标准流程，先以 SFT 初始化模型、再运行 RL。实验围绕五个问题展开：5.1 SFT 或 RL 如何影响模型对不同规则的泛化？5.2 当模型含视觉组件时，RL/SFT 如何影响其对不同视觉变体的泛化？5.3 RL/SFT 如何影响 VLM 的视觉识别能力？5.4 SFT 在 RL 训练中扮演什么角色？5.5 验证迭代次数如何影响泛化？

> **图 6**：规则变体下分布外性能比较。GeneralPoints 报告成功率，V-IRL 报告逐步准确率。每幅子图中 RL 与 SFT 以等计算量训练，其共享初始检查点（标记为 Init）作为基线。

### 5.1 规则泛化：RL 泛化，SFT 记忆

对每个任务，在单一规则上分别扩大 RL 与 SFT 的训练计算量：GeneralPoints 的 ID 情形将 'J'、'Q'、'K' 全部视为 10，OOD 情形将其解释为 11、12、13；V-IRL 的 ID 情形采用绝对方位坐标系，OOD 情形使用相对方位动作空间。

如图 5 所示，**RL 在所有任务（含单模态 LLM 与多模态 VLM）上一致地提升 OOD 性能**。具体而言（图 6），RL 在 GP-L 上取得 +3.5% 提升（11.5% → 15.0%）、在 V-IRL-L 上 +11.0%（80.8% → 91.8%）；即便 VLM 上叠加了视觉识别的额外挑战，RL 仍保持一致的增益：GP-VL +3.0%（11.2% → 14.2%）、V-IRL-VL +9.3%（35.7% → 45.0%）。与之相反，**SFT 在所有任务的全部 OOD 评估中都出现性能退化**：GP-L −8.1%（11.5% → 3.4%）、V-IRL-L −79.5%（80.8% → 1.3%）、GP-VL −5.6%（11.2% → 5.6%）、V-IRL-VL −33.2%（35.7% → 2.5%）。

### 5.2 视觉分布外任务中的泛化

在规则变体之外，本文进一步研究视觉变体对 OOD 泛化的影响（规则保持一致）：GeneralPoints 上用黑色花色（♠、♣）训练 VLM、在红色花色（♥、♠）上测试（译注：原文如此，按花色语义此处应为红色花色 ♥、♦，♠ 为黑色黑桃，疑为原文笔误）；V-IRL 上用纽约市采集的路线训练、在包含全球各城市路线的原始 V-IRL VLN mini 基准（Yang et al., 2024a）上评估。

> **图 7**：视觉变体下分布外性能比较。与图 5、图 6 类似，同时给出性能动态（线）与最终性能（柱）。V-IRL VLN mini 基准上此前最优结果（Yang et al., 2024a）以橙色标出。

**RL 在视觉 OOD 任务中泛化**。如图 7 所示，RL 在视觉 OOD 任务中仍然泛化，而 SFT 持续受限：GP-VL 与 V-IRL-VL 上，RL 分别取得 +17.6%（23.6% → 41.2%）与 +61.1%（16.7% → 77.8%）的性能提升；SFT 则分别退化 −9.9%（23.6% → 13.7%）与 −5.6%（16.7% → 11.1%）。作为这一视觉 OOD 研究的副产品，本文的多轮 RL 形式化将 V-IRL mini 基准上的最优结果（Yang et al., 2024a 中表 5）提升 +33.8%（44.0% → 77.8%）。值得注意的是，此前 V-IRL 报告的最优方法依赖两阶段 VLM-LLM 协作技术并在闭源模型上定制提示工程（OpenAI, 2023a），而本文的端到端 RL 方法使开源模型（Dubey et al., 2024）达到了更优性能。

### 5.3 RL 改进视觉能力

基于"RL 训练的 VLM 能泛化到视觉 OOD 任务"这一观察（5.2 节），自然引出后续问题：RL 如何影响 VLM 的视觉能力？为此，本文在 GP-VL 环境中进行了额外消融研究，同时考察 RL 与 SFT 的 OOD 性能以及模型的视觉识别准确率（即从输入图像中识别 4 张卡牌的准确率），研究扩大后训练计算量如何同时影响规则 OOD 泛化（图 8 左）与视觉识别准确率及视觉 OOD（图 8 右）。

> **图 8**：GP-VL 中不同变体下 RL 与 SFT 的识别率 vs. 成功率。报告识别率（y 轴）与回合成功率（x 轴）的同分布（红色）与 OOD（蓝色）性能；以透明度（色条）表示每个数据点的训练计算量，相连的（⋆-∘）点对使用相同检查点评估。随着后训练计算量扩大，RL 同时改进识别率与总体准确率，SFT 则呈相反效应。

**扩大 RL 提升视觉识别准确率**。如图 8 所示，VLM 的视觉识别准确率在很大程度上影响总体性能（Zhong et al., 2024 亦有类似观察）。此外，扩大 RL 计算量也会提升视觉识别准确率——这是其泛化能力的副产品；而扩大 SFT 则同时恶化视觉识别准确率与总体性能。更多实验结果见附录 D.1 的图 16 与图 17。

### 5.4 SFT 对 RL 训练的作用

尽管 RL 在泛化模型推理与视觉能力方面优于 SFT，实验流程仍是在 SFT 之后实例化 RL。本小节聚焦另一个关键问题：**SFT 对 RL 训练是否必要？**为此，本文在纯语言 GeneralPoints（GP-L）上直接对基座模型 Llama-3.2 施加端到端 RL 的额外实验（图 9）。

> **图 9**：无 SFT 初始化时 GP-L 上的 RL 实验。所有试验均因基座模型糟糕的指令遵循能力而失败。

**当主干模型不遵循指令时，SFT 对 RL 训练是必要的**。图 9 表明，没有 SFT 时所有端到端 RL 运行都无法提升。具体而言，无 SFT 时基座模型受糟糕的指令遵循能力所困：基座 Llama-3.2-Vision-11B 倾向于生成冗长、离题且非结构化的响应（详细失败案例见附录 D.3 图 20），使得无法为 RL 训练检索任务相关信息与奖励。需要注意的是，由于主干模型不同，该结果与 DeepSeekAI et al. (2025)（其认为 SFT 对下游 RL 训练并非必要）并不矛盾。

验证是多步训练与评估流程中的另一个关键组件（见图 2 与图 3）。为验证其必要性并更好地理解其效果，本文在 GP-L 上以不同验证迭代次数 {1, 3, 5, 10} 进行 RL 实验（图 10）。

> **图 10**：GP-L 上同分布 vs. OOD 性能的增长。记录不同验证迭代次数（VIter）的 RL 实验随训练计算量扩大（颜色透明度）的表现。

**扩大验证规模提升泛化**。图 10 表明，验证步数越多，RL 泛化越好。具体而言，在所有实验的相同计算预算下，观察到 OOD 性能提升 +2.15%（3 步）、+2.99%（5 步）、+5.99%（10 步）；相比之下，仅一步验证的情形只有 +0.48% 的边际提升。

## 6 结论、讨论与局限

本文对基础模型后训练技术（尤其是 RL 与 SFT）的泛化效应进行了全面分析。通过在 GeneralPoints 与 V-IRL 任务上的大量实验，本文证明：在规则与视觉两类变体上，RL 在学习可泛化知识方面表现更优，而 SFT 倾向于仅仅记忆训练数据；这一现象在多模态算术与空间推理能力上一致出现。此外，本文还研究了 RL 对视觉识别的影响、SFT 的角色以及验证步数的作用。研究期间，尚有两个挑战未获解决：

**SFT 在 GP-VL 上的失败**。图 5 的 GP-VL 子图中，SFT 无法达到与 RL 相当的同分布性能。为排除超参数选择带来的方差，本文额外以不同学习率与可调组件进行了 10 组以上实验（图 16），无一呈现如 RL 般的强劲上升趋势（图 17）。结合"扩大 SFT 会退化视觉识别能力"（图 8）的观察，本文猜想 SFT 局部地过拟合于推理 token、而忽视了识别 token，原因可能是推理 token 出现频率更高（示例见图 11）。进一步研究留待未来工作。

**RL 在极端情形下的局限**。如 5.4 节所述，SFT 对 Llama-3.2 上的有效 RL 训练是必要的。本文进而考察将 RL 应用于一个过度调优（overly-tuned）的 SFT 检查点：如图 19 所示，从此类检查点出发时 RL 无法恢复分布外性能；失败示例见图 21，模型坍缩回训练规则。这些结果与 5.4 节的发现共同表明：当初始检查点极端欠拟合或过拟合时，RL 的效果有限。SFT 在何种条件下促进有效 RL，仍需进一步研究划定。

**影响声明**：本研究限于受控研究环境——GeneralPoints 为合成环境，V-IRL 为真实世界地图模拟器，未涉及真实系统的部署或交互，未引入可预见的社会或伦理影响。

## 附录要点

1. **GeneralPoints 数据**（附录 A.1）：卡牌四元组从一副 52 张标准扑克牌中采样，且经专家求解器保证每个采样四元组至少存在一个等于目标点 24 的解。
2. **GeneralPoints 可配置参数**（附录 A.3）：目标点（任意正整数，实验固定为 24）；人头牌规则（'J'/'Q'/'K' 全作 10，或分别作 11/12/13）；卡牌采样（从 52 张中无放回抽 4 张，或强制至少含一张人头牌）；卡牌颜色（仅黑色花色 ♣♠ / 仅红色花色 / 全部花色）。图 5 的训练与域内评估使用"全作 10"规则；域外评估使用替代规则并强制至少一张人头牌，迫使模型在训练中未曾遇到的大于 10 的数字上进行计算；视觉偏移实验用黑色花色训练、红色花色评估。
3. **GeneralPoints 奖励设计**（附录 A.3）：回合在生成正确等式或达到最大验证步数（原文记为 55，结合 5.5 节验证迭代上限 {1,3,5,10}，疑为 5 的排版重复——译注）时终止。r=5 对应生成等于目标点的合法等式；r=−1 对应每卡恰好一次但不等于目标点、或超出最大验证步数；r=−2 对应合法等式中含非给定卡牌的数字；r=−3 对应其他所有非法等式；GP-VL 中识别卡牌错误额外施加 r=−1.5 惩罚。
4. **V-IRL 数据**（附录 B.1）：借助 Yang et al. (2024a) 的数据采集流程，构建了纽约市 1000 条独有路线的训练库；规则变体与视觉域内实验从该库随机采样路线评估；视觉 OOD 实验直接采用 VLN mini 基准——18 条独有路线、覆盖米兰、新德里、布宜诺斯艾利斯、伦敦、香港、纽约（与训练数据不重叠）、墨尔本、拉各斯、旧金山九城，每城 2 条。
5. **V-IRL 环境简化**（附录 B.3）：去除了需要单独视觉检测器处理街景的两阶段导航流程与在线查询，以降低训练时间与成本；新增两个配置参数——动作空间（绝对/相对方位，对应规则变体）与最大直路长度（限制转弯点间可移动坐标数、避免连续重复的 "forward()"）。奖励设计：r=1 对应当前坐标处动作正确；r=−1 对应动作错误或超出最大验证步数（2）；r=−1.5 对应地标检测失败。
6. **SFT 数据与次优轨迹消融**（附录 C.1）：训练样本由每个系统提示与对应专家响应配对构成，主实验中的全部 SFT 均使用最优单轮提示-响应对（无验证与修正步骤）。在 GP-L 上用含错误与验证消息的次优轨迹训练 SFT 的消融（图 15）表明：即便增加轨迹多样性，SFT 仍只是记忆训练数据、OOD 性能退化——说明记忆化源于 SFT 训练的根本性质，而非 SFT 数据本身。
7. **训练与评估设置**（附录 C.2–C.3）：遵循 RL4VLM 流程，先 SFT 初始化、再从该初始化模型分别扩大 SFT 与 RL 的计算量；每项实验以共享学习率调节全部组件；所有训练在 8 卡 H800（80GB）机器上完成。评估指标：V-IRL-VL 报告逐步准确率（中间验证步计为独立样本）；GP-L/GP-VL/V-IRL-L/V-IRL-VL 报告成功率——GeneralPoints 上推理时验证中至少成功一次即算成功，V-IRL 上须在路线每个可移动点都采取正确动作。训练计算量按 $X_{\text{SFT}}=6N(D_{\text{init}}+D_{\text{SFT}})$、$X_{\text{RL}}=6N(D_{\text{init}}+D_{\text{RL}})+2ND_{\text{buffer}}$ 估计，其中 $D_{\text{buffer}}\approx\lambda D_{\text{RL}}$（PPO 含回放缓存收集与优化的迭代阶段，需额外推理计算），GeneralPoints 与 V-IRL 的 $\lambda$ 经计算分别约为 6 与 5.1。所有折线图采用 3 阶多项式 Savitzky–Golay 滤波平滑；假设每个评估点服从二项分布，标准误按 $\sqrt{P(1-P)/N}$ 近似。
8. **GP-VL 消融**（附录 D.1）：全参数微调搜索学习率 {1×10⁻⁴, 1×10⁻⁴, 1×10⁻⁵, 1×10⁻⁶, 5×10⁻⁷, 1×10⁻⁷}（译注：原文如此，首个 1×10⁻⁴ 疑应为 1×10⁻³）；冻结视觉编码器时搜索 {1×10⁻⁶, 1×10⁻⁷}；再冻结适配器时搜索 {1×10⁻⁶, 5×10⁻⁷, 1×10⁻⁷}。没有任何实验的同分布成功率超过 30% 或呈上升趋势；而 RL 只需在 {2×10⁻⁶, 1×10⁻⁶} 中搜索、全部组件可调，寻找合适超参数的工作量极小。
9. **V-IRL-VL 总体成功率**（附录 D.2）：受任务复杂度所限，两种训练方法的总体成功率均不高于 1%——该指标聚合逐步误差，要求远高于逐步准确率（例如逐步准确率 10% 的随机策略在平均 10 步的路线上总体成功率仅约 10⁻⁸%）。
10. **失败案例**（附录 D.3）：无 SFT 初始化时（图 20），Llama-3.2-Vision-11B 无法正确遵循指令，转而生成试图用 Python 暴力枚举求解的长响应且无法在有限上下文内完成；从过度拟合检查点出发时（图 21），在相对方位规则下模型输出训练时绝对方位动作空间的 "turn_direction(northwest)" 而失败——此类失败随 SFT 规模扩大而更频繁出现。

## 创新点提炼

1. **首次以等计算量对 SFT 与 RL 的"记忆 vs 泛化"做系统性受控比较**。在规则变体与视觉变体两个正交的分布偏移维度、纯语言与视觉-语言两种模态上，本文证明了同一结论：RL 将同分布收益迁移到未见规则与未见视觉分布，而 SFT 一致地退化（最极端者 V-IRL-L 上 SFT 使 OOD 性能从 80.8% 崩落至 1.3%）。这为"SFT 学格式、RL 学知识"的分工提供了最直接的实验证据。

2. **GeneralPoints：一个可精确控制规则与视觉分布偏移的算术推理环境**。在 Points24 之上引入人头牌取值规则（全作 10 vs 分别作 11/12/13）与卡牌颜色两类可控变体，使"泛化"可被操作化为"在以文本声明的不同规则、不同视觉外观下保持性能"，且天然支持 LLM（GP-L）与 VLM（GP-VL）两种设置的比较，为后训练研究提供了一个干净的测试床。

3. **发现 RL 能改进 VLM 底层视觉识别能力**。通过在同一检查点上同时度量卡牌识别率与任务成功率（图 8），本文揭示：扩大 RL 计算量在提升泛化的同时**提升**视觉识别准确率，而扩大 SFT 则**同时恶化**识别与总体性能——据此提出"SFT 局部过拟合于高频推理 token、忽视识别 token"的机理假设，将后训练范式与视觉感知能力直接关联。

4. **澄清 SFT 与 RL 的互补分工：SFT 稳定格式、RL 贡献增益**。无 SFT 的端到端 RL 因基座模型指令遵循能力差而全部失败（生成冗长离题的非结构化输出，无法解析奖励），而过度调优的 SFT 检查点又令 RL 无法恢复 OOD 性能（模型坍缩回训练规则）——由此划定 RL 有效的边界条件：既非可从任意基座冷启动，也非能挽救过拟合起点。

5. **多轮"序贯修正 + 验证器"RL 范式及其推理时缩放效应**。将推理时验证整合为多轮 RL 形式化，使模型能识别并修正自身错误；消融显示验证迭代次数是泛化的关键杠杆——相同预算下 10 步验证带来 +5.99% 的 OOD 提升而 1 步仅 +0.48%。作为副产品，该端到端 RL 使开源模型在 V-IRL mini 基准上达到 77.8%、超过依赖闭源模型两阶段协作的此前最优 33.8 个百分点。
