OpenRubrics 通过"**对比量规生成**（Contrastive Rubric Generation）从优选/劣选回答对比中同时提炼**硬性规则**与**原则**两类评价标准，再以**偏好-标签一致性**过滤噪声量规"，构建了大规模多样化的 (提示, 量规) 数据集，据此训练的量规引导奖励模型 Rubric-RM 在八个奖励建模基准上平均超越同规模强基线 8.4%，且收益可迁移至指令遵循与生物医学领域的策略模型优化。

## 摘要

奖励建模（reward modeling）是"基于人类反馈的强化学习"（RLHF）的核心，然而现有大多数奖励模型依赖标量分数或成对判断，无法捕捉人类偏好的多面性。近期研究探索了"**量规即奖励**"（rubrics-as-rewards, RaR），即用结构化准则来刻画回答质量的多个维度。然而，产出既可靠又可扩展的量规仍是一大挑战。本工作提出 **OpenRubrics**——一个多样化、大规模的 (提示, 量规) 对集合，用于训练量规生成模型与基于量规的奖励模型。为引出有区分力且全面的评价信号，本文提出**对比量规生成**（Contrastive Rubric Generation, CRG），通过对比优选（preferred）与劣选（rejected）回答，同时推导出**硬性规则**（hard rules，显式约束）与**原则**（principles，隐式质量）。进一步地，本文通过保持**偏好-标签一致性**（preference–label consistency）剔除噪声量规。在多个奖励建模基准上，本文的基于量规的奖励模型 **Rubric-RM** 超越同规模强基线 8.4%。这些增益还可迁移到指令遵循与生物医学基准上的策略模型。

**关键词**：量规即奖励、奖励建模、LLM 对齐、合成数据

## 1 引言

奖励建模是 RLHF 的核心，被广泛用于使大语言模型（LLM）与人类偏好对齐（Ouyang et al., 2022; Wu et al., 2023; Bhaskar et al., 2025）。通过为每个回答赋予标量分数（Ouyang et al., 2022）或偏好标签（Chen et al., 2025b），奖励建模在训练过程中提供优化信号，引导策略 LLM 生成有用且无害的回答。

尽管大量工作投入到使用**可验证奖励的强化学习**（RLVR）（Guo et al., 2025a; Yue et al., 2025），许多高价值的 LLM 应用——如长篇问答、通用有用性——运作在本质上主观的领域中，其正确性无法被二元信号充分刻画。为弥合这一鸿沟，"**量规即奖励**"（rubrics-as-rewards, RaR）（Gunjal et al., 2025）作为奖励建模的新范式应运而生。量规（rubric）由结构化的自然语言准则构成，将质量分解为可解释、可度量的维度，相比标量判断提供了更一致、更透明的评价框架。对策略模型而言，量规还使优化能够被显式原则所引导。

尽管前景可观，构建高质量量规仍是开放挑战。现有基准（Arora et al., 2025）依靠领域专家费力整编量规，成本高昂且难以扩展。近期工作（Huang et al., 2025; Viswanathan et al., 2025; Gunjal et al., 2025）通常通过直接提示 LLM 生成量规，但这些方法对量规的质量控制有限，且依赖商业 API 时成本可能高得惊人。

本工作提出 **OpenRubrics**——一个大规模 (提示, 量规) 对集合，以促进量规生成模型的训练。具体而言，本文提示 LLM 生成两类互补的量规：**硬性规则**（hard rules），捕捉提示中显式陈述的客观约束；以及**原则**（principles），概括优质回答的隐式、可泛化质量。这一设计使量规既能覆盖表层要求，也能覆盖更深层的质量维度。硬性规则通常易于提取，但原则更微妙、需要细粒度推理。为此，本文提出**对比量规生成**（CRG），其条件输入为用户查询及其配对的优选（chosen）与劣选（rejected）回答。通过利用负向对比（negative contrast），CRG 促使模型识别出区分强弱回答的判别性质量，从而产出更全面、更具排序意识的量规信号。为进一步确保可靠性、降低噪声，本文通过拒绝采样（rejection sampling）施加偏好-标签一致性，只保留能产生正确偏好预测的量规。

**本文贡献有三**：

1. 提出 **OpenRubrics**，一个大规模、多样化的量规集合。该数据集既支持量规生成模型，也支持大规模的量规引导奖励建模。
2. 区分两类基本量规类型，并提出**对比量规生成**策略，训练模型从提示与回答中产出全面且有判别力的量规；此外引入**偏好-标签一致性**机制，提升量规的质量与可靠性。
3. 在八个基准数据集上开展大量实验，Rubric-RM 持续超越强基线 8.4%。而且，将其集成到策略优化后，Rubric-RM 在高难度指令遵循与医学基准上带来显著增益。案例研究进一步验证了"硬性规则 + 原则"组合的收益，表明量规有助于减少过长输出造成的误报（false positives）。

## 2 相关工作

**奖励建模**。标准奖励模型在 Bradley–Terry 框架下通过排序损失为回答赋予标量分数（Bradley and Terry, 1952; Liu et al., 2025a）。为增强推理能力，生成式奖励模型（GenRM）引入合成的思维链（CoT），实现更准确的奖励估计（Ankner et al., 2024; Yu et al., 2025; Zhang et al., 2025b; Liang et al., 2025）。在逐点（pointwise）设定之外，成对（pairwise）奖励模型被提出以直接比较多个回答（Xu et al., 2025a; Liu et al., 2025b）。更近期，强化学习被用来进一步优化奖励模型，使其能对比较显式推理，从而取得更强的对齐性能（Chen et al., 2025a; Chen et al., 2025b; Whitehouse et al., 2025; Guo et al., 2025b）。与这些努力正交，本工作聚焦于用结构化量规提升奖励建模质量：通过引入基于量规的评价信号，为现有方法补充了一层可解释性并带来性能增益。

**量规即奖励**。近期工作探索了量规在评价与对齐两方面的应用：量规可为模型生成内容提供结构化评估（Arora et al., 2025; Hashemi et al., 2024; Pathak et al., 2025; Lin et al., 2025），引导指令遵循与领域适配（Viswanathan et al., 2025; Gunjal et al., 2025），通过基于规则的奖励提升安全性（Mu et al., 2024），并与可验证奖励结合用于推理任务（Huang et al., 2025; Zhou et al., 2025）。然而，多数现有方法依赖提示前沿 LLM 来生成量规，限制了可扩展性与一致性。本工作提出一个更可扩展的**高质量合成量规生成**框架，以更低成本同时改善奖励质量与可解释性。同期工作（Zhang et al., 2025a）也研究量规生成，但聚焦于以**迭代精炼**缓解奖励过度优化；本文则强调可扩展合成与量规-偏好一致性。

## 3 预备知识

> **图 1**：OpenRubrics 中合成量规生成的整体框架。

**量规**。本文将量规定义为针对给定提示量身定制的结构化评价准则集合。形式化地，记 $x$ 为输入提示、$\hat{y}$ 为模型生成的回答。量规 $\mathcal{R}(x)$ 表示为 $k$ 条准则的集合 $\mathcal{R}(x)=\{c_{i}\}_{i=1}^{k}$，其中每条 $c_{i}$ 为一条量规描述，指明回答质量的某个方面（如事实正确性、推理严谨性、风格）。

**基于量规的奖励模型**。在成对奖励建模先前工作（Liu et al., 2025b; Chen et al., 2025b; Guo et al., 2025b; Xu et al., 2025a）的基础上，本文聚焦比较式设定，目标是评估两个候选回答的相对质量。给定提示 $x$ 与两个样本 $(\hat{y}_{1},\hat{y}_{2})$，成对的基于量规的奖励函数定义为

$$
\text{reward}_{\text{pair}}(x,\hat{y}_{1},\hat{y}_{2})=r_{\theta}\big(x,\hat{y}_{1},\hat{y}_{2};\{c_{i}\}_{i=1}^{k}\big),
$$

其中 reward 为二元偏好标签，$r_{\theta}$ 为在产出偏好判断时整合量规准则 $\{c_{i}\}$ 的奖励模型。

OpenRubrics 的整体框架见图 1。总体目标有二：(1) 构建量规数据集 $\mathcal{D}_{\text{rubric}}$，训练一个在给定提示 $x$ 后自动合成量规 $\mathcal{R}(x)$ 的生成模型 $g_{\theta}$；(2) 构建奖励建模数据集 $\mathcal{D}_{\text{rm}}$，训练一个能产出可靠且可解释的成对判断的量规引导奖励模型 $r_{\phi}$。这一两阶段形式化将评估分解为**量规生成**与**量规条件化的奖励预测**，在人类对齐的准则与自动化偏好建模之间架起桥梁。

## 4 OpenRubrics

### 4.1 数据构建

**数据来源**。为生成能跨任务与领域泛化的高质量量规，本文整合了一批公开的偏好与指令微调数据集，兼顾通用领域与领域专属资源。具体来源包括：

- **UltraFeedback**（Cui et al., 2024）：聚合了来自 *Evol-Instruct*（Xu et al., 2024）、*UltraChat*（Ding et al., 2023）、*ShareGPT*（Chiang et al., 2023）与 *TruthfulQA*（Lin et al., 2022）的偏好标注；
- **Magpie**（Xu et al., 2025b）：通过 LLM 自提示（self-prompting）跨多样领域生成的大规模合成对齐数据集；
- **Skywork-Preference**（Liu et al., 2024）：整合了 *HelpSteer2*（Wang et al., 2024）与 *OffsetBias*（Park et al., 2024）的数据；
- **Synthetic-IF**（Lambert et al., 2025a）：面向可验证指令遵循的人类偏好判断集合；
- **MegaScience**（Fan et al., 2025）：覆盖物理、生物、化学等多个科学领域的专门语料；
- **Medical-o1**（Chen et al., 2024）：为诊断推理任务整编的医学 SFT 数据集。

> **图 2**：OpenRubrics 统计概览。(a) 数据分布（按指令数）；(b) 提示与量规的长度分布以及量规条数分布。

**偏好数据构建**。为给量规生成与判断模型训练（见 4.3 节）构建偏好数据，本文对既有偏好与 SFT 数据集做了定制化处理。对 UltraFeedback，选取最高分回答为**优选**（chosen）、最低分为**劣选**（rejected）。对 MegaScience 与 Medical-o1，使用 Qwen-3-8B/14B（Yang et al., 2025）、Llama-3.1-8B（Grattafiori et al., 2024）与 Gemma-3-12B（Team et al., 2025）生成多个回答，并从每个模型各选其一。对 Synthetic-IF，满足全部验证函数的回答标为**优选**，其余为**劣选**。对 MegaScience 与 Medical-o1 数据集，本文采用开源奖励模型集成——Athene-RM-8B（Frick et al., 2024a）与 Skywork-Reward-V2-Llama-3.1-8B-40M（Liu et al., 2025a）——对回答排序并构成最优-最差偏好对。

### 4.2 量规合成

收集多样化偏好对之后，目标是构建一组作为**锚点**（anchor）引导奖励建模的量规。为全面覆盖不同类型的约束同时保留判别粒度，本文将量规分为两类：(1) **硬性规则**，捕捉用户提示中显式陈述的要求；(2) **原则**，描述更高层的定性方面，如推理严谨性、事实性或风格连贯性。随后介绍两种生成高质量量规的策略：

**对比量规生成（Contrastive Rubric Generation, CRG）**。给定偏好数据集 $\mathcal{D}=\left\{\left(x_{i},\{\hat{y}_{i,m}\}_{m=1}^{M_{i}},\{\ell_{i,m}\}_{m=1}^{M_{i}}\right)\right\}_{i=1}^{N}$，其中 $x_{i}$ 为提示，$\{\hat{y}_{i,m}\}_{m=1}^{M_{i}}$ 与 $\{\ell_{i,m}\}_{m=1}^{M_{i}}$ 分别表示候选回答列表及其对应偏好信号。偏好信号 $\ell_{i,m}$ 可以是实值分数（若可得）或二元优选-劣选标签。本文通过构造按偏好降序的严格有序列表统一两种情形：$\hat{y}_{i,1}\succ\hat{y}_{i,2}\succ\cdots\succ\hat{y}_{i,M_{i}}$，其顺序由 $\ell$ 诱导；当仅有优选-劣选标签时，简单地令 $M_{i}=2$，$\hat{y}_{i,1}$ 为优选、$\hat{y}_{i,2}$ 为劣选。目标是推断量规 $\mathcal{R}(x_{i})$，使其既捕捉好回答应满足的质量、也解释列表中偏好差异的准则，从而利用比较所提供的丰富细粒度监督。形式化地，提示一个指令微调 LLM $h_{\psi}$：$\mathcal{R}(x_{i})\sim h_{\psi}\!\left(x_{i},\{\hat{y}_{i,m}\}_{m=1}^{M_{i}},\{\ell_{i,m}\}_{m=1}^{M_{i}}\right)$。生成器被要求产出一组判别性评价准则 $\mathcal{R}(x_{i})=\left\{c_{i,1},\ldots,c_{i,k_{i}}\right\}$，其中每条 $c_{i,j}$ 描述一个具体方面，且应能区分高偏好与低偏好的回答。这一列表式（listwise）设定促使模型发现既对任务敏感、又与偏好对齐的量规维度，同时利用一切可得的细粒度偏好信息。

**基于偏好-标签一致性的量规过滤**。并非所有生成的量规都忠实反映人类偏好信号。为确保可靠性，本文再次提示同一指令微调 LLM $h_{\psi}$ 执行基于一致性的过滤。具体地，对每个提示 $x_{i}$ 及其有序回答列表 $\{\hat{y}_{i,m}\}_{m=1}^{M_{i}}$，构造诱导的成对比较集合 $\mathcal{P}_{i}=\{(a,b)\mid 1\leq a<b\leq M_{i}\}$，其中每对的人类偏好标签为 $\ell_{i,(a,b)}=1$（即 $\hat{y}_{i,a}\succ\hat{y}_{i,b}$）；当原始数据只提供优选-劣选标签时，$M_{i}=2$，故 $|\mathcal{P}_{i}|=1$。接着，把完整量规 $\mathcal{R}(x_{i})$ 拼接进上下文，让模型判断每个诱导对：

$$
\hat{l}_{i,(a,b)}=h_{\psi}\!\left(x_{i},\mathcal{R}(x_{i}),\hat{y}_{i,a},\hat{y}_{i,b}\right), \tag{1}
$$

其中 $\hat{l}_{i,(a,b)}=(\hat{r}_{i,(a,b)},\hat{\ell}_{i,(a,b)})$ 分别表示预测依据（rationale）与预测偏好。只有当量规在诱导对集合上的偏好预测与人类标签一致时，才认为其对提示 $x_{i}$ 可靠：

$$
\mathrm{Acc}_{i}=\frac{1}{|\mathcal{P}_{i}|}\sum_{(a,b)\in\mathcal{P}_{i}}\mathbb{I}\!\left[\hat{\ell}_{i,(a,b)}=\ell_{i,(a,b)}\right]\ \geq\ \tau, \tag{2}
$$

其中 $\tau$ 为阈值（本文取 $\tau=0.5$）。最后，对每个诱导对 $(a,b)\in\mathcal{P}_{i}$，仅当 (i) 量规通过组级验证（$\mathrm{Acc}_{i}\geq\tau$）且 (ii) 当前成对预测正确（$\hat{\ell}_{i,(a,b)}=\ell_{i,(a,b)}$）时，才保留该量规条件化的训练实例：

$$
\mathcal{R}^{*}_{i,(a,b)}=\begin{cases}\mathcal{R}(x_{i}),&\text{if}\quad \mathrm{Acc}_{i}\geq\tau\quad\text{and}\quad\hat{\ell}_{i,(a,b)}=\ell_{i,(a,b)},\\ \emptyset,&\text{otherwise}.\end{cases} \tag{3}
$$

由此得到既可解释、又与人类偏好经验一致的优质量规集合。最终的**量规条件化偏好数据集**构成为成对形式：

$$
\mathcal{D}_{\text{rubric}}=\left\{\left(x_{i},\hat{y}_{i,a},\hat{y}_{i,b},\ell_{i,(a,b)},\mathcal{R}^{*}_{i,(a,b)}\right)\ \middle\|\ i\in[N],\ (a,b)\in\mathcal{P}_{i},\ \mathcal{R}^{*}_{i,(a,b)}\neq\emptyset\right\} \tag{4}
$$

$$
\triangleq\{(x_{i},\hat{y}_{i}^{+},\hat{y}_{i}^{-},\mathcal{R}^{*}(x_{i}))\}_{i=1}^{M}. \tag{5}
$$

即，把所有保留的展平并重索引，得到成对数据集，其中每个新实例对应一个被保留的 $(i,(a,b))$，且 $\hat{y}_{i}^{+}=\hat{y}_{i,a}$、$\hat{y}_{i}^{-}=\hat{y}_{i,b}$。

**量规统计概览**。本文沿三个维度分析整编的量规集：(1) 领域覆盖（指令遵循、推理、通用有用性；图 2a）；(2) *硬性规则*与*原则*之间的平衡、以及提示与量规的长度（图 2b）；(3) 提示主题的语义多样性，基于 Qwen-3-Embedding-0.6B（Zhang et al., 2025c）嵌入的 t-SNE 可视化（图 3）。这些统计证实了合成量规兼具全面覆盖与判别力，构成基于量规的奖励建模的基础。

### 4.3 奖励模型训练与推理

收集量规数据集后，本文继续开发一个输出评价量规的**量规生成模型**，以及产出最终偏好标签的奖励模型 **Rubric-RM**。

**量规生成**。首先微调 $g_{\theta}$，在给定提示 $x$ 的条件下生成量规 $\mathcal{R}^{*}$。给定数据集 $\mathcal{D}_{\text{rubric}}=\{(x_{i},\hat{y}_{i}^{+},\hat{y}_{i}^{-},\mathcal{R}^{*}(x_{i}))\}_{i=1}^{M}$，优化标准交叉熵目标：

$$
\mathcal{L}_{\text{SFT}}^{\text{rubric}}=-\,\mathbb{E}_{(x,\hat{y}^{+},\hat{y}^{-},\mathcal{R}^{*})\in\mathcal{D}_{\text{rubric}}}\sum_{t=1}^{|\mathcal{R}^{*}|}\log p_{\theta}\big(\mathcal{R}^{*}_{t}\mid x,\mathcal{R}^{*}_{<t}\big).
$$

**奖励模型训练**。随后训练奖励模型 $r_{\phi}$，利用生成的量规预测偏好标签 $\hat{l}$。使用 $\mathcal{D}_{\text{rm}}=\{(x_{i},\hat{y}_{i}^{+},\hat{y}_{i}^{-},\mathcal{R}^{*}(x_{i}),\hat{l}_{i})\}_{i=1}^{M}$，优化 $r_{\phi}$ 在提示、回答对与量规条件下预测 $\hat{l}$：

$$
\mathcal{L}_{\text{SFT}}^{\text{rm}}=-\,\mathbb{E}_{\mathcal{D}_{\text{rm}}}\sum_{t=1}^{|\hat{l}|}\log p_{\phi}\big(\hat{l}_{t}\mid x,\hat{y}^{+},\hat{y}^{-},\mathcal{R}^{*}(x),\hat{l}_{<t}\big).
$$

**推理**。推理时，给定成对测试实例 $(x,y^{\text{A}},y^{\text{B}})$，Rubric-RM 以两阶段流程预测最终偏好标签：(1) 量规生成器在指令 $x$ 条件下产出（或检索缓存的）量规 $\hat{\mathcal{R}}(x)=g_{\theta}(x)$；(2) 奖励模型在生成量规条件下、从两个候选标签 $\mathcal{C}=\{\text{A is better},\text{B is better}\}$ 中预测对候选回答 $(y^{\text{A}},y^{\text{B}})$ 的裁决：

$$
\hat{l}=\arg\max_{k\in\mathcal{C}}p_{\phi}\big(k\mid x,y^{\text{A}},y^{\text{B}},\hat{\mathcal{R}}(x)\big).
$$

这确保 Rubric-RM 的判断显式地以量规准则为依据（grounded）。

## 5 实验

### 5.1 数据集与实验设置

**训练数据**。Rubric-RM 的两个组件——*量规生成器*与*判断模型（judge）*——均在 4.2 节整编的 OpenRubrics 上训练。量规由优选/劣选回答的对比信号产出，并在使用前经过偏好-标签一致性过滤。除非特别说明，本文使用 OpenRubrics 的科学相关切片（slice），以更好地匹配 HealthBench/医学评估的领域研究。

**主干与变体**。除非特别说明，量规生成器与判断模型均从 Qwen-3-8B 微调（"Rubric-RM-8B"）。推理时，Rubric-RM 遵循 4.3 节的两阶段流程。本文还报告一个集成变体 voting@5，通过多数投票聚合五条独立采样的判断轨迹。

**基线**。将 Rubric-RM 与同等规模的白盒奖励（判断）模型比较：JudgeLRM-7B（Chen et al., 2025a）、RRM-7B（Guo et al., 2025b）与 RM-R1-7B（Chen et al., 2025b）。可得时还报告更大的 RM-R1-14B（Chen et al., 2025b）与 API 判断模型供参考。为隔离量规感知微调的贡献，还引入朴素 Qwen-3-8B（Rubric+Judge）基线——直接提示基础模型先生成量规再作判断。

**评测基准与指标**。将 Rubric-RM 作为成对奖励模型在以下流行奖励建模基准上评测：*RewardBench*（Chat、Chat-Hard）（Lambert et al., 2025b）、*RM-Bench*（Liu et al., 2025c）、*PPE-IFEval*（Frick et al., 2024b）、*FollowBench*（Jiang et al., 2024）、*InfoBench*（Qin et al., 2024）、*IFBench*（Peng et al., 2025）、*RewardBench2*（Precise-IF、Focus）（Malik et al., 2025）。*FollowBench* 与 *InfoBench* 原本用于评估 LLM 的指令遵循能力，本文将其适配为成对评测：从同一模型（Qwen-3-8B/14B）采样两个回答，其中一个满足全部指定约束、另一个违反其中部分。领域研究额外报告 HealthBench/医学结果。遵循各基准的官方划分与评分规则，报告准确率、胜率或其他特定分数。

篇幅所限，额外实现细节见附录 B。

### 5.2 Rubric-RM 的性能

本文首先验证 Rubric-RM 在奖励建模上的性能。为更系统评估，同时测试了以 Qwen3-4B/8B 为主干的 4B 与 8B 两个变体。表 1 报告结果。

**超越可比奖励模型**。Rubric-RM-4B 与 8B 均超越所有现有 7B 规模白盒基线（如 JudgeLRM、RRM、RM-R1）。值得注意的是，Rubric-RM-4B（68.4）超过最强的 7B 竞争者（最高 61.7），Rubric-RM-8B 进一步提升至 70.1。这证实：即便参数量更少，量规感知训练也比通用偏好学习产出更可靠的信号。

**多数投票进一步增强性能**。Rubric-RM-voting@5 通过五条独立判断轨迹的多数投票聚合预测。Rubric-RM-4B-voting@5 达到 70.3，Rubric-RM-8B-voting@5 取得最佳总平均 73.0，超越更大的模型如 RM-R1-14B（71.7）与 Rubric+Judge API（71.3）。这些结果凸显了基于量规的集成带来的稳定性收益。

**量规感知微调的有效性**。直接用 Qwen-3-8B 生成量规并判断仅得 57.7，而 Rubric-RM 达到 70.1。这 +12.4 的增益验证了本文核心贡献：经对比生成与一致性过滤得到的高质量量规，对有效的奖励建模至关重要。

**在指令遵循基准上的优势**。Rubric-RM 在需要细粒度指令遵循的基准上表现出色。在 FollowBench 与 InfoBench 上分别取得 81.5 与 83.8（voting@5），大幅超越 JudgeLRM、RRM 等基线。这表明量规比标量奖励模型更能捕捉细微约束。

### 5.4 Rubric-RM 在生物医学领域的应用

本节遵循 Arora et al. (2025) 的设定，进一步研究 Rubric-RM 在更专门的生物医学领域的有效性。量规生成器与判断模型均为以 Qwen-3-8B 为主干、用 OpenRubrics 科学相关领域数据微调的模型。

**在 HealthBench 上的性能**。Rubric-RM 在 HealthBench 上超越可比规模的推理奖励模型，达到 68.3，超过 RRM-7B（63.3）与 RM-R1-7B 变体（55.4/66.9），逼近 RM-R1-14B（69.9）。多数投票进一步提升性能：Rubric-RM-voting@5 达到 72.9，缩小了与 14B 推理模型及 API 判断模型的差距。一个关键发现是**领域专属量规 SFT 的重要性**：直接用 Qwen-3-8B 跑 Rubric+Judge 流水线仅得 51.8，而 Rubric-RM 提升 +16.5。这凸显了本文核心贡献：对比式、领域调谐的量规训练比即时量规生成产出精度更高、更具科学意识的评价信号。

> **图 5**：不同判断模型、奖励模型与所训策略模型在 HealthBench 上的比较：(a) 判断与奖励模型；(b) 训练所得策略模型。

**HealthBench 上使用 Rubric-RM 的偏好优化**。将 Rubric-RM 用作 HealthBench 上 DPO 的偏好判断器。从 Qwen-2.5-7B-Instruct（21.6）出发，用 ArmoRM 与 RM-R1-7B 做 DPO 分别提升至 22.5 与 22.7；相比之下，用 Rubric-RM 做 DPO 取得最佳结果 23.8，相对强 7B 推理奖励持续带来 +1.1–1.3 的增益。这些结果表明：量规感知、领域专门化的奖励模型可直接转化为更强的生物医学策略学习，优于生成式推理奖励。

### 5.6 案例研究

本节以案例研究说明 Rubric-RM 如何处理困难输入并改进奖励建模。表 5 展示了 RewardBench 上的案例：两个回答都很生动，但指令要求*少于两段*。基线模型忽略这一硬性约束、错误地偏好更长的回答，表现出冗长偏置（verbosity bias）与指令违反。相比之下，Rubric-RM 先做简单的结构性检查拒绝不合规候选，再比较高层次质量（如意象、原创性、聚焦度），选出正确回答。该例说明长思维链仍可能忽略显式约束，而基于量规的分解使此类失败显性化。

> **表 5**：RewardBench Chat Hard 案例（带错误标注）。提示要求"描述一个生动独特的人物，使用强烈意象与创造性语言，以*少于两段*作答"。回答 A 为单段、切题；回答 B 多段且夹杂无关内容，金标准为 A。RRM-7B 与 JudgeLRM 均以"回答 2 更详细/更生动"为由错选 B。Rubric-RM 生成的量规包含 3 条硬性规则（描述生动独特人物、使用强烈意象与创造性语言、少于两段）与 5 条原则（感官丰富语言、原创表达、语气一致、连贯聚焦、避免不必要的铺陈），其判断为："段落上限是最可验证的约束。回答 B 违反段落规则，而回答 A 满足全部硬规则与多数原则……（选 A）"。基线偏好更长、意象丰富的回答而漏掉显式段落约束；Rubric-RM 则先执行硬性规则、再评估原则。

## 6 结论

本文提出 OpenRubrics——一个面向可扩展、高质量量规生成的大规模数据集与框架。通过对比量规生成将评估分解为硬性规则与原则，并施加偏好-标签一致性过滤，本文构建了与人类判断更对齐、可解释且有判别力的量规信号。基于量规的奖励模型 Rubric-RM 在各基准上平均带来 8.4% 的提升，并通过离线强化学习进一步提升策略模型在多样基准上的性能。这些结果确立了"量规即奖励"作为透明、可泛化的 LLM 对齐的实用基础的地位。

---

## 局限性

尽管 OpenRubrics 展示了强劲的实证增益，仍存在若干局限。其一，量规生成依赖偏好数据中的对比信号与继承的模型判断；偏好-标签一致性过滤虽降低了噪声，所得量规仍可能反映底层模型与数据集的偏置，在主观或文化细腻的准则上尤甚。其二，本框架聚焦成对比较评估；将基于量规的奖励扩展到绝对打分或多回答排序场景仍是开放问题。其三，本文主要在离线偏好优化中评估基于量规的奖励；此类结构化奖励如何与完全在线的 RLHF 流水线、探索动态及长程策略学习交互，是未来工作的重要方向。

## 创新点提炼

1. **首个大规模 (提示, 量规) 对数据集 OpenRubrics**。基于 UltraFeedback、Magpie、Skywork-Preference、Synthetic-IF、MegaScience、Medical-o1 六大来源整编，兼顾通用指令遵循与科学/医学领域，使量规生成模型与量规引导奖励建模首次可以在规模化、多样化的数据上训练，摆脱对领域专家手工整编或商业 API 即时提示的依赖。

2. **"硬性规则 + 原则"的双类型量规体系**。将评价标准显式分解为捕捉提示中显式客观约束的硬性规则（hard rules）与刻画隐式可泛化质量的原则（principles），使量规同时覆盖表层要求与深层质量维度；案例研究表明该组合能有效纠正奖励模型对冗长输出的系统性误报（冗长偏置）。

3. **对比量规生成（CRG）**。不同于直接提示 LLM 生成通用量规，CRG 以"提示 + 按偏好严格排序的回答列表（含负向对比）"为条件，促使模型发现既有任务敏感性、又与偏好对齐的判别性准则；列表式设定还能充分利用实值分数等细粒度偏好信息。

4. **偏好-标签一致性过滤（式 1–3）**。通过让同一 LLM 在量规条件下重判全部诱导比较对，仅保留组级准确率超过阈值 τ=0.5 且当前成对预测正确的量规，形成"生成-验证"闭环，以近乎免费的拒绝采样机制剔除与人类偏好不一致的噪声量规，是合成数据可靠性保障的关键设计。

5. **两阶段 Rubric-RM 架构及其强实证收益**。将评估解耦为"量规生成 + 量规条件化判断"：Qwen-3-8B 主干在八基准上平均 70.1（超最强同规模基线 8.4%），voting@5 达 73.0 并反超 RM-R1-14B 与 API 判断器；作为 DPO 奖励信号时，在 IFEval（79.5）、Arena-Hard SC（53.1）、AlpacaEval（47.0）、WildBench（53.6）与 HealthBench（23.8，+1.1–1.3）上全面领先开源奖励基线。

6. **高效且可摊销的推理设计**。以"短量规生成 + 轻量判断"替代长思维链解码，100 样本仅 130.77 秒（vLLM），快于 RRM-7B 与全部 RM-R1 变体；量规可缓存复用，使大规模打分场景下的量规生成成本趋近于零，兼具可解释性与实用效率。
