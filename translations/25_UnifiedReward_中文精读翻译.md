## 摘要

人类偏好对齐（human preference alignment）的最新进展显著提升了多模态生成与理解能力。其中一个关键路径是训练奖励模型（reward model），为偏好优化提供监督信号。然而，现有奖励模型往往面向特定任务，这限制了它们在多样视觉应用中的适应性。本文进一步主张：联合学习评估多个视觉任务的奖励模型可能催生协同效应（synergistic effect）——图像理解能力的增强有助于更好地评估图像生成（通过对内容质量与语境相关性的更准确判断），而图像评估能力的精细化也有助于视频评估（通过对视频帧更高质量的分析）。（译注：原文此句存在语法笔误 "a reward model that jointly learning to assess multiple vision tasks"。）为此，本文提出 **UnifiedReward**——首个面向多模态理解与生成评估的统一奖励模型。它同时支持成对排序与逐点打分，可为视觉模型的偏好对齐提供有效奖励信号。具体而言：(1) 首先在本文构建的大规模人类偏好数据集上训练 UnifiedReward，该数据集同时覆盖图像与视频的生成/理解任务；(2) 随后利用该模型，通过"成对排序 + 逐点筛分"的两阶段策略渐进过滤视觉模型的输出，自动构造高质量成对偏好数据；(3) 最后使用这些数据经直接偏好优化（Direct Preference Optimization, DPO）使视觉模型与人类偏好对齐。实验结果表明，联合学习评估多样视觉任务带来了实质性的相互收益；我们将该流水线进一步应用于视觉理解与生成两侧，在每一任务域均取得了一致的提升。

**索引术语**：奖励模型、偏好对齐、多模态理解、多模态生成。

## 1 引言

人类偏好对齐的最新进展大幅推动了多模态生成与理解任务的发展。一条直接的技术路线是直接收集人类反馈、构建偏好数据集用于模型优化 (Wallace et al., 2024; Liu et al., 2024; Zhang et al., 2024)。尽管有效，收集大规模人类反馈耗时且耗费资源。为此，另一条流行的替代路线是：从有限量的偏好数据中学习奖励模型 (Wang et al., 2024; Xiong et al., 2024; Liu et al., 2025; Zang et al., 2025; Xu et al., 2024; Li et al., 2025)，再用学得的奖励函数基于视觉模型的输出生成偏好数据。这类合成偏好数据随后可用于视觉模型的偏好对齐，从而显著降低对大规模人工标注的需求。

尽管取得了进展，本文提出两点担忧：

1. **任务特化，适应性受限**。现有奖励模型通常为特定任务量身定制（如表 1 所示），这限制了它们在多样视觉理解与生成任务之间的适应能力。其关键症结在于：缺乏一个横跨广泛视觉任务的综合人类偏好数据集。
2. **任务之间本就相互关联，联合学习可能相互促进**。本文直观地论证：视觉任务本质上是相互关联的，联合学习多个视觉任务可能产生相互增强的效应。具体来说，图像理解的增强可以借助对内容质量与语境相关性的更准确判断，改善对图像生成的评估；类似地，图像评估能力的提升也有益于视频评估——高质量的图像评估带来对视频帧更准确的评价，从而整体上获得更好的视频质量评估。这种跨任务协同（cross-task synergy）促进了对图像与视频两种模态下理解与生成任务输出的更稳健评估，也启发了本文去构建一个能产出更精确偏好优化奖励信号的统一多模态奖励模型。

**本文贡献**如下：

1. 构建了一个横跨多样视觉任务的大规模人类偏好数据集，并在此之上开发了 UnifiedReward——首个面向多模态理解与生成评估的统一奖励模型；
2. 提出了一条同时适用于视觉理解与生成模型偏好对齐的通用流水线——这在当前研究中仍属尚未充分探索的领域。大量实验证明了其在提升各任务域视觉模型性能上的有效性；
3. 实验揭示：联合学习评估图像与视频任务，会在不同视觉域之间产生性能的协同提升。

通过这项工作，作者希望拓展奖励模型的适用范围，使其在多样视觉应用中更具适应性、泛化性与有效性。

## 2 相关工作

### 2.1 奖励模型

奖励模型对于使视觉理解与生成模型和人类偏好对齐至关重要。评估视觉质量与语义一致性的传统方法 (Huang et al., 2023; Liu et al., 2024; Huang et al., 2024) 依赖 FID (Heusel et al., 2017) 与 CLIP 分数 (Radford et al., 2021) 等指标。这些方法虽然有效，但难以充分捕捉人类偏好。因此，近期研究 (Xu et al., 2023; Zhang et al., 2024; Liang et al., 2024) 利用人类偏好数据微调 CLIP，使其能更好地预测并与人类评估对齐。随着 VLM 的出现 (Achiam et al., 2023; Wang et al., 2024)，其强大的视觉-文本对齐能力使其成为奖励建模的理想候选。按能力划分，这类模型可分为两大类：**理解评估模型** (Xiong et al., 2024; Zang et al., 2025)，专为评估视觉理解任务而设计；**生成评估模型** (Wang et al., 2024; Xu et al., 2024; Liu et al., 2025; He et al., 2024)，聚焦于评估视觉合成质量。

然而，如表 1 所示，这些奖励模型通常为特定任务设计，限制了它们对多样视觉理解与生成任务的适应能力。本文提出首个同时覆盖图像与视频理解与生成评估的统一奖励模型，在多样视觉应用中更具适应性、泛化性与有效性。

### 2.2 VLM/扩散模型的偏好学习

偏好学习被广泛用于提升 VLM 与扩散模型在图像/视频理解与生成上的性能。在**视频理解**方面，先前工作探索了利用人类反馈的强化学习来精炼面向事实性评估的奖励模型 (Sun et al., 2023)，而另一些工作 (Ahn et al., 2024; Li et al., 2025; Zhang et al., 2024) 则在 AI 生成的反馈上做强化学习以增强视频大模型。在**图像理解**方面，研究者将 DPO 作为偏好建模的替代途径：例如一些工作 (Ahn et al., 2024; Gunjal et al., 2024) 将 DPO 用于精炼从 GPT-4V 蒸馏得到的、针对不同模型输出的奖励；另一些工作 (Zhao et al., 2023) 则借助详细的图像描述，用 ChatGPT 生成正负样本对来构建偏好数据集。类似方法也被应用于图像生成 (Wallace et al., 2024; Lee et al., 2023; Xu et al., 2024) 与视频生成 (Liu et al., 2024; Liu et al., 2025; Wang et al., 2024; Xu et al., 2024; Furuta et al., 2024; Li et al., 2024; Yuan et al., 2024; Zhang et al., 2024)，即用奖励模型或人类偏好数据对齐预训练扩散模型。

然而，这些方法依赖任务专用奖励模型，且此前尚无横跨图像与视频、生成与理解四类任务偏好学习的统一奖励模型，这限制了基于奖励的对齐的泛化性与效率。本文研究了联合学习评估多个视觉任务的有效性，证明跨任务协同可增强各任务域的评估能力。

## 3 方法

### 3.1 总览

本工作旨在为视觉模型的偏好对齐构建一个统一奖励模型。如前所述，现有研究通常为特定任务开发专用奖励模型（表 1），这限制了其在多样视觉应用中的适应性；同时，联合学习多个视觉任务可能产生相互增强的效应，但这一方向尚未被充分探索。为此，本文提出 **UnifiedReward**——首个面向多模态理解与生成评估的统一奖励模型，同时支持成对排序与逐点打分。它随后被用于 VLM 与扩散模型的对齐，在多样视觉任务上实现更稳健、更具适应性的偏好学习。

本文流水线如图 3 所示。具体而言：首先构建一个大规模统一偏好数据集（3.2.1 节），并在该数据集上训练 UnifiedReward（3.2.2 节）；随后通过对 VLM 与扩散模型的输出施加成对排序与逐点筛分，为其整理偏好数据集（3.3 节）；最后将这些整理后的数据集用于直接偏好优化（3.4 节），有效实现模型与人类偏好的对齐。

### 3.2 统一奖励模型训练

#### 3.2.1 统一偏好数据集构建

一个横跨多个视觉相关任务的综合人类偏好数据集，是训练统一奖励模型的必要前提。然而，现有人类反馈数据集（如 Wang et al., 2024; Liu et al., 2024; Xiong et al., 2024）通常面向特定任务设计，泛化性受限。目前尚无一个能同时覆盖视觉理解与生成任务的人类偏好数据集，这凸显了对更通用数据集的需求。为填补这一空白，本文整合既有数据集并加以预处理，构建了**首个大规模统一人类偏好数据集**，包含约 236K 样本，同时覆盖图像与视频的理解与生成任务。数据集的详细统计与分布可视化分别见表 2 与图 2。下面按任务说明数据构建过程。

> **图 2**：统计结果可视化。展示了本文构建的统一偏好数据集的分布，以及各任务的成对/逐点数据分布。

**图像生成**。EvalMuse (Han et al., 2024) 由 4K 提示词组成，每个提示词配有多张由不同模型生成的图像。每张图像由至少三位标注者评估，给出一个总分（1–5）与逐元素标签（指示特定元素是否出现）。对于逐点打分学习，本文将最终得分取为所有评分的平均；某一元素若至少两位标注者认可则视为"已生成"，否则记为"未生成"。本文将总分与逐元素标签整合为奖励模型学习的评估答案。对于成对排序，从同一提示词下选择平均分最高与最低的图像组成排序对。人类偏好数据集（Human Preference Dataset, HPD）(Christodoulou et al., 2024) 含 700K 人类偏好投票：每个提示词提供两张不同模型生成的图像及其各自票数。本文直接用票数构建成对排序数据，把票数更多的图像排为更优者。Open-Image-Preferences（OIP）(data-is-better-together, 2024) 含 7.4K 文生图偏好对，本文直接使用。

**图像理解**。LLaVA-Critic-113K (Xiong et al., 2024) 含 40K 逐点打分与 73K 成对排序样本，用于图像理解评估学习。本文从中为成对排序与逐点打分各选取 25K 样本。

**视频生成**。VideoDPO (Liu et al., 2024) 含 10K 合成视频对，用于文生视频模型 DPO。本文直接用该数据集做视频生成的成对排序学习。LiFT-HRA (Wang et al., 2024) 与 VideoFeedback (He et al., 2024) 提供了大量针对合成视频逐点打分的人类反馈，本文直接纳入。

**视频理解**。ShareGPTVideo-DPO (Zhang et al., 2024) 含 17K 视频理解 DPO 数据，其中每对中的两个回答各带一个评估分数。本文直接将其中的对数据用于成对排序学习，同时抽取单个回答的分数用于逐点打分学习。

**表 2**：图像与视频生成/理解评估的训练数据集。"*" 表示该数据集在本文中经过了预处理。

| 任务 | 子任务 | 评分方式 | 数据集 | 规模 |
| --- | --- | --- | --- | --- |
| 图像 | 生成 | 成对 | EvalMuse* | 3K |
| | | | HPD* | 25.6K |
| | | | OIP | 7.4K |
| | | 逐点 | EvalMuse* | 32.7K |

对于成对排序数据集，本文将答案格式统一为"image/video/response X 优于 image/video/response Y"，其中 X 与 Y 为指定编号。若数据集包含评估理由 (Xiong et al., 2024; Wang et al., 2024)，则予以保留，使模型能够学习人类的推理过程。对于逐点打分，本文不强制统一回答格式或分数区间，允许模型学习不同数据集多样的评分风格与打分体系；同时相应调整指令提示，以确保评估准则与回答保持一致。

如图 2 所示，与其他任务相比，视频生成成对排序评估的训练数据相对有限，但本文认为多任务学习的协同效应可以缓解这一不足。总体而言，该数据集提供了多样而全面的人类偏好集合，同时覆盖图像与视频理解/生成任务上的成对排序与逐点打分，从而支撑有效的奖励模型训练，保证在多模态理解与生成应用上的稳健性能。

#### 3.2.2 统一偏好学习

基于上述综合数据集，本文微调一个具有强视觉理解能力的预训练 VLM (Li et al., 2024) 来构建 UnifiedReward，使其在多样视觉任务上联合训练。本文并非从零开始学习评估，而是将"评估能力"作为一种额外的判别性技能融入模型，利用其既有的视觉理解能力来增强在各类任务上的评估表现。

图 3（上）展示了训练过程。具体而言，对于多模态**生成**评估，模型输入为视觉 token、指令输入与一段提示词（caption）；对于多模态**理解**，则将 caption 替换为问题及对应的一个（或多个）回答，使输入格式与相应任务的需求对齐。模型被训练为依据指令提示中给定的准则，预测逐点分数或成对排序结果。若训练数据包含评估理由，模型还被训练生成详细的解释来支撑其评估。训练期间的优化目标为标准交叉熵损失，但仅对模型预测的答案部分计算。

> **图 3**：方法总览。(1) 统一奖励模型训练：使用逐点打分与成对排序策略，训练一个同时评估多模态生成与理解的统一奖励模型。(2) 偏好数据构建：用训练好的奖励模型经三步构建高质量偏好数据——(a) 从 VLM/扩散模型生成数据，(b) 成对排序划分 chosen 与 rejected 输出，(c) 逐点过滤精炼 chosen 与 rejected 样本。(3) 生成/理解模型对齐：将构建的偏好数据用于经 DPO 微调 VLM/扩散模型，使其输出与人类偏好对齐。

训练得到 UnifiedReward 之后，本文将其用于多模态理解与生成模型的偏好对齐。该过程由两个顺序步骤组成：偏好数据构建与生成/理解模型对齐，后续小节将分别详述。

### 3.3 偏好数据构建

偏好对齐数据的质量直接决定模型对齐的效果。现有方法 (Wang et al., 2024; Liu et al., 2025; Xiong et al., 2024) 往往局限于单一评估策略——要么给模型输出分配成对排序，要么分配逐点分数——来构建偏好数据。与之相对，本文同时利用 UnifiedReward 的成对排序与逐点打分能力，形成一条质量更高的偏好数据构建流水线（如图 3 左下所示）。

具体而言，该流水线包含三个顺序步骤：

1. **数据生成**。给定一个图像/视频-问题对（或生成提示词），由一个 VLM（或扩散模型）生成多个候选输出 $\{O_{1},O_{2},\dots,O_{N}\}$。这些输出构成后续偏好数据过滤的初始池。
2. **成对排序**（Pair Ranking）。给定 $N$ 个输出，将其分组为 $N/2$ 对，并令模型对每一对进行成对排序。随后将排好的对划分为 chosen（更优）列表 $\mathcal{C}=\{O^{c}_{1},O^{c}_{2},\dots,O^{c}_{N/2}\}$ 与 rejected（更差）列表 $\mathcal{R}=\{O^{r}_{1},O^{r}_{2},\dots,O^{r}_{N/2}\}$。
3. **逐点筛分**（Point Sifting）。最后，令模型对 chosen 列表与 rejected 列表中的所有输出分别赋予逐点分数。最终的偏好数据对确定为：

$$
\left(O^{*}_{c}=\arg\max_{O\in\mathcal{C}}S(O),\quad O^{*}_{r}=\arg\min_{O\in\mathcal{R}}S(O)\right), \tag{1}
$$

其中 $S(O)$ 表示模型赋予的逐点分数，$O^{*}_{c}$ 为最受偏好的输出，$O^{*}_{r}$ 为最不受偏好的输出。

通过成对排序与逐点打分的结合，最终偏好数据可提供高质量且可靠的偏好信号，同时捕捉相对比较与绝对质量评估两方面信息。

### 3.4 生成/理解模型对齐

构建偏好数据后，本文利用 DPO 对多模态生成与理解模型进行对齐。DPO 使模型无需显式奖励建模即可与人类偏好对齐，直接基于排好序的偏好对进行优化。

#### 3.4.1 面向多模态生成的 DPO

对于多模态生成任务，扩散模型 (Ho et al., 2020) 凭借其在图像与视频合成中生成高质量、多样化输出的强大能力而被广泛使用。因此，本文在扩散模型上应用 DPO，使其输出与人类偏好对齐。

给定构建的偏好对数据集 $\mathcal{D}_{Gen}=\{(x^{w}_{0},x^{l}_{0})_{i}\}_{i=1}^{M}$，其中 $x^{w}_{0}$ 与 $x^{l}_{0}$ 分别表示更受偏好与较不受偏好的生成样本，$M$ 为样本数。参照 Wallace et al., 2024 的做法，本文通过比较微调模型与预训练参考模型之间的噪声预测差异来优化扩散模型：

$$
L(\theta)=-\mathbb{E}_{\substack{(x^{w}_{0},x^{l}_{0})\sim\mathcal{D}_{Gen},\; t\sim\mathcal{U}(0,T),\\ x^{w}_{t}\sim q(x^{w}_{t}\mid x^{w}_{0}),\; x^{l}_{t}\sim q(x^{l}_{t}\mid x^{l}_{0})}}
\log\sigma\Bigg(-\beta_{g}T\omega(\lambda_{t})\Big(\big\|\epsilon^{w}-\epsilon_{\theta}(x^{w}_{t},t)\big\|_{2}^{2}-\big\|\epsilon^{w}-\epsilon_{\mathrm{ref}}(x^{w}_{t},t)\big\|_{2}^{2}
-\Big(\big\|\epsilon^{l}-\epsilon_{\theta}(x^{l}_{t},t)\big\|_{2}^{2}-\big\|\epsilon^{l}-\epsilon_{\mathrm{ref}}(x^{l}_{t},t)\big\|_{2}^{2}\Big)\Big)\Bigg), \tag{2}
$$

其中 $x^{w}_{t}$ 与 $x^{l}_{t}$ 分别是 $x^{w}_{0}$ 与 $x^{l}_{0}$ 在时间步 $t$ 加噪后的潜变量；$\epsilon_{\theta}(x^{*}_{t},t)$ 与 $\epsilon_{\mathrm{ref}}(x^{*}_{t},t)$ 分别为微调后与预训练参考扩散模型预测的噪声；$\beta_{g}$ 为控制优化强度的温度超参数；$\sigma$ 为逻辑函数（logistic function）；$\lambda_{t}$ 表示信噪比；$T\omega(\lambda_{t})$ 为加权函数，本文将其视为常数，与 $\beta_{g}$ 合并处理。

该损失鼓励微调后的扩散模型降低偏好样本上的去噪误差、同时提高非偏好样本上的误差，从而提升生成质量。

#### 3.4.2 面向多模态理解的 DPO

与生成对齐类似，本文将 DPO 用于调整多模态理解模型（即 VLM）的回答偏好。给定输入 $x$（如一个图像/视频-问题对）及其来自偏好数据集 $\mathcal{D}_{\mathrm{Und}}$ 的偏好回答 $y_{w}$ 与非偏好回答 $y_{l}$，优化目标表述为：

$$
\mathcal{L}(\theta)=-\mathbb{E}_{(x,y_{w},y_{l})\sim\mathcal{D}_{\mathrm{Und}}}\Bigg[\beta_{u}\log\sigma\Bigg(\log\frac{\pi_{\theta}(y_{w}\mid x)}{\pi_{\mathrm{ref}}(y_{w}\mid x)}
-\log\frac{\pi_{\theta}(y_{l}\mid x)}{\pi_{\mathrm{ref}}(y_{l}\mid x)}\Bigg)\Bigg], \tag{3}
$$

其中 $\pi_{\theta}(y_{*}\mid x)$ 与 $\pi_{\mathrm{ref}}(y_{*}\mid x)$ 分别为微调模型与预训练参考模型下的回答概率，$\beta_{u}$ 为控制优化灵敏度的温度超参数。

该损失鼓励微调后的 VLM 提高生成偏好回答的似然、降低生成非偏好回答的似然，从而改善模型与人类偏好的对齐并提升推理质量。

### 4.4 讨论

#### 4.4.1 多任务评估学习

本文直观主张视觉任务本质相互关联、联合学习可能相互促进。因此，本文探究多任务学习对奖励模型的影响：对每个任务，采用不同的训练数据配置来训练模型，考察跨模态（图像与视频）与跨任务（理解与生成）联合学习的作用。以图像理解任务为例，本文设计了三种训练配置：(1) 仅在图像理解评估数据上训练；(2) 联合学习图像理解与图像生成评估；(3) 联合学习图像理解与视频理解评估。结果见表 3：多任务学习相较单任务训练显著提升了模型整体性能。例如，图像+视频理解联合训练相较仅图像理解训练，总体准确率与宏平均准确率分别提升 5.3% 与 8.3%。其他任务的结果见表 8 与表 4，一致展示了联合学习的有效性。这些结果凸显了跨视觉任务共享知识的好处，带来了更稳健、更泛化的奖励模型。

#### 4.4.2 超越数据规模扩展的跨任务协同

为验证 UnifiedReward 的收益并非简单地来自更大的训练集，本文在表 9(A) 引入了**预算匹配对照**（budget-matched control）："Single-task (native)" 指在各自任务专属数据上训练的单域奖励模型；"Single-task (step-matched)" 指将相同模型进一步过采样、使其更新步数与 UnifiedReward 总更新步数对齐。即便做了这样的预算匹配，UnifiedReward 仍在所有评测轴上取得最佳性能。这说明其优势并非仅仅源于更多训练数据或更长的优化，而是源自理解与生成之间的**正向跨任务协同**。本文进一步通过"单域训练、跨域评测"分析方向性迁移（表 9(B)）。结果显示出清晰的跨任务促进：以理解为中心的训练同样改善生成评估，说明迁移并不局限于源域。同时，单域训练在自身模态内泛化最好，对其他模态也能提供一致的正向收益；而 UnifiedReward 在所有目标上保持一致强劲，表明统一多任务学习在增强正向迁移的同时减少了模态专属的过拟合。

## 6 结论

本文提出 **UnifiedReward**——首个面向多模态理解与生成评估的统一奖励模型，兼具成对排序与逐点打分能力，可用于视觉模型的偏好对齐。具体而言：本文首先在所构建的大规模、综合、横跨广泛视觉任务的数据集上微调一个预训练 VLM，得到 UnifiedReward；随后用该模型经"成对排序 + 逐点筛分"的两阶段过滤过程，从视觉模型输出中自动构建高质量偏好对数据；最后将这些数据用于经直接偏好优化实现的模型偏好对齐。实验结果表明，跨多样视觉任务的联合学习带来了显著的相互收益。将该流水线应用于图像与视频的理解与生成任务后，本文在每个任务域都取得了实质性提升。

## 附录要点（压缩概括）

1. **附录 A（奖励模型基线细节）**：PickScore——在 Pick-a-Pic 上以 CLIP 式模型结合 InstructGPT 奖励模型目标变体训练的图像生成评估模型（采用 "yuvalkirstain/PickScore_v1" 检查点）；HPSv2——基于 CLIP、在 HPD_v2 上微调的图像生成打分模型；ImageReward——经 137K 专家比较（rating+ranking）训练的文生图偏好奖励模型；LLaVA-Critic——基于 LLM 的图像理解评估模型（采用 "lmms-lab/llava-critic-7b"）；VideoScore——在 VideoFeedback（37.6K 合成视频、11 个视频生成模型、多方面人类打分）上训练的视频质量评估模型；LiFT——首个用人类反馈对齐 T2V 模型的方法，其 LiFT-HRA 数据集约 20K 人类标注（分数+理由），并训练 LiFT-Critic 奖励模型；VisionReward——细粒度多维奖励模型，但图像、视频各训独立模型；VideoReward——在 182K 人类标注、12 个视频生成模型来源的偏好数据上训练的多维视频奖励模型。
2. **附录 A（评测基准细节）**：VLRewardBench 含 1,250 个精心设计的高质量样本，覆盖通用多模态查询、视觉幻觉检测与复杂推理（评测时随机打乱回答顺序以增强稳健性）；ShareGPTVideo 含 900K 描述与 17K DPO 偏好数据，本文用其中 16K 训练、1K 测试；GenAI-Bench 通过与人类偏好对比评估 MLLM 判断 AI 生成内容的能力（本文用其图像与视频生成部分）；VideoGen-RewardBench 建于 VideoGen-Eval 之上，含 26.5K 人工构建视频对，按视觉质量、运动质量、文本对齐与总体质量标注（本文用总体质量指标）。
3. **附录 A（DPO 基线细节）**：LLaVA-Critic 用 LLaVA-RLHF 的图像-问题对为 OV-7B 构造偏好数据、训练 3 个 epoch，本文采用相同来源公平对比；LLaVA-Houd-DPO 用 ShareGPTVideo 17K 偏好数据做 DPO，本文从该 17K 中随机采样 14K 构建自己的训练数据、其余设置完全一致；LLaVA-TPO 采用局部与全局两级时序 grounding 偏好数据做自训练，因其训练数据未开源，本文用其发布检查点对比；VideoDPO 是首个基于综合偏好评分系统 OmniScore 的视频生成 DPO 方法，本文用其发布数据集为 T2V-Turbo DPO 作基线，并从其数据抽取视频-描述对构建自己的偏好数据；Pick-a-Pic 剔除约 12% 平局后含约 851K 偏好对、58.9K 唯一提示词，本文直接以之为 SDXL-Turbo DPO 基线，并从中随机采样 14K 提示词构建自己的偏好数据。
4. **附录 B（更多定性比较）**：在 SDXL-Turbo（对比 Pick-a-Pic DPO）与 T2V-Turbo（对比 VideoDPO）上提供更多定性结果（图 8、图 9）；视频理解评估（MSRVTT/MSVD/TGIF）使用 gpt-3.5-turbo-1106 作为裁判，附录给出了 GPT 评测提示词模板（图 10）。

## 创新点提炼

1. **首个"四任务 × 双模式"的统一奖励模型**。此前奖励模型均为任务特化——图像生成（PickScore/HPS/ImageReward）、图像理解（LLaVA-Critic）、视频生成（VideoScore/LiFT/VisionReward/VideoReward）各占一角且多为单一打分模式。UnifiedReward 以单一模型同时覆盖图像/视频 × 理解/生成四类评估任务，并同时支持成对排序与逐点打分（表 1），在所有四类奖励基准上达到或超过各专项基线（如表 3 宏平均准确率 66.5%，超过 GPT-4o 的 62.4% 与 Gemini-1.5-Pro 的 62.5%）。

2. **约 236K 样本的统一人类偏好数据集**。整合并预处理 EvalMuse、HPD、OIP、LLaVA-Critic-113K、VideoDPO、LiFT-HRA、VideoFeedback、ShareGPTVideo 八个来源，首次形成同时覆盖四类任务、兼含成对/逐点两种标注形态的偏好数据集；对成对数据统一答案格式并保留人类评估理由，对逐点数据刻意保留多样评分风格以学习异构评分体系。

3. **"成对排序划池 + 逐点打分筛分"的两阶段偏好数据构建流水线**。先用成对排序把 N=10 个候选输出划分为 chosen/rejected 两个池，再用逐点打分在池内分别取最优与最差构成偏好对（式 1）。消融实验（表 12B）证明两阶段严格优于随机选择、仅打分、仅排序——排序提供可靠相对次序，打分过滤低质量样本，二者互补。

4. **系统性的跨任务协同验证（超越数据规模）**。通过预算匹配对照（把单任务模型的更新步数过采样到与统一模型一致）与"单域训练-跨域评测"迁移矩阵（表 9），严格证明收益来自任务间正向迁移而非训练量；并揭示协同方向的直觉链条——图像理解增强图像生成评估、图像评估增强视频评估；视频生成成对数据仅 10K 的匮乏也被多任务联合学习显著缓解。

5. **跨骨干与跨优化范式的可扩展性**。在 Qwen2.5-VL 3B/7B/32B 上重训 UnifiedReward，性能随骨干规模一致上升（表 10，32B 达宏准确率 79.3%）；除 DPO 外，将 UnifiedReward 直接用作 FLUX.1-dev 上 GRPO 的奖励信号（表 13），在 CLIP/ImageReward/Aesthetic 三项上均超过 HPSv2 与 PickScore 信号，且是唯一不损害 CLIP 对齐分的奖励——证明学得的奖励可作为通用优化信号。

6. **四条 DPO 线上的全胜验证**。在完全公平的偏好数据来源下，基于 UnifiedReward 的偏好数据构建让 OV-7B 图像理解 DPO 全面超过 LLaVA-Critic（表 6，LLaVABench 101.4 对 100.3）、LLaVA-Video 视频理解 DPO 大幅超过 Houd-DPO 与 TPO（表 5，MSRVTT 65.0 对 56.8）、SDXL-Turbo 图像生成 DPO 超过直接用 Pick-a-Pic 原始数据（表 7A，PickScore 63.32 对 54.32）、T2V-Turbo 视频生成 DPO 超过 VideoDPO（表 7B）——证明高质量偏好数据的"蒸馏"价值贯穿理解与生成两侧。
