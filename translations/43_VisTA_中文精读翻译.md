## 一句话核心总结

VisTA 把"视觉工具选择"建模为强化学习问题：训练一个独立的视觉-语言智能体，仅以任务答案的正确性为反馈信号（GRPO + 工具感知的对比式奖励），从包含同类异构工具的多样化工具库中按查询动态探索、选择并组合工具，去辅助一个全程冻结的推理模型——由此学得的选择策略无需重训即可迁移到不同推理骨干（如 GPT-4o），并在 ChartQA、Geometry3K、MathVerse、BlindTest 及分布外（OoD）变体上稳定超越免训练与直接微调推理器的基线。

## 摘要

我们提出 VisTA——一个新的强化学习（Reinforcement Learning, RL）框架，它使视觉智能体能够依据经验性能（empirical performance），从一个多样化的工具库中动态地探索、选择与组合工具。现有的工具增强推理方法或依赖免训练（training-free）的提示，或依赖大规模微调；二者均缺乏主动的工具探索，且通常假设工具多样性有限，而微调方法还额外需要大量人工监督。与之相对，VisTA 利用端到端强化学习，以任务结果作为反馈信号，迭代地打磨复杂的、针对具体查询的工具选择策略。借助组相对策略优化（Group Relative Policy Optimization, GRPO），该框架使智能体无需显式的推理监督即可自主发现有效的工具选择路径。在 ChartQA、Geometry3K 与 BlindTest 基准上的实验表明，VisTA 相对免训练基线取得了显著的性能增益，在分布外（out-of-distribution, OoD）样本上尤为明显。这些结果突显了 VisTA 增强泛化、自适应利用多样工具的能力，并为灵活的、经验驱动的视觉推理系统铺平了道路。项目网站：https://oodbag.github.io/vista_web/。

## 1 引言

大型语言模型（Large Language Models, LLMs）（Brown et al., 2020; Touvron et al., 2023; Achiam et al., 2023）与视觉-语言模型（Vision-Language Models, VLMs）（Liu et al., 2023; Yang et al., 2024; Hurst et al., 2024）的最新进展，在数学问题求解、代码生成与视觉问答等任务上展现出令人印象深刻的能力。然而，这些模型仍然受限于其架构的静态性与权重中信息的固定性。为突破这些约束，近期工作探索用外部工具增强 LLMs 与 VLMs（Chen et al., 2022; Gou et al., 2023; Gao et al., 2023; Patil et al., 2024; Hu et al., 2024; Gupta & Kembhavi, 2023; Surís et al., 2023），大幅扩展了它们的功能。工具增强使模型得以访问专家知识源与动态计算——例如调用 Python 解释器进行自我验证——从而提升复杂任务上的推理表现。

然而，当前的工具集成范式在 LLMs 与 VLMs 中都面临显著局限。现有方法通常或依赖带人工监督的大规模微调来教会 LLMs 如何调用工具（Schick et al., 2023; Liu et al., 2024），或以免训练方式纯粹依赖 LLMs 的内部世界知识（Gou et al., 2023; Lu et al., 2025; Hu et al., 2024）。这些方法往往依赖工具使用演示（Schick et al., 2023; Liu et al., 2024）或详细的工具描述来指导 LLMs 的使用（Hu et al., 2024; Lu et al., 2025）。因此，它们缺乏依据每个查询的具体特性来自动探索、选择或调整工具选择的能力——当存在多个能力各异的同类工具时（这在真实场景中十分常见），这一问题尤为突出。当集成能力未知、文档不全或表现不一致的工具时——其实际性能可能与描述不符——挑战更加明显。从多样来源检索工具时，LLMs 缺乏对这些工具强项与弱项的全面了解。若没有经验学习（experiential learning）机制，系统便无法确定最优的工具选择，也无法发现可能通过协同部署而涌现的工具组合增效。

在真实应用中，工具在不同问题域上的功能与适用性差异巨大。在每一工具类别内部，各个实现各具能力，使其在不同语境下的效果各不相同。这构成了一个复杂的决策问题，恰好适合强化学习（RL）（Sutton & Barto, 1998）。RL 固有的探索-利用（exploration-exploitation）机制使智能体能够基于经验性能而非预先设定的规则，系统地评估并自适应地识别最有效的工具。通过与环境的迭代交互，RL 智能体可以学到依据具体查询动态调整工具组合的自适应策略，甚至可能发现仅凭工具描述难以察觉的非显性工具效用模式。

为此，本文提出一个新的 RL 框架——VisualToolAgent（VisTA），训练自主智能体从多个可用选项中智能地选择最优工具。与免训练（Gou et al., 2023; Lu et al., 2025; Hu et al., 2024）和微调方法（Schick et al., 2023; Liu et al., 2024）不同，本文的 RL 方法内在地支持探索-利用机制，允许智能体通过迭代交互系统性地试验各种工具组合。

本工作聚焦视觉推理任务。该框架包含一个通过端到端 RL 训练的自主智能体，它动态选择最优工具以引导一个固定的 VLM 解决复杂的视觉推理问题。额外的好处是，该框架允许 VLM 本身在 RL 训练期间保持冻结，这意味着智能体学得的选择策略无需重新训练即可迁移到不同的推理模型——这是部署灵活性上的一个关键优势。框架采用组相对策略优化（GRPO）（Shao et al., 2024）算法，使智能体完全从零开始自主发现有效的工具选择路径，无需显式的推理示例。关于智能体在实践中如何执行推理与选择工具的详细展示，见图 6、图 7 中的示例。

> **图 1**：VisTA 总览。（左）该方法训练智能体在无人工监督的情况下自主发现有效的视觉工具组合。（右）通过将智能体与推理器解耦，学得的选择策略可与广泛的推理模型无缝集成。

我们在 ChartQA（Masry et al., 2022）上评估本文方法——这是一个颇具挑战性的视觉推理基准，要求模型解读数值数据、文本标签与复杂视觉结构，例如精确估计图表中柱条的高度。我们还在 Geometry3K（Lu et al., 2021）上测试，它考察细粒度的图形理解与逻辑推理：该任务要求模型准确解析视觉元素（如图形、标签），并将其与文本问题条件对齐以进行基于数学的推理。实验结果表明，本文的 RL 方法显著优于免训练方法；在分布外（OoD）变体——一个对标准数据集引入扰动的鲁棒版本——上测试时，性能差距进一步拉大。这证明了本文方法面对新颖场景时出色的泛化能力，以及在挑战性视觉条件下保持性能的能力。

## 2 相关工作

### 2.1 工具增强推理

当配备搜索引擎（Komeili et al., 2021）、计算器（Cobbe et al., 2021）与 Python 解释器（Chen et al., 2022; Gao et al., 2023）等外部工具时，LLMs 展现出显著提升的推理能力。例如，基于编程的方法（Chen et al., 2022; Gao et al., 2023）集成 Python 解释器来简化中间步骤并验证最终输出，从而提升数学任务上的准确率。类似策略已被引入视觉领域：近期的 VLM 方法（Gupta & Kembhavi, 2023; Surís et al., 2023; Hu et al., 2024）生成 Python 代码来调用专门的视觉模块，将复杂视觉任务分解为可由专用视觉工具处理的更简单子任务。然而，现有方法往往依赖人工演示或标注（Schick et al., 2023; Liu et al., 2024），或仅用模型内部知识以免训练方式运行（Lu et al., 2025; Hu et al., 2024）。这些方法通常工具多样性有限，并严重依赖显式的工具描述（Schick et al., 2023; Hu et al., 2024; Liu et al., 2024; Lu et al., 2025），缺乏针对具体查询自主探索或调整工具使用的能力。与之相对，本文提出的 VisTA 框架使 VLMs 能够在无人为设计先验的情况下，基于经验性能自主探索与选择工具。通过 RL 训练智能体，VisTA 发现了随上下文而定的工具选择策略，可自适应地针对每个视觉推理任务的细微需求定制工具使用。

### 2.2 面向增强推理的强化学习

RL 在增强复杂推理能力与实现推理扩展（inference scaling）方面展现了强劲潜力。OpenAI 的 o1（OpenAI, 2024）与 DeepSeek-R1（Guo et al., 2025）等模型借助长链式思考（chain-of-thought, CoT）（Wei et al., 2022）推理，在数学问题求解等任务上取得显著成功。这些模型擅长错误纠正、步骤分解与迭代精炼等策略，形成更结构化、更长的推理。近期多项研究（Liu et al., 2025; Huang et al., 2025）将 DeepSeek-R1 框架适配到视觉推理，训练模型直接从视觉输入生成基于 CoT 的输出。这些工作聚焦于微调推理模型本身以执行端到端视觉推理，而本文采取一个正交视角：不修改、不重训推理模型，而是训练一个自主智能体去推理"应选择哪些工具来最好地辅助一个*冻结的*推理模型求解给定查询"。通过学习依据每个查询选择辅助工具，智能体在不改动模型内部参数的情况下提升性能（从而保持对其他任务的泛化能力）。该设计也确保了跨不同视觉推理模型的广泛兼容性，为改进多模态推理系统提供了灵活、模块化的策略。ReTool（Feng et al., 2025）是一项并行工作，用 RL 教 LLMs 为文本推理调用代码执行工具；与之不同，本文处理的是具有多样工具选择的视觉推理这一更具挑战性的设定，它要求智能体自适应地选出最有效的工具。

### 2.3 视觉推理任务

一些视觉推理任务，如深度估计与空间推理（Fu et al., 2024），可以用直接的专用工具（如深度估计器或目标检测器）有效解决。与之相对，本文瞄准更复杂、认知要求更高的任务——其最优工具选择依赖于具体查询且并不显然。图表理解（Masry et al., 2022; Lu et al., 2023）是一项具有挑战性的任务，也是视觉推理能力的有力指标：它要求模型处理数值数据、文本标签与复杂视觉结构，不仅要识别视觉元素，还要进行精确的解读与测量，例如准确估计柱状图中柱条的高度。几何问题（Lu et al., 2021; Lu et al., 2023; Zhang et al., 2024）构成类似的高要求挑战：需要细粒度的图形理解，以及植根于视觉细节的文本推理。它通过要求 VLMs 解码图中的视觉元素（如字符与几何图形），并将其与文本问题中给定的条件对齐以求解数学问题，来评估 VLMs 的多模态逻辑推理能力。本文方法在这两类基准上均取得强劲表现，证明了为图表与几何推理任务自适应地学习选择工具的有效性。

## 3 方法

本节介绍 VisTA——一个用于工具增强视觉推理的强化学习（RL）框架。与依赖免训练或微调策略的既往方法不同，VisTA 使智能体通过试错交互学习如何选择工具，无需人工监督。借助 RL 的探索-利用动态，智能体基于性能反馈从大量工具中自适应地做出选择。值得注意的是，核心推理模型保持固定，使学得的工具选择策略无需额外训练即可跨不同推理骨干迁移。

> **图 2**：策略优化。给定用户查询，智能体从预定义的外部工具集中选择工具。工具作用于图像，其输出与查询一起输入冻结的推理器模型。*直接路径*（Direct Path，query+image）与*工具增强路径*（Tool-Augmented Path，query+tools+image）均被评估以计算奖励信号，该信号用于更新智能体的工具选择策略。

### 3.1 问题形式化

记 $(q, I)$ 为一个视觉-语言查询，由图像 $I$ 与关联的文本查询 $q$ 组成，采样自任务分布 $\mathcal{D}$。我们考虑如下设定：一个冻结的视觉-语言模型（推理器，reasoner）$f_\theta$，以及一个外部工具库 $\mathcal{T}=\{T_1,\ldots,T_M\}$，其中 $M$ 为可用工具总数。这些工具涵盖多样的专门视觉模块；例如在图表理解任务中，我们使用图表转 SVG 转换器、图表转表格抽取器与图表转描述（caption）生成器。

我们将智能体的观测或状态定义为 $s=(q,I)$，同时涵盖图像及其对应查询。我们的目标是学习一个选择策略 $\pi_\phi(t\mid s)$——由一个视觉-语言模型（智能体，agent）实现——来决定对给定查询部署哪些工具。形式上，选择策略将状态 $s$ 映射到所选工具序列 $t=\langle T^{(1)},\ldots,T^{(K)}\rangle$，其中 $T^{(i)}\in\mathcal{T}$ 且 $K\leq M$。这里 $K$ 表示为该具体查询选择的工具数量，它随任务复杂度自适应变化。

### 3.2 VisTA 框架

VisTA 框架实现了一条端到端流水线，为视觉推理任务中的动态工具选择学习策略（图 2），利用强化学习实现对工具组合的系统性探索。该流水线运行如下：

1. 视觉-语言智能体观测状态 $s=(q,I)$，并通过策略 $\pi_\phi(t\mid s)$ 选择工具序列 $t=\langle T^{(1)},\ldots,T^{(K)}\rangle$；
2. 每个所选工具在图像上执行，产生输出 $o^{(i)}=T^{(i)}(I)$，其中 $i\in\{1,\ldots,K\}$；
3. 这些输出与原始输入组合，构成增强提示（augmented prompt）；
4. 冻结的推理器 $f_\theta$ 处理增强提示，产生最终答案：

$$
y^{\text{img+tools}}=f_\theta\!\left(q,I,\{o^{(1)},\ldots,o^{(K)}\}\right). \tag{1}
$$

训练期间，我们还仅用原始查询与图像计算一个基线预测：

$$
y^{\text{img}}=f_\theta(q,I), \tag{2}
$$

这使我们能够度量所选工具对推理性能的影响，具体见下一节的奖励设计。

### 3.3 策略优化

为训练智能体通过系统性探索发现有效的工具组合，我们基于 GRPO 算法（Shao et al., 2024）构建；关键区别在于，为使其适配视觉工具选择，我们设计了一个新颖的任务专属奖励函数。

在给定上下文中，某个工具从推理器的视角可能是有助、有害或中性的。若所选工具使推理器答对问题，我们奖励智能体。若工具未带来正确答案，奖励取决于推理器在没有工具增强输入时的表现：具体而言，若推理器在没有工具时同样失败，奖励置 0，因为工具对结果没有影响；但若推理器本可独立答对，我们赋奖励 $-0.5$，惩罚其对最终答案的负面影响。

更形式化地，在每个训练步，给定输入状态 $s=(q,I)$，我们从当前策略 $\pi_\phi$ 采样 $G$ 个工具选择候选 $\{t_j\}_{j=1}^G$。对每个候选 $t_j$，通过比较推理器有无工具时的预测，计算工具感知奖励 $r_j$：

$$
r_j=\begin{cases}
+1 & \text{若 } y^{\text{img}}\neq y^* \text{ 且 } y^{\text{img+tools}}_j=y^*\quad(\text{工具有助})\\
-0.5 & \text{若 } y^{\text{img}}=y^* \text{ 且 } y^{\text{img+tools}}_j\neq y^*\quad(\text{工具有害})\\
0 & \text{若 } y^{\text{img}}\neq y^* \text{ 且 } y^{\text{img+tools}}_j\neq y^*\quad(\text{无变化})\\
+1 & \text{若 } y^{\text{img}}=y^* \text{ 且 } y^{\text{img+tools}}_j=y^*\quad(\text{工具中性})
\end{cases} \tag{3}
$$

其中 $y^{\text{img}}$ 是推理器仅使用问题的预测，$y^{\text{img+tools}}_j$ 是使用 $t_j$ 所选工具后的预测，$y^*$ 是真值。该奖励设计激励"仅凭图像不足时能带来正确预测"的工具选择，同时惩罚损害性能的选择。随后计算每个候选的组相对优势（group-relative advantage）：

$$
A_j=\frac{r_j-\text{mean}(\{r_1,\ldots,r_G\})}{\text{std}(\{r_1,\ldots,r_G\})}. \tag{4}
$$

这一归一化将每次工具选择的性能置于其他候选的语境中，使智能体能够辨别哪些工具组合对该具体查询表现更好，而不依赖绝对奖励值。最后，通过最大化以下目标更新策略 $\pi_\phi$：

$$
\mathcal{J}_{\text{VisTA}}(\phi)=\mathbb{E}_{s\sim\mathcal{D}}\,\mathbb{E}_{\{t_j\}_{j=1}^G\sim\pi_{\phi_{\text{old}}}(\cdot\mid s)}\!\left[\frac{1}{G}\sum_{j=1}^{G}\min\!\left(r_j^{\text{ratio}}A_j,\ \text{clip}\left(r_j^{\text{ratio}},1\pm\epsilon\right)A_j\right)-\beta\,\mathbb{D}_{\text{KL}}\left(\pi_\phi\,\|\,\pi_{\text{ref}}\right)\right], \tag{5}
$$

其中 $r_j^{\text{ratio}}=\frac{\pi_\phi(t_j\mid s)}{\pi_{\phi_{\text{old}}}(t_j\mid s)}$，$\pi_{\phi_{\text{old}}}$ 是前一策略，$\pi_{\text{ref}}$ 是固定的参考策略。该目标通过比率裁剪与 KL 正则化平衡探索与利用：比率项防止过大的策略更新，KL 散度项通过使策略贴近参考分布来保持稳定性。经过这一优化，能持续提升推理性能的工具获得更高的选择概率，使智能体得以基于经验证据而非预定义规则发现有效的工具组合。

### 3.4 工具选择提示

我们设计了一个结构化的提示模板来引导智能体的工具选择过程。对图表理解任务，该模板呈现组织在三个功能类别下的 9 个工具（编号 0–8）："你是一名专家智能体，负责为图表推理任务选择工具。你可以使用编号 0 到 8 的 9 个工具，每个工具属于三种功能类型之一：type1、type2 与 type3……功能：0: type1 (A)、1: type1 (B)、2: type1 (C)、3: type2 (D)、4: type2 (E)……给定一张图表与查询 {Question}，请选出最有帮助的工具编号。仅以逗号分隔的编号列表形式，在 \<answer\> 标签内输出所选编号。"

该提示结构仅提供最小的工具分类信息，不含免训练方法通常依赖的详细功能描述或使用演示。相反，本文框架激励智能体通过强化学习经验性地发现并自适应地选择最有效的工具。当集成能力未知、文档不全或表现不一致的工具时，这一进路尤具价值。

## 4 实验

我们在视觉推理基准上评估 VisTA 框架，与免训练基线及其他基于 RL 的方法比较，并分析 VisTA 的工具选择策略与分布，以及训练过程中的智能体行为动态。

### 4.1 实验设置

**数据集与指标**。我们在两个主要数据集上实验：ChartQA（Masry et al., 2022）与 Geometry3K（Lu et al., 2021）。二者都提供成对的视觉输入与问题，但推理风格与评测协议不同。我们使用两个数据集的训练集训练 VisTA 智能体，并在各自测试集上评估。对 ChartQA，除原始测试集外，我们还通过人工移除图表中的文本标签构造一个分布外（OoD）变体，该设定旨在考察模型对文本线索的依赖与其视觉推理能力。因此，我们总共在三个测试集上评估：ChartQA（域内）、ChartQA-OoD（扰动版）与 Geometry3K。ChartQA 采用开放式答案格式，因此我们报告宽松准确率（relaxed accuracy，与金标准答案相差 5% 以内即算正确）作为评估指标，以奖励语义正确的答案；Geometry3K 是多项选择基准，使用标准准确率来度量与正确选项的精确匹配。

**训练细节**。对 ChartQA 与 Geometry3K，我们各随机采样约 800 个样本用于训练，并在完整测试集上评估。我们使用 8 块 NVIDIA A100 GPU 训练本文方法，批大小为 8，每个查询生成 4 个答案以鼓励多样化的工具交互。我们使用 AdamW（Loshchilov & Hutter, 2017）优化器，学习率为 $5\times 10^{-5}$，智能体训练 100 轮迭代。推理时仅使用工具增强预测路径。

**工具池**。我们为每个领域的推理需求精心组织了基准专属的工具池。对 ChartQA，我们构建了 9 个工具的池子，分为三种功能类型：图表转 SVG、图表转表格与图表转描述，每类 3 个工具。图表转表格工具（T0: UniChart（Masry et al., 2023）、T1: DePlot（Liu et al., 2022）、T2: ChartMoE（Xu et al., 2024））将图表转换为结构化表格；图表转 SVG 工具（T3: OpenCV（Bradski, 2000）、T4: ChartDet（Yan et al., 2023）、T5: ChartQCR（Luo et al., 2021））从图表中抽取几何元素（柱、线、饼）与颜色；描述模块（T6: ChartAssistant（Meng et al., 2024）、T7: ChartVLM（Xia et al., 2024）、T8: QwenVL-32B（Bai et al., 2025））在全局层面总结视觉内容。对 Geometry3K，我们使用较小的 4 工具池，分为两类：符号解析器与专用几何求解器，每类 2 个工具。符号解析器抽取实体与关系（如角度、标签）；专用模型接收问题与图形，生成求解该问题的步骤序列。符号解析器使用 T0: DiagramFormalizer（Zhang et al., 2025）与 T1: Inter-GPS（Lu et al., 2021）；专用求解器使用 T2: G-LLaVA 13B（Gao et al., 2023）与 T3: MultiMath（Peng et al., 2024）。每类中的工具相互独立实现，使智能体能够在能力重叠但有差异的工具之间学习细粒度偏好。

### 4.3 工具选择分析

为评估本文工具选择策略是否有效学会了为每个查询组合并选择最合适的工具，我们将其性能与单独使用各个工具进行比较。具体而言，我们将每个工具的输出连同原始输入送入冻结的推理器，并记录其在 ChartQA 基准上的准确率。我们还计算了一个 88.0% 的伪上界（pseudo-upper bound）：若任一单个工具能使推理器产生正确答案，则该查询视为正确。这充当完美单工具选择所能达到的宽松上限，但未计入组合多个工具的收益。

> **图 3**：单个工具（T0–T8）、无工具基线（No）、本文基于 RL 的选择策略（Ours）与伪上界（Upper）在 ChartQA 准确率上的比较。

图 3 展示了每个工具单独的表现（T0–T8）以及无工具基线（76.4%）。虽然某些工具（如 T2 的 78.3% 与 T1 的 78.0%）优于无工具基线，但与伪上界（88.0%）的巨大差距表明，没有任何单一工具能在所有查询上一致表现最佳——不同工具似乎在不同的数据子集上最优。理想情况下，训练良好的策略应学会为每个具体查询选择最有效的工具，取得超越任何静态工具选择的性能。本文方法取得 79.4% 的准确率，超过所有单个工具。这表明该策略学会了超越固定的工具使用，并基于查询特定上下文调整其选择。本文策略也缩小了最佳单个工具与伪上界之间的部分差距，显示出在无显式监督下向最优工具选择的进展。

图 4 展示了该相关性随训练迭代的变化。尽管初期有所波动，我们观察到明显的上升趋势：相关性随训练进展从接近零增长到超过 0.8。这表明智能体在逐渐使其工具选择策略与每个工具的相对效用对齐——偏爱那些对推理器准确率贡献更大的工具。这些结果表明，本文的 RL 策略并不依赖固定启发式，而是学会基于工具对任务成功的经验贡献加以辨别。这种对齐随时间涌现，进一步证明智能体正通过强化反馈有效地调整其行为。

### 4.5 工具选择分布

图 5 展示了本文 RL 训练的智能体以及使用 QwenVL-7B 与 GPT-4o 的免训练基线在测试集上的工具选择分布。本文方法明显偏好工具 1 与工具 2——二者均为图表转表格工具，是基于单独表现最有效的工具之列（见图 3）。与之相对，表现较弱的工具（如图表转 SVG 的工具 3 与描述模块的工具 6）被选择的频率低得多，说明学得的策略已基于经验反馈有效适应，偏好高效用的工具。

以免训练方式运行、没有强化反馈的 QwenVL-7B 基线呈现出更均衡的选择模式，接近正态分布。这表明它缺乏强烈偏好，不会持续优先选择最有效的工具。同时，GPT-4o 倾向于为每个查询选择更多工具、极少选择不用工具，并将选择分散到更广的工具集上；然而这种更广的使用仍与工具有效性缺乏清晰对齐，选择频率与工具性能之间未表现出强相关。

这些差异凸显了通过 RL 学习工具选择策略的好处。与仅依赖静态提示理解的免训练方法不同，本文智能体基于下游任务结果调整其行为，从而实现更有效的工具使用。

> **图 5**：本文 RL 训练的智能体、QwenVL-7B 与 GPT-4o 的工具选择频率。本文方法强烈偏好有效工具（工具 1 与工具 2）并回避用处较小的工具，而 QwenVL-7B 呈均匀分布，GPT-4o 选择面广但与工具性能无明显对齐。

### 4.11 ChartQA-OoD 测试集的构建

图表问答提出了独特的挑战：要求模型在数值、文本标签与复杂视觉结构上进行推理。有效的图表理解不仅需要识别视觉元素，还需要精确的解读——例如准确估计柱状图中柱条的高度。

为更好地评估 VLMs 的鲁棒性与推理能力，我们为 ChartQA（Masry et al., 2022）构造了带两类针对性扰动的分布外（OoD）测试集。其一，人工移除每张图表中几何元素（如柱与点）上的文本标签；这通过消除经 OCR 直接获取数值答案的途径，孤立地考察模型对视觉特征的依赖。其二，为进一步测试模型空间推理的鲁棒性，我们对图表施加随机几何扰动：每张图表以 50% 的概率被水平或垂直拉伸至原宽或原高的两倍。这些变换保持语义结构但引入视觉变化。所得 ChartQA-OoD 测试集使我们得以探查模型是否严重依赖文本线索，以及其推理对轻微视觉扭曲的敏感程度。该设置为评估 VLMs 的泛化与视觉理解能力提供了更严格的基准。

## 5 讨论与结论

本文提出了 VisTA——一个使视觉智能体能够为多模态推理自主选择有效外部工具的 RL 框架。与既往方法不同，VisTA 在无显式监督的情况下学习自适应的工具选择策略。实验表明其相对强基线取得显著的准确率提升，突显了 VisTA 在鲁棒、灵活视觉推理上的潜力。

**局限性**。本文框架使智能体能够通过经验学习视觉工具选择，但目前尚不能处理需要多工具顺序组合（sequential composition）的情形；探索这一顺序工具组合能力代表了一个有前景的未来研究方向。其次，框架目前依赖固定的人工组织工具集，这可以通过自动发现与集成新工具的方法加以增强。发展此类自动化工具选择与集成方法可显著提升本文方法的可扩展性与适应性。

**更广泛的影响**。本文框架增强了 AI 系统自主学习何时以及如何使用外部工具（如图像描述器与目标检测器）的能力，有望改善多模态环境中的泛化性与鲁棒性。虽然本文当前研究聚焦于图表理解与几何问题等风险相对较低的设定，但在医疗等高风险领域部署类似方法时，错误的工具使用可能引入微妙却重大的错误。在这些敏感应用中，确保可靠性、透明度与适当的人类监督将至关重要。

## 创新点提炼

1. **免监督的端到端视觉工具选择 RL 框架**。VisTA 将"从同类异构工具库中为每个查询选择工具"建模为 RL 问题：智能体通过试错交互与任务结果反馈自主学习选择策略，全程无需人工演示、详细工具描述或显式推理监督。相比依赖提示或微调的既有范式，其固有的探索-利用机制支持对能力未知、文档不全工具的系统性试验。

2. **工具感知的对比式奖励设计**。通过同时评估"直接路径"（仅查询+图像）与"工具增强路径"（查询+工具输出+图像）的答案正确性，构造 +1 / −0.5 / 0 / +1 四情形奖励（式 3），精确区分工具有助、有害、中性、无变化四种情况，并经组相对优势归一化（式 4）后由 GRPO 目标（式 5）优化，使奖励信号聚焦于工具对推理器的边际贡献而非绝对正确率。

3. **智能体与推理器解耦带来的零成本可迁移性**。推理模型全程冻结、仅训练选择策略，使学得的策略无需重训即可搭配不同推理骨干部署：用 QwenVL 7B 训练的策略直接换用 GPT-4o 后，ChartQA 从 79.4 升至 88.9。这既保留了推理模型对其他任务的通用能力，又兼容 GPT-4o、GPT-o1 等多种推理器，是部署灵活性的关键来源。

4. **面向经验学习的极简工具提示接口**。提示模板仅给出工具的功能分类与索引编号，刻意省略详细功能描述与使用演示，迫使智能体通过 RL 经验性地发现工具的真实效用。这使框架天然适合集成能力未知、文档不全或表现不一致的工具——而依赖静态描述的免训练方法在这些场景下缺乏可靠依据。

5. **多维度的策略行为实证分析**。论文从单个工具性能与伪上界（88.0% 对本文 79.4%）、工具使用频率与效用的 Pearson 相关（从近 0 收敛至 0.8 以上）、选择分布（强偏好高效表格工具、回避低效 SVG/描述工具）等多个角度，系统刻画了 RL 策略从均匀探索到偏好高效工具的收敛过程，为"经验驱动工具选择"提供了行为层面的证据。

6. **面向鲁棒性检验的 ChartQA-OoD 基准构造**。通过移除图表文本标签（切断 OCR 捷径）与 50% 概率的双向几何拉伸（宽或高拉伸至两倍）两类扰动，构造分布外测试集以检验模型对文本线索的依赖与视觉推理鲁棒性；VisTA 在该基准上领先最佳基线 6.4 个百分点，验证了经验驱动工具选择的泛化优势。
