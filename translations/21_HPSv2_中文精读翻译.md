## 摘要

近期的文生图（text-to-image）生成模型已能从文本输入生成高保真图像，但现有评估指标无法准确衡量这些生成图像的质量。为解决这一问题，本文引入**人类偏好数据集 v2（Human Preference Dataset v2, HPD v2）**——一个刻画人类对来自广泛来源图像之偏好的大规模数据集。HPD v2 包含 433,760 对图像上的 798,090 次人类偏好选择，是该类别中最大的数据集（译注：摘要原文为 "433,760 pairs of images"，按第 3 节与附录 H 的数据表，该数字应指图像张数而非图像对数）。其文本提示词与图像经过刻意收集以消除潜在偏置——这正是以往数据集的通病。通过在 HPD v2 上微调 CLIP，本文得到**人类偏好分数 v2（Human Preference Score v2, HPS v2）**——一个能更准确预测人类对生成图像偏好的评分模型。实验表明，HPS v2 在各种图像分布上的泛化能力优于以往指标，且对文生图生成模型的算法改进敏感，因而是评估这些模型的更优指标。本文还研究了文生图生成模型评估提示词的设计，使评估稳定、公平且易于使用。最后，本文用 HPS v2 建立了一个文生图生成模型基准，涵盖来自学术界、社区与工业界的一系列近期文生图模型。代码与数据已开源于 <https://github.com/tgxs002/HPSv2>。

## 1 引言

近期文生图合成的进展 (Ramesh et al., 2021; Ramesh et al., 2022; Rombach et al., 2022; Nichol et al., 2021; Ding et al., 2022) 已使基于文本提示词生成高保真图像成为可能。然而，用不同随机种子生成的图像往往质量参差不齐，且已有工作 (Wu et al., 2023; Xu et al., 2023; Kirstain et al., 2023) 表明，Inception Score（IS）(Salimans et al., 2016)、Fréchet Inception Distance（FID）(Heusel et al., 2017) 与 CLIP Score (Radford et al., 2021) 等流行指标与人类对这些图像的偏好相关性不佳。因此，人类偏好是文生图生成模型一个重要却难以追踪的方面。为促进该领域研究，本文构建了一个以人类偏好标注的大规模数据集——人类偏好数据集 v2（HPD v2），并基于在 HPD v2 上训练的偏好预测模型——人类偏好分数 v2（HPS v2）——建立基准，以验证面向人类对齐图像合成的算法进展。

> **图 1**：本工作总览。首先收集人类偏好数据集 v2（HPD v2），随后在其上训练偏好预测模型——人类偏好分数 v2（HPS v2）。

HPD v2 是一个比较来自多种来源图像之人类偏好的综合数据集，包括 9 个文生图生成模型与 COCO Captions 数据集 (Chen et al., 2015)。它包含 79.8 万条由人类标注的、针对同一提示词所生成图像的成对比较，是该类别中最大的数据集。该数据集解决了以往数据集 (Wu et al., 2023; Xu et al., 2023; Kirstain et al., 2023) 中出现的偏置问题。**第一类偏置源于图像来源**。以往数据集主要包含 Stable Diffusion (Rombach et al., 2022) 及其变体生成的图像，因此无法验证只在这些数据集上训练与评估的模型能否泛化到其他图像分布。HPD v2 纳入了 9 个近期模型 (Ding et al., 2022; Nichol et al., 2021; Esser et al., 2021; Liu et al., 2021; Zhou et al., 2021; Rombach et al., 2022; Gu et al., 2022; Ramesh et al., 2021) 生成的图像，以及 COCO Captions 的真实图像，从而能更好地评估泛化能力。**另一类偏置来自文本提示词**。用户撰写的提示词（如 DiffusionDB 中的提示词）(Wang et al., 2022) 往往遵循"描述 + 若干风格词"的特定组织方式，风格词之间常互相矛盾，使标注者更难理解（示例见表 1）。这些风格词本身也高度偏置，给训练与评估带来问题。为消除该偏置，本文用 ChatGPT 去除风格词，并将提示词整理为一句表述清晰的句子。

基于 HPD v2，本文训练了偏好预测模型——人类偏好分数 v2（HPS v2），依据图像被人类偏好的可能性为其打分。实验表明，HPS v2 的泛化能力优于此前模型，包括 HPS v1 (Wu et al., 2023)、ImageReward (Xu et al., 2023) 与 PickScore (Kirstain et al., 2023)。

本文进一步研究如何用 HPS v2 评估文生图生成模型并为其建立基准，核心在于选择一组合适的提示词。Pick-a-Pic (Kirstain et al., 2023) 提议使用其数据集中的提示词，但没有研究应选哪一组、需要多少条。DrawBench 是 Imagen (Saharia et al., 2022) 引入的提示词列表，但本文发现其规模不足以支撑稳定评估。DiffusionDB (Wang et al., 2022) 是一个大规模的用户提示词及生成图像数据库，但其中很大一部分提示词偏向某些数据集特有的风格词，对用其他数据训练的模型并不公平。为缓解该问题，本文用 ChatGPT 清洗 DiffusionDB 的提示词，并仔细研究评估所需的提示词数量，以确保平均分数在统计上稳定。最终得到 4 组用于评估与基准测试的提示词列表，按风格分为 "Animation"（动画）、"Concept-art"（概念艺术）、"Painting"（绘画）与 "Photo"（照片）。

本文还表明 HPS v2 对算法改进敏感。首先，评估了一种直接的测试时技巧——将扩散模型的输入噪声与先验图像混合；其次，通过实验验证了 Wu et al. (2023) 所提方法的量化改进。实验表明 HPS v2 对算法改进敏感，可用于评估文生图生成模型。

**本文贡献**如下：

1. **HPD v2**——面向文生图模型生成图像之人类偏好研究的大规模、精心标注数据集；
2. **HPS v2**——优于现有模型的人类偏好预测模型，并给出若干示例用法以展示其敏感性与准确性；
3. 一组**公平、稳定、易用**的文生图生成模型评估提示词。

## 2 相关工作

### 2.1 文生图生成模型

文生图生成模型允许用户基于文本输入创作图像。DALL·E (Ramesh et al., 2021) 首次实现了高质量的开放域文生图生成。此后，各种架构与建模范式被探索用于提升图像质量，包括自回归模型 (Ramesh et al., 2021; Ding et al., 2022)、GAN (Sauer et al., 2023) 与扩散模型 (Rombach et al., 2022; Ramesh et al., 2022; Saharia et al., 2022)。其中，扩散模型展现出卓越的计算效率与生成高质量样本的能力 (Ramesh et al., 2022)。然而，尽管当前文生图扩散模型能够生成高保真图像，它们常与人类偏好对齐不佳。该领域的近期研究尝试改进扩散模型的图像质量 (Wu et al., 2023; Lee et al., 2023)，但由于缺乏合适的指标与基准，这些改进的评估仍然困难。因此，需要发展新的评估指标与基准来有效验证算法层面的增强。

### 2.2 生成模型的图像质量评估

IS (Salimans et al., 2016) 与 FID (Heusel et al., 2017) 被广泛用于图像生成模型的评估，但它们与近期文生图模型生成图像的人类偏好相关性不佳 (Kirstain et al., 2023; Wu et al., 2023)。LPIPS (Zhang et al., 2018) 通过在人类感知相似度数据集上拟合预训练模型来度量图像对的感知相似性；类似的方法论也用于 HYPE (Zhou et al., 2019) 以评估生成的人脸。近期若干工作 (Wu et al., 2023; Xu et al., 2023; Kirstain et al., 2023) 提出在同一提示词生成图像的人类选择上微调视觉-语言模型（Vision-Language Model, VLM），并以微调后的 VLM 作为人类评估的代理；但这些模型只在 Stable Diffusion 及其变体的图像上调优，其泛化能力尚未得到验证。

### 2.3 图像质量数据集

AVA (Murray et al., 2012) 是一个对照片给出人类评分的数据集。与 AVA 类似，Simulacra (Pressman et al., 2022) 也收集人类评分，但对象是由文本生成的图像。AVA 与 Simulacra 都是图像评分类数据集（即对图像给出绝对分数），二者被用于训练美学分数预测器（Aesthetic Score Predictor）(Schuhmann et al., 2022)，该预测器参与了 Stable Diffusion 的数据清洗流水线。InstructGPT (Ouyang et al., 2022) 提出用人类反馈对齐预训练语言模型；基于人类反馈的强化学习（Reinforcement Learning from Human Feedback, RLHF）思想也被探索用于视觉内容创作 (Lee et al., 2023; Wu et al., 2023)，这需要比较同一提示词生成的图像。HPD v1 (Wu et al., 2023) 正是在此背景下收集的，并通过将文生图模型与人类偏好对齐来提升图像质量。与 HPD v1 类似，ImageReward (Xu et al., 2023) 与 Pick-a-Pic (Kirstain et al., 2023) 是成对图像比较数据集，聚焦于生成图像的评估。AGIQA-1K (Zhang et al., 2023) 与 AGIQA-3K (Li et al., 2023) 的收集方式类似，但规模要小得多。本文的 HPD v2 相比现有工作包含来源更广泛的更多图像，能更全面地评估这些偏好预测模型；与其他数据集的正面比较见表 5。Fake2M (Lu et al., 2023) 是另一个相关数据集，聚焦于区分生成图像的视觉图灵测试。

## 3 人类偏好数据集 v2（HPD v2）

人类偏好数据集 v2（HPD v2）是一个大规模、标注干净的数据集，刻画人类对文本提示词所生成图像的偏好。数据集共包含 43.4 万张图像上的 79.8 万对二元偏好选择。每一对包含由不同模型用同一提示词生成的两张图像，并附有一位标注者做出的二元选择。HPD v2 的收集流水线包括提示词收集（3.1 节）、图像收集（3.2 节）与偏好标注（3.3 节）；数据集的详细统计见 3.4 节；与以往数据集的正面比较见 3.5 节。

### 3.1 提示词收集

**提示词来源**。一个朴素的想法是使用图像描述数据集中的描述文本，如 COCO Captions (Chen et al., 2015) 与 LAION (Schuhmann et al., 2022)。但这些描述大多针对真实图像，可能无法反映生成模型用户的一般兴趣——许多"虚构"内容只能源自生成模型用户的想象。

近期有两个包含用户撰写提示词的来源。**DrawBench** 是 Imagen (Saharia et al., 2022) 提出的用于评估文生图模型的提示词列表，由 200 条提示词组成、分为 11 类，旨在测试模型能力的各个方面；但其规模只勉强满足评估目的（译注：意指不足以支撑统计稳定的评估）。**DiffusionDB** (Wang et al., 2022) 是一个包含大量用户提示词及对应生成图像的数据库，但其中相当一部分提示词偏向特定风格。例如，DiffusionDB 中约 15.0% 的提示词包含人名 "Greg Rutkowski"，28.5% 包含 "artstation"。这些词的有效性高度依赖生成模型的训练数据：一个训练时未见过 artstation 图像、或训练提示词中不含 "artstation" 的模型，可能对这些风格词毫无响应——在这些有偏提示词上测试此类模型是不公平的。此外，这些提示词中还存在相互矛盾的内容。例如表 1 第一条提示词中，"renaissance oil painting"（文艺复兴油画）与 "realism"、"hyperrealist"（超写实）相矛盾。这些矛盾可能干扰标注者对文图对齐的评估。

本文为不同目的收集三组提示词：训练偏好预测模型、测试偏好预测模型、对生成模型做基准测试。三组均由 COCO Captions 提示词与经 ChatGPT 清洗的 DiffusionDB 提示词构成。详细统计见 3.4 节与表 7。

本文组建了 57 人的承包标注团队，其中 50 名标注员、7 名质检员。每名标注员先接受入职培训以熟悉本文的要求与标注系统，关于要求的详细指南见附录 B。培训结束后，标注员需完成一项测试——对 300 组图像排序的任务；质检员基于这些测试评估标注质量。至少 10% 的任务由质检员交叉检查：检查标注者做出的最高排序选择，并相对质检员自己的答案计算 recall@2。

## 4 人类偏好分数 v2（HPS v2）

本节介绍 HPS v2 的训练，并在 HPD v2 与 ImageReward (Xu et al., 2023) 两个测试集上对现有偏好预测模型进行全面评估。

### 4.1 训练

CLIP (Radford et al., 2021) 是将图像与文本对齐到同一嵌入空间的基座模型：其图像编码器将图像编码为视觉特征，文本编码器将描述编码为文本特征，二者的余弦相似度度量输入图像与描述之间的对齐程度。然而如表 6 所示，CLIP 在零样本人类偏好预测上表现不佳。关于 CLIP 模型的更多背景信息见附录 C（译注：原文此句指向附录 F，但按内容应指附录 C 的 "CLIP Details"）。

HPS v2 通过在 HPD v2 上微调 CLIP 得到。训练集中每个实例包含一对图像 $\{x_1, x_2\}$ 与提示词 $p$：若图像 $x_1$ 优于 $x_2$，标注为 $y=[1,0]$，否则 $y=[0,1]$。CLIP 模型可视为一个评分函数 $s$，计算提示词 $p$ 与图像 $x$ 之间的相似度：

$$
s_{\theta}(p,x)=\frac{\mathrm{Enc}_{\mathrm{txt}}(p)\cdot\mathrm{Enc}_{\mathrm{img}}(x)}{\tau}, \tag{1}
$$

其中 $\tau$ 是 CLIP 模型可学习的温度标量，$\theta$ 为 CLIP 的参数。预测偏好 $\hat{y}_i$ 按下式计算：

$$
\hat{y}_{i}=\frac{\exp(s_{\theta}(p,x_{i}))}{\sum_{j=1}^{2}\exp(s_{\theta}(p,x_{j}))}. \tag{2}
$$

$\theta$ 通过最小化 KL 散度来优化：

$$
L_{\mathrm{pref}}=\sum_{j=1}^{2}y_{i}\,(\log y_{i}-\log\hat{y}_{j}). \tag{3}
$$

（译注：式 (3) 求和号内的 $y_i$ 疑为 $y_j$ 之笔误，即标准的交叉熵形式。）

本文微调由 OpenCLIP (Radford et al., 2021; Ilharco et al., 2021) 训练的 ViT-H/14：在 HPD v2 上以 AdamW 优化器 (Kingma and Ba, 2014; Loshchilov and Hutter, 2017) 优化 $L_{\mathrm{pref}}$ 共 4,000 步，学习率为 3.3×10⁻⁶，权重衰减 0.35，批大小 128，预热 500 步，随后按余弦学习率调度。在有限数据上微调预训练模型时，一种常见做法是冻结或降低前几层的学习率 (He et al., 2022; Vasconcelos et al., 2022; Zhai et al., 2022)。本文训练 CLIP 图像编码器的最后 20 层与文本编码器的最后 11 层。超参数以 HPD v2 测试集上的准确率为目标，经贝叶斯优化确定。

## 6 局限性

本工作存在若干潜在局限。提示词来自 DiffusionDB (Wang et al., 2022) 与 COCO Captions (Chen et al., 2015)；基准中除 "Photo" 外三种风格的选择，是本文基于在 DiffusionDB 中观察到的一般兴趣总结的。尽管 DiffusionDB 提供了反映社区用户需求的海量提示词，但确实存在被忽视的主题，例如标志（logo）与平面设计——这些需求在设计行业同样至关重要，且与一般图像创作相比有独特的标准或偏好。用 ChatGPT 清洗提示词也可能引入潜在偏置，尽管目前尚未发现此类模式。此外，该数据集由 57 位标注者标注，因而可能带有他们的偏置。另一局限是本工作未研究图像分辨率对人类偏好的影响，而生成分辨率在不断提高，这一影响可能很大。

生成模型本质上可能带来负面的社会影响。生成模型的进步往往意味着更逼真的生成内容，这些内容可能被恶意利用，以传播更具迷惑性的错误信息与虚假内容。此外，还存在放大训练数据中已有偏置与刻板印象的风险。

## 7 结论

在本工作中，本文设计了一条偏置更小的流水线，用于收集人类偏好标注所需的提示词与图像。基于所收集的数据，本文提出了人类偏好数据集 v2——一个包含 79.8 万对精心标注比较对的人类偏好数据集，使训练人类偏好分数 v2——最先进的偏好预测模型——成为可能，从而让文生图生成模型的评估更好地与人类价值和判断对齐。本文还提供了一组更稳定、更公平的文生图生成模型评估提示词，并建立了一个比较众多近期模型的基准。最后，本文通过若干示例用法展示了 HPS v2 的准确性。基于 HPD v2 与 HPS v2，仍有许多进一步发展与扩展的机会。希望本工作能启发并促进该领域的未来研究。

2. **标注指南**（附录 B）：要求标注者从普适与个人美学角度对图像排序，主要权衡文图对齐与图像质量；两条裁决原则——(1) 当图像 A 在美学吸引力与保真度上均超过 B、或 B 存在严重畸变与模糊时，即便 B 更贴合提示词，也应 A 优先（文中以"倚在门上的滑雪板"与"头上长双角的猫"为例）；(2) 当图像在美学与个人偏好上难分高下时，应细读提示词、主要依据文图对齐排序（"赛博朋克场景中穿蓝色背带裤的姜黄色老鼠机械师"一例）。另提醒特别注意大写专有名词（机器翻译可能产生误解），不熟悉的术语应上网检索样例与解释。

6. **超参数消融**（附录 F）：学习率以 3.3×10⁻⁶ 最优（HPD v2 准确率 83.27%，0.5×10⁻⁶ 时仅 81.79%）；图像编码器解冻层数以 20 层最佳（83.27%，全部冻结仅 78.37%）；文本编码器解冻层数以 11 层为选定配置（83.27%）——说明图像编码器的适配对偏好预测更关键。

7. **示例用法一：检索式初始化**（附录 G.1）：受"Stable Diffusion 训练时不存在输入潜特征完全随机的时间步、而推理却从纯随机噪声出发"这一训练-推理失配现象启发，将 Dreamlike Photoreal 2.0 生成的先验图像编码为与训练阶段噪声水平相近的潜特征，与随机噪声混合后初始化 SD 推理（原先无先验时从 $\mathcal{N}(\mathbf{0},\mathbf{I})$ 采样）。HPS v2 成功检测出该简单技巧带来的提升（表 13：四风格 27.26/26.61/26.66/27.27 → 27.39/26.59/26.71/27.46）；可视化亦显示噪声初始化对生成图像的全局布局影响很大，随机初始化可能导致不理想的布局。

8. **示例用法二：量化 HPS v1 的对齐微调**（附录 G.2）：Wu et al. (2023) 的人类偏好对齐微调此前只能通过用户研究验证（HPS v1 自身含该适配模型的训练、且其偏置与评估提示词未获充分研究，故不适合作为评估指标）；用 HPS v2 量化后，四个风格分数从 SD v1.4 的 27.26/26.61/26.66/27.27 提升至 27.80/27.16/27.24/27.60，证明 HPS v2 对算法改进敏感、可作为评估指标。

9. **数据表（Datasheet）要点**（附录 H）：数据集为促进人类审美偏好的学术研究而建；实例即"两张图像 + 一条提示词 + 一次人类选择"，共 798,090 条比较（译注：Datasheet 原文写作 789,090，应为笔误）、433,760 张图像、107,515 条提示词，基准另含 3,200 条无配图的独立提示词；未记录每条实例的标注者身份；采集时间为 2023-03-15 至 2023-06-03；标注者时薪 20 元、质检员 25 元；数据集自包含，以 Apache 2.0 许可发布，后续更新记录于 GitHub 仓库；推荐评估协议为：偏好模型用准确率（%），文生图模型评估用保留 4 位小数的 HPS v2 分数及标准差。

## 创新点提炼

1. **迄今最大、系统性去偏的人类偏好数据集 HPD v2**。798,090 次成对偏好选择覆盖 9 个文生图模型（自回归 / 扩散 / GAN 三种架构）+ COCO 真实图像，而此前数据集（HPD v1、ImageReward、Pick-a-Pic）几乎只含 Stable Diffusion 系图像，无法检验偏好模型的跨分布泛化；同时用 ChatGPT 清洗提示词，剔除堆砌且互相矛盾的风格词（DiffusionDB 中 "Greg Rutkowski" 占 15.0%、"artstation" 占 28.5%）与平台偏置，并过滤 NSFW 内容，从图像与文本两端同时去偏。

2. **受控的专家标注流程与数据透明度**。57 名签约标注者（50 标注 + 7 质检）经入职培训、300 组图像排序测试与 recall@2 交叉质检（至少 10% 任务）筛选，整体录用率 61%，录用后仍持续抽查；并公开标注者性别、学历、年龄、就业等人口统计信息——这是匿名互联网众包（HPD v1 的 Discord 用户、Pick-a-Pic 的网页用户，后者 34.9% 实例来自重复超 50 次的提示词）难以企及的质量控制与偏置分析基础。

3. **HPS v2 偏好评分模型：更强泛化 + 超越单人的平均偏好**。在 CLIP ViT-H/14 上以成对 softmax + KL 散度目标（式 1–3）微调，采用部分层解冻（图像编码器后 20 层、文本编码器后 11 层）与贝叶斯优化调参；在 ImageReward 与 HPD v2 两个测试集上同时取得最佳准确率（65.7% / 83.3%），尤其在图像分布差异极大的 HPD v2 测试集上显著超越 HPS v1、ImageReward、PickScore，并实证"多人平均偏好所学模型可超过单个人的一致性（78.1%）"。

4. **公平、稳定、易用的评估提示词协议**。经 ChatGPT 清洗并按 Animation / Concept-art / Painting / Photo 四风格分类，每风格 800 条（共 3,200 条）、分 10 组各 80 条报告均值±标准差；800 条的规模经专门研究确保统计稳定且计算开销可控，一举克服 DrawBench（仅 200 条、不稳定）与原始 DiffusionDB（风格词偏置、对不同训练数据的模型不公平）两类缺陷。

5. **覆盖学界-社区-工业界 20 个模型的文生图基准**。以 HPS v2（式 4）统一评测，揭示"社区模型（Dreamlike Photoreal 2.0、Realistic Vision、Deliberate 等 SD 系微调模型）普遍优于学术模型"的趋势；并通过 CogView2"美学质量高但可控性差"的案例及与 CLIP Score、Aesthetic Score 的相关性分析，表明 HPS v2 捕捉了与既有指标不同维度的偏好信息。

6. **对算法改进敏感性的双重验证**。两个用例证明 HPS v2 能可靠反映算法级改进：其一为噪声混合的检索式初始化（简单测试时技巧，四风格分数一致提升）；其二为 HPS v1 人类偏好对齐微调（此前只能靠用户研究验证，现可获得量化增益）。这确立了 HPS v2 作为"能跟踪文生图算法进展"的评估指标地位。
