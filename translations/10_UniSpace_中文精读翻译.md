## 摘要

语义视觉编码器（semantic vision encoder）已成为多模态理解与图像生成中语义条件化（semantic conditioning）的核心视觉接口。然而，其最终 token 丢弃了细粒度视觉细节，导致像素级重建能力差，限制了其在图像生成与编辑等对重建敏感任务中的使用。本工作探讨：理解、生成与编辑能否被建模在基于预训练语义 ViT 构建的单一视觉表示空间中。我们表明，语义 ViT 的冻结 Transformer 块并非本质上无法保留视觉细节；而是原始的补丁参数化（patch parameterization）驱使表示趋向语义抽象，使细粒度信息难以从最终 token 中恢复。基于这一观察，我们提出**补丁重参数化（Patch Reparameterization）**：保留原始语义通路，同时增加一个重建感知的补丁嵌入（reconstruction-aware patch embedding），为同一套冻结 ViT 块提供细粒度视觉信息。所得统一表示在保留多模态理解能力的同时，实现了高保真图像重建与良好的重建—生成权衡。我们进一步将该表示扩展为 **UniSpace**——一个 8B 的混合 Transformer 专家（Mixture-of-Transformer-Experts, MoT）模型，在同一视觉空间中执行理解、生成与编辑，无需单独的 VAE 通路。系统级评估展示了实用的文生图（text-to-image）生成与基于指令的图像编辑，表明重参数化的预训练 ViT 可以作为可扩展多模态建模的统一视觉接口。

## 1 引言（Introduction）

语义视觉编码器已成为现代多模态系统中最重要的视觉接口之一。在视觉—语言模型中，SigLIP (Tschannen et al., 2025) 与 CLIP (Radford et al., 2021) 等编码器为图像理解提供语义对齐的视觉 token。在理解之外，它们还被广泛用作图像生成与编辑系统中的语义条件信号。然而，这些 token 主要面向语义抽象与对齐优化，而非保留细粒度视觉细节。其最后一层表示的像素级可恢复性（pixel-level recoverability）往往很差，不足以作为细节敏感任务（如图像生成与保持参考的编辑）的唯一视觉接口。

这一限制导致当前的生成与编辑系统依赖碎片化的视觉表示。文生图模型通常在自编码潜空间（如 VAE latents）中生成图像，而当需要高层图像语义时再单独引入语义编码器。对图像编辑而言，这种割裂问题更为严重：参考图像必须同时提供语义指导（如物体身份与布局）与细粒度细节（如纹理、颜色与局部结构）。因此，现有系统往往将语义编码器特征与面向重建的 latents 或特征组合使用。近期的统一多模态模型 (Deng et al., 2025)（即 BAGEL）继承了同样的问题：尽管理解、生成与编辑可能被置于同一骨干网络中，视觉信息仍通过分离的语义空间与重建导向空间来表示——它们在架构层面统一了，但在视觉表示层面并未统一。

本工作探讨：视觉理解、生成与编辑能否被建模在基于预训练语义 ViT 构建的单一视觉表示空间内。这引出两个核心挑战。**第一**，我们需要一种统一语义理解与细粒度细节重建、同时保留预训练语义骨干的视觉表示。**第二**，我们需要将该表示扩展到基于 LLM 的统一多模态模型，使其在同一视觉空间中支持理解、生成与编辑。

> **图 1（核心发现）**：补丁嵌入——而非冻结 Transformer 块——才是重建瓶颈。(a) 随深度增加，语义分类准确率上升，但经预训练 SigLIP2 通路的像素可恢复性崩溃；仅将其补丁嵌入 $P_s$ 替换为随机投影 $P_{\mathrm{rand}}$，即可将最后一层 PSNR 提升 3.70 dB；所有 Transformer 权重保持冻结，重建探针完全相同。(b) 该受控干预表明：输入参数化决定了同一骨干激活哪条信息通路——预训练通路偏好语义抽象，而破坏它则暴露出一条细节更丰富的残差通路。

为解决第一个挑战，我们重新审视语义 ViT 重建能力差的原因。如图 1 所示，瓶颈不在于冻结的 Transformer 块，而在于抑制细粒度视觉细节的原始语义补丁嵌入。这启发了**补丁重参数化（Patch Reparameterization）**：保留原始补丁嵌入用于语义理解，并添加一个重建感知嵌入为同一冻结骨干提供视觉细节。合并两条 token 流即可得到兼具理解与重建能力的统一表示，并以平衡流匹配（balanced flow-matching）目标进行训练。将该设计应用于若干预训练编码器，得到 PR-SigLIP2、PR-DINOv2 与 PR-Qwen-ViT，它们在保留语义理解的同时支持高保真重建、生成与保持参考的图像编辑。

为解决第二个挑战，我们将 PR-Qwen-ViT 扩展为 **UniSpace**——一个 8B、基于 Qwen 的混合 Transformer 专家多模态模型。UniSpace 使用补丁重参数化的 ViT 编码器—解码器作为其唯一视觉接口。与先前将语义视觉编码器与单独 VAE 潜空间组合的统一模型不同，UniSpace 在同一统一视觉表示空间中表示参考图像、目标图像与生成输出。该设计直接检验：重参数化的预训练语义 ViT 能否在规模化场景下充当理解、生成与编辑共享的视觉接口。实验表明，UniSpace 在统一生成训练下实现强大的文生图与指令式图像编辑，同时保留通用视觉理解能力。

**本文贡献有三点**：

1. 提出补丁重参数化（Patch Reparameterization），证明冻结的预训练语义 ViT 能够保留细粒度视觉信息，并可被改造为在单一骨干内同时提供语义与重建感知视觉 token；
2. 构建了一系列统一视觉编码器，包括 PR-SigLIP2、PR-DINOv2 与 PR-Qwen-ViT，为理解、重建与生成提供均衡的视觉表示；
3. 开发了由 PR-Qwen-ViT 驱动、基于 Qwen 的统一多模态模型 UniSpace，其单一视觉编码器—解码器接口同时支持多模态理解、文生图生成与指令式图像编辑。

## 2 相关工作（Related Work）

### 2.1 面向生成与重建的语义表示

近期工作表明，语义表示对图像生成高度有益。REPA (Yu et al., 2024) 将中间扩散 Transformer 特征与预训练语义表示对齐，以加速收敛并提升生成质量。VA-VAE (Yao et al., 2025b) 在自编码器训练中引入语义对齐，使潜空间更易于被生成模型学习。RAE (Zheng et al., 2025) 进一步证明，冻结语义编码器特征搭配一个可学习的重建解码器即可直接充当生成 latents。

然而，语义表示并不会自动成为统一的视觉分词器（visual tokenizer）。此类分词器必须同时支持语义理解、高保真重建与生成建模。UniFlow (Yue et al., 2025) 通过蒸馏构建理解感知的重建表示，RAEv2 (Singh et al., 2026) 通过纳入多层 DINO (Caron et al., 2021) 特征改进 RAE 式重建。这些工作将语义表示向重建方向扩展，但语义能力、重建保真度与生成建模三者之间的平衡仍然充满挑战。特别地，强大的理解与重建并不意味着该表示易于被生成先验建模。补丁重参数化正是针对这一缺口：在冻结语义 ViT 内提升重建保真度，同时保持所得表示适合生成建模。

### 2.2 统一多模态模型中的视觉表示空间

近期工作探索了在单一框架内支持理解、生成与编辑的统一多模态模型 (Cui et al., 2025; Wang et al., 2024; SenseNova-U1 Team, 2026; Deng et al., 2025)。但它们在视觉信息的表示方式上差异显著。一些方法用离散视觉分词器对图像建模 (Cui et al., 2025; Wang et al., 2024)，另一些则在连续潜空间中运作。常见设计是为不同任务使用分离的预训练视觉空间。例如，BAGEL (Deng et al., 2025) 采用混合 Transformer 专家架构：语义视觉编码器 token 支持理解，VAE latents 支持生成，共享自注意力使两条通路交互。该模型在架构上是统一的，但其视觉表示仍分裂于语义空间与重建导向空间之间。

我们的 UniSpace 则保留预训练 ViT 的语义先验，并将补丁重参数化的编码器—解码器作为唯一视觉分词器。这使理解、生成与编辑能在同一统一视觉表示空间中运作，同时受益于预训练语义编码器的效率与可迁移性，且无需引入单独的 VAE 潜空间。

## 3 通过补丁重参数化构建统一编码器（Unified Encoder via Patch Reparameterization）

SigLIP、CLIP 等预训练语义 ViT 提供了强大的视觉感知与图文对齐能力，但其最终 token 并非为忠实像素重建设计。现有获取"理解感知重建表示"的尝试往往要训练一个全新视觉编码器 (Yao et al., 2025a) 或依赖语义蒸馏 (Yue et al., 2025)，这会使系统复杂化并可能改变原始语义表示。我们提出一个更简单的问题：是否有必要重新学习 Transformer 块，还是说冻结的语义 ViT 可以被重参数化，从而暴露出其原始语义 token 所抑制的视觉细节？

我们用补丁重参数化回答这一问题。预训练补丁嵌入保持不变以保留原始语义通路，同时新增一个重建感知补丁嵌入，提供另一种参数化方式，在同一套冻结 Transformer 块内保留与重建相关的视觉信息。通过简单的 Token 融合（Token Fusion）策略——重建 token 被压缩后与语义 token 拼接——所得表示统一了语义与重建信息，为理解与生成建模提供共享的视觉接口。

### 3.1 补丁重参数化能够携带视觉细节（诊断实验）

先前分析 (Singh et al., 2026) 表明，语义 ViT 的浅层特征保留更多细粒度视觉细节，而深层特征更加语义抽象。与该观察一致，图 1 显示：随着视觉 token 逐层穿过更深的 Transformer 块，其语义分类准确率从 0.93% 升至 81.29%，而像素级可恢复性迅速退化。然而，这种退化并不必然意味着冻结 Transformer 块本质上无法携带视觉细节。与具有显式低维瓶颈的自编码器不同，ViT 骨干在整个网络中维持高维 token 表示，这为跨层传播输入依赖的细节提供了可能通路。

为检验可恢复性差是否由冻结 Transformer 块本身造成，我们在 SigLIP2 上进行诊断实验：将其预训练补丁嵌入替换为随机初始化的线性投影，保持后续所有 Transformer 块冻结，并在不同深度提取的特征上训练完全相同的重建探针（reconstruction probe）。如果冻结的语义 Transformer 块无法携带像素级信息，那么仅改变输入投影不应改善深层的可恢复性。

**反直觉的结果是**：在使用完全相同的冻结 Transformer 块的前提下，随机补丁嵌入将最后一层 PSNR 从 20.96 提升至 24.66。如图 1 所示，在补丁嵌入输出处，预训练投影与随机投影的可恢复性相近（PSNR 分别为 39.29 与 39.68）；二者的行为只在 token 穿过同一套冻结语义 Transformer 块后才分化。在预训练补丁嵌入下，输入激活了后续块被优化去进行语义抽象的视觉模式，逐步抑制与语义目标无关的变化；而随机投影破坏了这一偏好的语义处理轨迹，使更多低级输入变化得以通过残差通路（residual pathway）保持可恢复。

该结果表明：像素级信息并非因为隐藏空间无法携带而丢失，而是在语义编码器原始输入参数化下被选择性抑制。当然，随机化补丁嵌入本身并非可行方案，因为它摧毁了预训练语义表示。它启发的是一种最小化改造（minimal adaptation）：保留原始语义补丁嵌入用于理解，另学一个重建感知补丁嵌入，将视觉细节注入同一套冻结 Transformer 块（见图 2）。

> **图 2（方法总览）**：原始语义补丁嵌入与冻结 ViT 块保留预训练语义通路，重建感知补丁嵌入将视觉细节注入同一冻结骨干。语义 token 与重建感知 token 经 Token 融合层组合成统一表示，供理解、重建与生成共享。

### 3.2 构建统一表示与显式 Token 融合

给定输入图像 $I$，我们构建一个保留预训练编码器语义能力、并以通道因子化（channel-factorized）形式附加重建细节的统一表示。设 $F_\phi$ 为预训练语义 ViT 的冻结 Transformer 块，$P_s$ 为其原始预训练补丁嵌入。原始语义 token 为：

$$
T_s = F_\phi(P_s(I)), \tag{1}
$$

其中 $P_s$ 与 $F_\phi$ 均保持冻结。该路径保留预训练语义表示，是视觉理解的基础。

为捕获与重建相关的细节，我们引入重建感知补丁嵌入 $P_r$：从 $P_s$ 初始化，面向重建优化，其后接同一套冻结 Transformer 块：

$$
T_r = F_\phi(P_r(I)). \tag{2}
$$

因此，$T_r$ 并非由独立的重建编码器产生，而是通过不同的输入参数化在同一语义 ViT 参数空间内编码得到。

**显式 Token 融合（Explicit Token Fusion）**。统一 $T_s$ 与 $T_r$ 的一种朴素方法是用 MLP 将其融合进单一纠缠特征空间。然而，如 5.1.4 节所讨论，这种隐式融合使生成建模时难以控制语义与重建信息的相对贡献。因此，我们将两个组件沿通道维度保留为显式分离的特征组。拼接之前，先将重建 token 投影到紧凑空间：

$$
\widetilde{T}_r = W_r T_r, \tag{3}
$$

其中 $W_r$ 是沿通道维度的可学习线性投影，将重建 token 从 $d$ 维映射到更低维度 $d_r$。该投影的作用与拼接不同：它降低重建组件的维度，减轻生成模型的负担，同时保留对解码器关键的视觉细节。随后将原始语义 token 与压缩后的重建 token 沿通道维度拼接：

$$
T_u = \operatorname{Concat}(T_s, \widetilde{T}_r). \tag{4}
$$

完整的统一表示 $T_u$ 作为所有下游任务（理解、重建、生成）的共享视觉表示；$T_s$ 与 $\widetilde{T}_r$ 均不单独使用。与"学习式特征合并"不同，这种显式融合不改变预训练语义表示，并在语义信息与重建信息之间维持显式边界。压缩降低重建细节的维度，拼接则使两种信息源在生成训练中可被分别寻址。

### 3.3 面向重建与生成的训练

**训练重建感知通路。** 构建 $T_u$ 后，遵循 RAE，采用 ViT 解码器 $D_\psi$ 重建输入图像：

$$
\hat{I} = D_\psi(T_u). \tag{5}
$$

训练时，重建感知组件与解码器以重建目标优化：

$$
\mathcal{L}_{\mathrm{rec}} = \mathcal{D}(\hat{I}, I), \tag{6}
$$

其中 $\mathcal{D}$ 由像素级与感知（perceptual）重建损失实例化。仅更新重建感知补丁嵌入 $P_r$、线性投影 $W_r$ 与解码器 $D_\psi$；原始补丁嵌入 $P_s$ 与预训练 ViT 块 $F_\phi$ 保持冻结。由于重建训练从不修改原始语义路径，预训练语义 token 在结构上被完整保留，而附加路径则学习提供解码器所需的关键细节。

**平衡生成建模（Balanced Generative Modeling）。** $T_u$ 的显式通道分解也为生成训练提供了直接控制。对拼接表示直接施加朴素 MSE，会依据两组件的维度与尺度隐式加权，而无法指定目标中应有多少比例聚焦于解码器关键的重建信息。因此我们采用平衡流匹配（balanced flow-matching）目标：先按维度归一化各组件的误差，再分配显式目标权重。

我们用条件流匹配（conditional flow matching）建模统一表示的分布。设 $Z_1 = T_u$ 表示一个统一表示，$Z_0 \sim \mathcal{N}(0, \mathbf{I})$ 为同形状的高斯噪声样本，$t \sim \mathcal{U}[0,1]$ 为时间步。构造线性概率路径：

$$
Z_t = (1-t)Z_0 + tZ_1, \tag{7}
$$

其目标速度（target velocity）为：

$$
V_t = \frac{\mathrm{d}Z_t}{\mathrm{d}t} = Z_1 - Z_0. \tag{8}
$$

给定 $Z_t$、$t$ 与条件 $c$，生成模型 $v_\theta$ 预测速度 $\widehat{V}_t = v_\theta(Z_t, t, c)$。设 $T_s \in \mathbb{R}^{N \times a}$ 与 $\widetilde{T}_r \in \mathbb{R}^{N \times b}$ 分别为 $T_u$ 的语义组件与重建组件。它们的显式通道分离允许我们将目标速度与预测速度分区：

$$
V_t = \operatorname{Concat}(V_t^s, V_t^r), \qquad \widehat{V}_t = \operatorname{Concat}(\widehat{V}_t^s, \widehat{V}_t^r). \tag{9}
$$

我们按各组件的维度数归一化预测误差，并优化重建—语义平衡的流匹配目标：

$$
\mathcal{L}_{\mathrm{BFM}} = \mathbb{E}_{Z_1, Z_0, t, c}\left[ (1-\lambda_r)\frac{\lVert \widehat{V}_t^s - V_t^s \rVert_F^2}{Na} + \lambda_r \frac{\lVert \widehat{V}_t^r - V_t^r \rVert_F^2}{Nb} \right], \tag{10}
$$

其中 $\lambda_r$ 指定分配给重建组件的总目标权重比例。我们设 $\lambda_r = 0.75$，即将 75% 的目标权重分配给解码器关键的重建组件，同时保留促进生成学习的语义组件；该选择得到附录 A 表 12 消融的支持。

推理时，采样 $Z_0 \sim \mathcal{N}(0, \mathbf{I})$ 并求解常微分方程：

$$
\frac{\mathrm{d}Z_t}{\mathrm{d}t} = v_\theta(Z_t, t, c), \qquad t: 0 \rightarrow 1, \tag{11}
$$

得到生成的统一表示 $\widehat{T}_u$，再经解码器解码为图像 $\hat{I} = D_\psi(\widehat{T}_u)$。

### 3.4 实现细节

**统一分词器构建。** 我们在三个预训练语义 ViT 上实例化补丁重参数化：SigLIP2-B (Tschannen et al., 2025)、DINOv2-B (Oquab et al., 2024) 与 Qwen-ViT (Bai et al., 2025)，分别得到 PR-SigLIP2、PR-DINOv2 与 PR-Qwen-ViT。SigLIP2-B 在 256×256 分辨率下评估，16×16 token 网格，768 维语义空间；DINOv2-B 使用其原生 14×14 token 网格与 768 维语义空间；Qwen-ViT 支持原生分辨率输入，patch 大小 16×16，在我们的设置中语义空间为 1152 维。所有骨干的重建感知补丁嵌入 $P_r$ 均从预训练补丁嵌入 $P_s$ 初始化，全部 Transformer 块 $F_\phi$ 冻结。重建投影 $W_r$ 将重建感知流映射到 128 通道：PR-SigLIP2 与 PR-DINOv2 得到 896 维统一表示，PR-Qwen-ViT 得到 1280 维表示。

**重建训练。** 图像重建使用 ViT-XL 规模解码器：28 层、隐藏宽度 1152、FFN 宽度 4096、16 个注意力头。遵循 RAE 训练配方，重建目标组合像素级与感知损失，并进一步用对抗损失精化解码器以实现高保真解码。对 SigLIP2-B 与 DINOv2-B，先用 L2 与 LPIPS 损失训练 $P_r$、$W_r$ 与解码器：AdamW，学习率 $2\times10^{-4}$，$(\beta_1,\beta_2)=(0.9,0.95)$，权重衰减 0，全局 batch size 512，1 个 warmup epoch，EMA 衰减 0.9978。随后冻结编码器侧模块，仅用 L2、LPIPS 与 GAN 损失再训练解码器 20 个 epoch（优化器、batch size 与 EMA 设置不变），判别器学习率从 $2\times10^{-4}$ 余弦退火至 $2\times10^{-5}$。ImageNet 主要结果额外使用一个简短的解码器校准（decoder calibration）阶段：从早期 DiT checkpoint 采样 latents 并只更新解码器（编码器与生成模型固定），使解码器适应统一潜空间中真实的生成误差。SigLIP2-B 与 DINOv2-B 在 ImageNet-1K 256×256 分辨率上训练，Qwen-ViT 则以相同统一分词器设计在网页数据上训练。

**生成训练。** ImageNet 生成上，遵循 RAE (Zheng et al., 2025) 生成协议评估 PR-SigLIP2 与 PR-DINOv2：采用相同 DiTwDDTHead 架构，输入尺寸 16、patch 大小 1、896 输入通道、hidden sizes (1152, 2048)、depths (28, 2)、16 个注意力头。使用线性速度预测、logit-normal 时间分布以及 RAE 的维度依赖时间偏移（time-shift）规则；对 896×16×16 的 latent，偏移所用维度为 229,376、base 为 4096。训练用 AdamW：学习率 $2\times10^{-4}$、betas (0.9, 0.95)、权重衰减 0、全局 batch size 1024（梯度累积 2）、EMA 衰减 0.9995、梯度裁剪 1.0，线性调度 40 个 warmup epochs 并在第 800 epoch 衰减至 $2\times10^{-5}$。采样用 Euler ODE 求解器、50 步。

## 4 UniSpace：在单一视觉空间中扩展统一建模

在建立了同时保留语义与像素级信息的表示之后，我们接下来研究它能否充当大规模多模态模型的共同视觉接口。我们将这一想法实例化为 **UniSpace**：一个在单一补丁重参数化视觉表示空间内完成文生图生成、指令式图像编辑与图像理解的统一多模态模型。编辑在该设置中尤为重要，因为它对表示的两面都构成压力测试：模型必须理解参考图像与指令、执行所请求的修改、并在所有无关区域保留细粒度细节。UniSpace 因此对全部三项任务使用同一冻结的统一视觉分词器，并在混合 Transformer 专家架构内进行扩展。

### 4.1 统一 MoT 架构

UniSpace 构建在 decoder-only 的 Qwen3-8B (Yang et al., 2025) 骨干之上，采用 BAGEL (Deng et al., 2025) 的混合 Transformer 专家（Mixture-of-Transformer-Experts, MoT）设计。它包含一个**理解专家**与一个**生成专家**，二者在共同的多模态序列上运作。Token 类型被硬路由（hard-routed）到模态特定参数：文本与条件图像 token 由理解专家处理，而待预测的加噪视觉 token 由生成专家处理。在每一层，自注意力允许两个专家处理的 token 直接交互，在理解与生成之间保留无瓶颈的上下文。

> **图 3（UniSpace 流水线）**：UniSpace 建立在所提统一视觉表示之上，使用 PR-Qwen-ViT 编码器—解码器作为参考图像、目标图像与生成图像的唯一视觉接口。文本与视觉 token 经混合 Transformer 专家骨干路由，完成理解、文生图生成与指令式图像编辑，无需额外 VAE 通路。

UniSpace 的关键区别在于其视觉接口。现有基于 MoT 的模型通常使用两个视觉表示空间：语义 ViT 向理解通路提供 token，单独的 VAE 向生成通路提供 latents。相比之下，UniSpace 将第 3 节开发的统一编码器与解码器作为其唯一视觉分词器，既不需要单独的 VAE 编码器，也不需要额外的 VAE 潜空间。表 1 将该设计与两个代表性 MoT 系统对比：BAGEL 为语义条件与生成保留两个预训练视觉空间；SenseNova-U1 移除外部视觉编码器，端到端学习原生像素接口。UniSpace 走的是另一条路线：保留预训练 ViT 的语义先验，将其重参数化为与重建兼容的视觉分词器，并把理解、生成与编辑 consolidate 到一个冻结、可复用的视觉表示中，而不引入单独的 VAE 通路。

**表 1：代表性 MoT 统一模型的视觉接口对比**（"Spaces"指多模态模型使用的不同视觉表示空间数量）

| 模型 | 视觉接口 | 预训练语义先验 | 单独 VAE | Spaces | 参考条件 | 接口训练 |
| --- | --- | --- | --- | --- | --- | --- |
| BAGEL (Deng et al., 2025) | SigLIP2 + FLUX-VAE | ✓ | ✓ | 2 | ViT + 干净 VAE token | 冻结 |

对图像理解，输入图像被编码为 $T_u$，与文本指令一起处理以预测文本响应。对文生图生成，目标图像表示在同一 $T_u$ 空间中，沿流路径被加噪，由以文本为条件的生成专家预测。图像编辑则结合两种情形：参考图像编码为 $T_u^{\mathrm{ref}}$ 并与编辑指令一同提供，而加噪的目标表示在同一 $T_u$ 空间中被预测。通过共享自注意力，目标 token 同时以指令与参考表示为条件，采样得到的表示再由同一解码器 $D_u$ 解码。因此，三项任务在 token 排布与路由上不同，但共享同一视觉分词器、表示空间与图像解码器（见图 3）。

### 4.2 统一训练目标

UniSpace 在共享多模态序列上使用两个训练目标：文本响应的交叉熵下一 token 预测（next-token prediction），以及统一表示空间 $T_u$ 中视觉预测的平衡流匹配。对理解样本，模型以标准下一 token 预测目标预测响应 token：

$$
\mathcal{L}_{\mathrm{NTP}} = -\sum_{k=1}^{L} \log p_\theta(y_k \mid y_{<k}, c_{\mathrm{und}}), \tag{12}
$$

其中 $y_{1:L}$ 表示目标文本响应，$c_{\mathrm{und}}$ 表示由输入图像表示 $T_u$ 与文本指令构成的多模态上下文。对生成与编辑任务，目标图像先被映射到统一表示空间得到 $Z_1$，再按公式 (7) 的线性流路径扰动。初始噪声从标准高斯分布采样，目标速度定义为噪声与目标表示之间的位移。遵循 RAE (Zheng et al., 2025)，采用 logit-normal 时间步采样策略与相同的维度依赖时间偏移规则。模型以公式 (10) 的平衡组件级流匹配目标优化，其中 $\lambda_r = 0.75$ 在所有 UniSpace 训练阶段沿用（与分词器级生成设置一致）。

所得统一视觉预测目标为：

$$
\mathcal{L}_{\mathrm{vis}}(c) = \mathbb{E}\left[ \ell_{\mathrm{BFM}}\left( v_\theta(Z_t, t, c), V_t \right) \right]. \tag{13}
$$

此处 $c$ 表示任务特定条件。对文生图生成，条件只包含文本 token；对图像编辑，条件还额外纳入参考图像表示与编辑指令。因此：

$$
\mathcal{L}_{\mathrm{t2i}} = \mathcal{L}_{\mathrm{vis}}(c_{\mathrm{t2i}}), \qquad \mathcal{L}_{\mathrm{edit}} = \mathcal{L}_{\mathrm{vis}}(c_{\mathrm{edit}}). \tag{14}
$$

生成与编辑因此共享同一目标表示空间与视觉预测损失，仅在条件上下文上不同。

总体上，UniSpace 在理解、文生图生成与图像编辑样本的混合数据上训练。设 $\tau \in \{\mathrm{und}, \mathrm{t2i}, \mathrm{edit}\}$ 表示训练样本的任务类型，总训练目标可写为：

$$
\mathcal{L}_{\mathrm{UniSpace}} = \mathbb{E}_{(x, \tau) \sim \mathcal{D}}\big[ \mathbf{1}_{\tau=\mathrm{und}} \mathcal{L}_{\mathrm{NTP}} + \mathbf{1}_{\tau=\mathrm{t2i}} \mathcal{L}_{\mathrm{vis}}(c_{\mathrm{t2i}}) + \mathbf{1}_{\tau=\mathrm{edit}} \mathcal{L}_{\mathrm{vis}}(c_{\mathrm{edit}}) \big]. \tag{15}
$$

即：理解由文本响应上的交叉熵监督，生成与编辑则在统一表示空间 $T_u$ 中共享同一平衡流匹配目标，仅在条件上下文上不同。统一编码器与解码器在 UniSpace 训练全程保持冻结；所有 MoT 参数均可训练，统一视觉分词器全程冻结。

### 4.3 训练细节

**训练数据与课程（渐进训练课程）。** UniSpace 在内部策划的文生图生成、图像编辑与视觉理解数据集上训练，分别提供图像生成、指令引导编辑与图文理解的监督。完整训练课程总结于表 2。我们跨三个阶段渐进扩展训练，图像分辨率依次提升：256、512、1024。

- **Stage 1**：联合优化文生图生成与视觉理解，采样比例 10:1；
- **Stage 2**：引入图像编辑，生成、编辑与理解数据按 10:3:1 混合；
- **Stage 3**：在 1024 分辨率下通过打包（packed）多模态训练进一步扩展全部三种能力；
- **SFT**：预训练后进行多模态监督微调（supervised fine-tuning），使用打包的文生图、图像编辑与 LLaVA-NeXT 风格视觉指令数据 (Liu et al., 2024b)，生成、编辑与视觉指令样本按 10:3:2 混合。该阶段在保留预训练习得的生成与编辑能力的同时，提升指令遵循与视觉理解。

所有训练阶段合计，UniSpace 处理约 5.1 亿（510M）训练样本实例，对应约 4700 亿（470B）多模态 token。样本实例指训练中观察到的样本（可能包含对底层数据集的重复采样）。统一视觉分词器与视觉编码器在所有阶段全程冻结。

**优化。** 使用 AdamW：$\beta_1 = 0.9$、$\beta_2 = 0.95$、$\epsilon = 10^{-15}$、零权重衰减；线性 warmup 后接恒定学习率调度（三个预训练阶段 warmup 600 步，SFT 100 步），各阶段峰值学习率见表 2。以 BF16 精度训练，全局梯度范数裁剪至 1.0。每个优化步每设备处理一条打包序列，不做梯度累积；训练期间不使用指数滑动平均（EMA）。

模型渐进训练：每个阶段从前一阶段选定的 checkpoint 初始化，而优化器与学习率调度器在每个新阶段开始时重新初始化。视觉编码器与统一视觉分词器全程冻结，语言模型、模态专家与多模态投影模块则联合优化。

**打包多模态训练（Packed Multimodal Training）。** 为在异构多模态序列长度下提升训练效率，我们采用打包多模态训练：将多个独立样本（可能来自不同训练目标）拼接为单条打包序列，直至达到预定义 token 预算；样本按表 2 中任务特定采样比例抽取，因此所述比例描述的是整个训练过程的期望采样频率，而非每条打包序列的精确构成。

我们为打包序列构造块级注意力掩码（block-wise attention mask）以阻止不同样本间的信息交换：token 只能关注属于同一样本的 token，而每条样本内部的注意力遵循其模态特定模式——文本 token 使用因果注意力，视觉 token 在同一样本内使用全注意力。位置索引在打包序列内的每条样本处重置。损失仅在有效目标 token 上计算：文本交叉熵损失作用于目标文本 token，图像生成损失仅作用于目标视觉 token。

Stage 1、Stage 2、Stage 3 与 SFT 的最大打包序列长度分别为 3,072、8,192、12,288、13,000，各阶段 token 利用率约为 73%–79%。随着图像分辨率提升，每条打包序列包含的样本数因视觉 token 增多而减少，但全局任务采样分布保持不变。

**数据处理。** 三个预训练阶段使用分辨率特定的图像桶（image bucket）：按纵横比调整尺寸并分桶，纵横比偏差阈值为 0.05。视觉输入由冻结的统一视觉分词器进行 token 化。文生图中以 0.1 的概率对文本条件做 dropout 以支持无分类器引导（Classifier-Free Guidance, CFG）；多模态训练中对指令也以 0.1 的概率 dropout。图像编辑中，参考图像经理解分支处理，目标图像则作为生成目标表示。

**分布式训练基础设施。** Stage 1–3 在 256 块 Ascend 910B NPU（每块 64GB，16 节点 × 每节点 16 NPU）上训练；SFT 在 128 块 Ascend 910B NPU（8 节点）上训练。训练以 PyTorch 实现，采用 FSDP 与 SHARD_GRAD_OP 分片策略，并使用 BF16 混合精度、激活检查点（activation checkpointing）与基于 SDPA 的注意力以降低显存占用。所选训练轨迹总计约 142K NPU 小时。

#### 5.1.4 纠缠统一表示的辅助诊断研究

作为独立于最终设计的辅助诊断实验，我们研究"同时支持语义理解与高保真重建"本身是否足以支撑生成建模。我们构造一个**故意纠缠（entangled）**的表示：将语义与重建特征经 MLP 融并进单一潜空间，不做显式分解。如图 5 所示，该诊断变体在真实编码 latents 上表现良好：zero-shot 准确率 78.53（SigLIP 基线为 79.10）、rFID 0.069、PSNR 33.83。

然而，纠缠表示无法支持忠实的生成解码。在该融合表示上训练 DiT 先验后，用预训练高保真重建解码器 $D_r$ 解码生成的 latent $\widehat{Z}_m$ 得到 FID 120.9，表明严重的生成失败。有趣的是，用语义解码器 $D_s$ 解码同一 $\widehat{Z}_m$ 却得到低得多的 FID 8.07。这并不表示统一潜空间中的生成成功；而是说明生成先验主要捕获了主导的语义结构，而未能保留 $D_r$ 所需的重建相关信息。

我们进一步发现，合并器输出变化的约 95% 可由语义通路解释。这种语义主导性解释了解码器依赖的生成差距：生成的 latent 虽保留了足以让 $D_s$ 产生合理图像的语义结构，却不保留 $D_r$ 高保真解码所需的细粒度方向。这些结果揭示了**表示质量与生成可建模性（generative modelability）之间的差距**：真实编码 latents 上的良好重建并不保证生成之后的忠实重建。这正启发了我们的显式因子分解（explicit factorization）——$T_s$ 与 $\widetilde{T}_r$ 沿通道维度拼接，使重建组件在流匹配训练中可直接被寻址。纠缠表示与诊断协议的细节见附录 C。

> **图 5（纠缠统一表示的诊断研究）**：由语义与重建表示构造 MLP 融合 token $Z_m = M(Z_s, Z_r)$ 并与二者同时对齐。尽管 $Z_m$ 在真实编码 latents 上支持强理解与高保真重建，其生成解码在使用预训练高保真重建解码器 $D_r$ 时失败（FID 120.9）；用语义解码器 $D_s$ 解码同一生成 latent 得到低得多的 FID 8.07，表明生成先验捕获了语义结构，却未能在纠缠潜空间中保留重建相关信息。

### 5.2 扩展统一多模态建模（Scaling Unified Multimodal Modeling）

我们接下来研究所提统一表示能否从受控表示学习扩展到完整多模态系统。UniSpace 的目的并非单独隔离表示本身：它将冻结的统一编码器—解码器与 8B 混合 Transformer 专家骨干相结合，并在大规模内部生成、编辑与理解数据上训练。因此我们把 UniSpace 用作**系统级验证**。中心问题是：单一基于 ViT 的视觉空间能否取代"语义图像 token + VAE latents"的常规分离，同时仍然支撑实用的生成与编辑。

同一模型也保留了理解通路，但我们不把 UniSpace 的系统级理解分数作为本文的主要证据。UniSpace 主要面向生成与编辑优化，其后训练配方并非为最大化标准 VLM 基准而设计。统一表示本身的理解能力已由表 4 的受控实验验证（其中所有任务均使用完整统一表示 $T_u$）。

## 6 局限（Limitation）

我们的结果确立了共享视觉表示的可行性，但并不意味着在所有下游任务上均有统一提升。UniSpace 主要面向生成与编辑优化，其系统级理解性能仍落后于专用视觉—语言模型——尽管受控实验表明该表示本身大体保留了原始语义编码器的能力。此外，由于该编码器同时作为理解与生成的统一表示，在理解数据上训练时无法在不潜在损害生成能力的前提下自由更新它。这一架构约束限制了视觉理解的进一步提升。未来工作的重要方向因此是探索统一表示与统一多模态模型（UniMM）如何联合优化，同时在理解与生成之间维持平衡。

---

## 7 结论（Conclusion）

我们提出了补丁重参数化（Patch Reparameterization）——一种不修改 Transformer 块、将预训练语义 ViT 转变为统一视觉分词器的最小化改造。通过保留原始语义通路、引入重建感知补丁通路、并显式因子化二者输出，所提表示在单一冻结参数空间内支持多模态理解、高保真重建与生成。更广泛地，我们的发现表明：统一视觉能力不必从训练新视觉骨干开始——改变信息进入既有语义编码器的方式，就足以暴露出范围大得多的视觉信息。

将同一冻结表示扩展为 UniSpace 进一步表明：单一视觉空间可以在大型多模态系统中取代常规的 ViT–VAE 双接口。在一个 8B 混合专家模型内，UniSpace 支持多模态理解、高质量图像编辑与实用的文生图生成。特别地，它在保持紧凑 8B 模型规模的同时实现了高质量图像编辑与具竞争力的文生图生成，展示了统一视觉空间在大规模多模态系统中的实用性。我们发布完整的 UniSpace 系统，希望它能促进统一多模态模型的进一步研究。

## 附录 C 纠缠表示与诊断协议

我们补充 5.1.4 节诊断实验的细节。设 $I$ 为输入图像，且

$$
Z_s = E_s(I), \qquad Z_r = E_r(I)
$$

分别表示预训练语义编码器与重建导向编码器的输出。我们用 MLP 合并两种表示：

$$
Z_m = M([Z_s; Z_r]),
$$

其中 $[\cdot\,;\cdot]$ 表示通道级拼接。与本文方法的因子化表示不同，$Z_m$ 不保留显式的语义—重建分解。

合并器以正文所述的相同语义与重建对齐目标训练：$Z_m$ 与 $Z_s$ 对齐以保留语义信息，$Z_m$ 的一个线性投影与 $Z_r$ 对齐以保留重建相关信息。语义解码器 $D_s$ 与高保真重建解码器 $D_r$ 在诊断实验之前分别训练，其对应编码器保持冻结。在表示层面，所得 $Z_m$ 在真实编码 latents 上同时支持语义理解与高保真重建：zero-shot 准确率 78.53（SigLIP 基线 79.10），PSNR 33.83，rFID 0.069。

随后我们直接在 $Z_m$ 上以与主实验相同的图像分布与评估协议训练 DiT 先验 20 epochs。所得生成 latent 呈现显著的解码器依赖差距：用高保真重建解码器 $D_r$ 解码得 FID 120.9，而用语义解码器 $D_s$ 解码得低得多的 FID 8.07。该差距表明 DiT 先验主要学习了纠缠表示中语义主导的变化，而未能建模 $D_r$ 所需的重建相关变化。因此，$Z_m$ 在真实编码 latents 上同时支持语义理解与高保真重建，并不保证两类信息对生成先验同样可及——重建信息确实存在，但其与语义变化的纠缠组合使生成模型难以识别与控制。

为量化语义通路的相对贡献，我们测量合并器输出变化中可由语义输入解释的比例：

$$
\rho_s = \frac{\mathrm{Var}(M(Z_s, 0))}{\mathrm{Var}(M(Z_s, Z_r))}.
$$

方差在评估图像集合上用相同合并器参数计算。我们得到 $\rho_s \approx 95\%$，即合并器输出变化大部分由语义通路解释。这表明重建相关方向虽足以重建真实编码 latents，却只占据纠缠潜空间中相对较小且难以控制的部分。这一观察启发了最终表示所用的显式因子分解：$T_s$ 与 $\widetilde{T}_r$ 沿通道维度拼接，并在流匹配训练中保持直接可及。

## 创新点提炼

1. **定位重建瓶颈：补丁嵌入而非冻结 Transformer 块**。通过严格的受控诊断实验（仅将 SigLIP2 的预训练补丁嵌入替换为随机线性投影、其余全部冻结），发现最后一层 PSNR 反而从 20.96 升至 24.66（+3.70 dB）。这证明语义 ViT 的高维隐藏空间本可携带像素级细节，细节丢失是原始输入参数化对信息通路的"选择性抑制"，而非骨干能力的缺失，从根因上推翻了"语义编码器不能重建"的常见假设。

2. **补丁重参数化（Patch Reparameterization）双通路设计**。保留冻结的原始语义补丁嵌入 $P_s$ 与冻结 Transformer 块 $F_\phi$，新增一条从 $P_s$ 初始化、面向重建优化的补丁嵌入 $P_r$，两条 token 流共享同一套冻结 ViT 参数空间。以最小化改造得到 PR-SigLIP2、PR-DINOv2、PR-Qwen-ViT 系列统一分词器：语义理解不降反微升（如 PR-SigLIP2 平均 64.37 vs 基线 63.39），同时 rFID 低至 0.14、甚至超过 FLUX-VAE 等专用生成式 VAE。

3. **显式 Token 融合 + 通道压缩的可控表示结构**。不同于用 MLP 把语义与重建特征纠缠合并，重建 token 先经 $W_r$ 压缩到 128 维再与语义 token 沿通道拼接（768+128），保持语义/重建信息的显式边界。附录 B/C 的消融与诊断证明：无压缩（768+768）虽提升纯重建（rFID 0.085）却令生成 FID 大幅恶化；纠缠表示尽管"理解+重建"俱佳（PSNR 33.83、rFID 0.069），生成解码却崩溃（$D_r$ 解码 FID 120.9，95% 输出方差由语义通路主导）——显式分解是生成可建模性的关键。

4. **平衡流匹配目标（BFM）**。将统一表示按语义/重建两组件分区，按各自维度数（$Na$、$Nb$）归一化预测误差，并用显式权重 $\lambda_r$ 控制重建组件的目标份额（取 0.75）。附录 A 消融显示存在中间最优（$\lambda_r=0.75$ 时 FID 7.10，而 0.25 时 8.99、0.92 时 7.39），使"高保真重建"与"易于生成建模"两个目标在同一潜空间中达到平衡。

5. **UniSpace：消除 VAE 双通路的单一视觉空间统一模型**。将 PR-Qwen-ViT 编码器—解码器作为 8B Qwen3 MoT（混合 Transformer 专家）模型的唯一冻结视觉接口，参考图像、目标图像与生成输出全部表示于同一 $T_u$ 空间（对比 BAGEL 的 SigLIP+FLUX-VAE 双空间），理解用 next-token 交叉熵、生成与编辑共享同一 BFM 目标，仅条件上下文不同；配合 256→512→1024 渐进分辨率训练课程与打包多模态训练（约 510M 样本、470B token、142K NPU 小时）。

6. **系统级验证统一表示的实用性与可扩展性**。8B 规模下 ImgEdit 总评 4.28（显著超同规模 SenseNova-U1 的 3.90 与 BAGEL 的 3.20，接近 32B Emu3.5 的 4.41）；GEdit 双语平均 7.395；OneIG-Bench 双语平均 0.547（统一模型中最高）；DPG-Bench 86.49 且 Relation 分 94.97 为全部对比模型最高。这证明了"重参数化预训练语义 ViT 可作为大规模统一多模态建模的共享视觉接口"这一核心命题，并完整开源了系统。
