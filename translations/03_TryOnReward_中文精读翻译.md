## 摘要

虚拟试穿（Virtual Try-On, VTON）旨在为人物穿上参考服装，生成视觉合理且符合人类偏好的结果。要把这种面向偏好的目标转化为可执行的优化目标，依赖于一个与人类审美对齐的打分函数。然而，经典保真度指标与人类判断的相关性很弱，而通用视觉-语言模型（Vision-Language Model, VLM）也无法提供试穿质量评估所需的判别粒度——试穿评估的关键在于忠实保留服装与人物细节。这一缺陷在强化微调（Reinforcement Fine-Tuning, RFT）优化中被进一步放大，导致严重的奖励作弊（reward hacking）。为此，我们提出 TryOnReward，一个专为 VTON 定制的细粒度奖励模型。它构建在视觉-语言骨干网络之上，采用注视校准目标（foveation calibration objective）把每个质量维度锚定在相关区域，避免全局捷径学习（global shortcut learning）。同时，TryOnReward 通过边际感知监督（margin-aware supervision）联合优化成对偏好与各维度质量分数，同时利用相对与绝对质量信号。为支撑模型训练与评估，我们构建了人工逐维度评分数据集 TryOnReward-100K，以及覆盖多样真实场景的两个基准 TryOn-Bench 与 TryOnRewardBench。大量实验证实，TryOnReward 在人类偏好对齐上显著优于通用评判模型；作为 RFT 奖励函数使用时，它在多个基线上持续产出更受人类偏好的试穿结果。

## 1 引言

**图 1**：不同奖励模型所关注区域的可视化。通用 VLM 倾向于产生弥散的注意力，这对细粒度识别任务是有害的。相比之下，我们的 TryOnReward 正确关注了注视一致性（foveated consistency）评估所需的关键区域。

虚拟试穿（VTON）旨在用指定服装为目标人物进行数字化穿衣 (Chong et al., 2025a; Feng et al., 2026)。得益于现代生成模型，该任务进展迅猛。随着合成质量日趋成熟，前沿正从产出「合理」（plausible）的结果转向产出「受偏好」（preferred）的结果。触及这一前沿的关键在于一个与人类审美对齐的打分函数，它扮演两个互补角色：一是以人类判断为基准对试穿模型进行评测，二是为强化微调（RFT）(Zheng et al., 2025a; Liu et al., 2026; Xu et al., 2026) 提供优化信号——RFT 是日益主流的后训练范式，用于引导策略产出人类偏好的结果 (Wang et al., 2025b; Luo et al., 2025; Zhong et al., 2025)。因此，一个能可靠捕捉人类偏好的奖励模型，是筛选高质量生成与推动虚拟试穿系统进步的核心。

然而，试穿质量打分的要求极为苛刻。与一般参考图像生成不同，VTON 必须在渲染逼真结果的同时，忠实保留细粒度服装属性（如 logo、纹理与织法）以及人物身份，且不能出现轮廓形变或编辑伪影。质量因此取决于区域级的细节，而单一整体分数恰恰容易忽视这些细节。当今的打分器正是这类不理想的整体式打分：经典保真度指标（SSIM、LPIPS、FID）与人类判断相关性很差；通用奖励模型——ImageReward (Xu et al., 2023)、BaseReward (Zhang et al., 2025)、HPSv3 (Ma et al., 2025)、EditReward (Wu et al., 2025c)——以及现成的 VLM 评判器 (Bai et al., 2025; Wang et al., 2025a; Chng et al., 2025) 则面向宽泛的图文对齐、以整体美感为目标。它们缺乏试穿所需的区分力，会漏掉服装细节丢失与身份漂移（identity drift）这类微妙但致命的失败。这一盲区不只是评估上的麻烦——在 RFT 下它还会被主动利用：当整体式奖励驱动 RFT 时，策略会漂移向整体上吸引人、但服装错配或身份偏移的图像，而测得的奖励却持续攀升（即奖励作弊）。

两个设计缺口解释了这一弱点。**第一，现有奖励模型对视觉证据利用不足。** 细粒度 VTON 评估需要跨图像比较特定区域——参考服装对应输出中的服装区域、输入与输出中承载人物身份的区域——然而 VLM 往往依赖语言先验与粗粒度语义表征，而非任务相关的视觉 token (Guan et al., 2024; Zheng et al., 2025b)，其注意力很容易被显著但无信息量的内容吸引 (Lin et al., 2025)（如图 1 所示）。**第二，它们的奖励表示过于狭隘。** 成对偏好学习 (Ma et al., 2025; Zhang et al., 2025) 把偏好候选排在被拒候选之上——非常适合排序与 RFT，但只捕捉偏好方向，因此 (5,4) 与 (5,1) 两对评分被同等对待，尽管二者的质量差距截然不同；点级回归（pointwise regression）(Li et al., 2026; Zhang et al., 2026) 能传达绝对质量，但对标注主观性敏感，且不强制任何显式排序。二者互补，促使我们提出同时捕捉相对排序与绝对分数语义的统一形式化。

为应对这些挑战，我们提出 TryOnReward，一个专为 VTON 定制的细粒度奖励模型。它构建于视觉-语言骨干网络之上，把人类偏好分解为三个核心维度——服装一致性（Garment Consistency）、身份一致性（Identity Consistency）与视觉质量（Visual Quality）——并为每个维度学习任务特定的评判标准。为弥合第一个缺口，我们提出注视校准目标（Foveation Calibration Objective, FCO）：在图像-掩码先验引导下，把每个维度锚定到其相关区域，引导模型远离全局捷径。为弥合第二个缺口，我们在一个框架内统一两种范式：对每个维度，一个奖励头（Reward Head）学习候选间的相对偏好，一个评分头（Score Head）回归人类评分，并利用候选间分数差作为边际感知监督。这些设计共同产出一个同时编码排序一致性、评分语义与偏好强度的奖励空间，为试穿优化提供更具判别力的信号。为训练与评估该模型，我们构建了 TryOnReward-100K——含 99,286 条人工逐维度评分样本的大规模数据集，以及覆盖多样输入形式、人物分布与真实场景的基准 TryOnRewardBench。大量实验表明，TryOnReward 对人类偏好的对齐显著优于通用评判模型；作为 RFT 奖励使用时，它在各种基线上产出持续受人类偏好的试穿结果。

**本文贡献总结如下：**

- 我们提出 TryOnReward，一个 VTON 专用奖励模型，把人类偏好分解为服装一致性、身份一致性与视觉质量；并构建 TryOnReward-100K 与 TryOnRewardBench，支撑试穿奖励模型的训练与系统评估。
- 我们提出注视校准目标，把每个质量维度锚定到任务相关区域，使奖励预测基于可靠的视觉证据；并提出统一成对偏好学习与点级分数回归的奖励学习形式化，联合捕捉偏好次序、评分语义与偏好强度。
- 在 TryOnRewardBench、DressCode、VITON-HD 与 TryOnBench 上的大量实验证明，TryOnReward 对人类偏好的对齐远优于通用评判模型，且作为 RFT 奖励在各基线上持续提升试穿质量。

## 2 相关工作

### 2.1 虚拟试穿

近年来 VTON 的进展主要由扩散模型驱动：TryOnDiffusion (Zhu et al., 2023)、OOTDiffusion (Xu et al., 2025)、CatVTON (Chong et al., 2025a) 等方法通过有效的服装特征融合提升服装保真度。更近期的方法进一步探索扩散 Transformer 与统一试穿框架，包括 Leffa (Zhou et al., 2025) 与 OmniTry (Feng et al., 2026)，追求更精细的细节保留、更广的适用性与免掩码生成。与此同时，基于 RFT 的后训练也被引入 VTON，Tstars-Tryon (Chen et al., 2026) 利用多奖励优化来提升生成质量。然而，现有 VTON 方法仍缺乏一个能够评估任务特定一致性、并为 RFT 优化提供可靠监督的专用细粒度奖励模型。

### 2.2 奖励模型

奖励模型通过提供与人类对齐的优化信号，已成为生成模型 RFT 后训练的关键组件。在视觉生成中，HPS 系列 (Wu et al., 2023; Ma et al., 2025) 从大规模标注中学习人类偏好，近期基于 VLM 的方法进一步把奖励建模扩展到更广的场景：RewardDance (Wu et al., 2025b) 探索可扩展的 VLM 奖励预测，OneReward (Gong et al., 2025) 为多任务图像生成开发统一奖励模型，EditReward (Wu et al., 2025c) 则面向指令引导的图像编辑。尽管如此，这些通用奖励模型主要面向单图生成或编辑任务，无法满足 VTON 的需求——后者需要多输入推理以及对服装与身份一致性的区域级评估。相比之下，我们提出 VTON 专用奖励模型，把人类偏好分解为服装一致性、身份一致性与视觉质量，并通过带 FCO 的成对-点级统一学习提供细粒度的任务感知监督。

## 3 数据集策划与构建

**图 2**：数据构建流程与 TryOnRewardBench 构成概览。

### 3.1 TryOnReward-100K

为训练 TryOnReward，我们采用四阶段流程构建 TryOnReward-100K：源数据收集与过滤、候选生成、配对构建、偏好标注（如图 2 所示）。我们从开源数据集、公开网络来源、电商平台与实拍图中收集并整理多样的服装与人物图像。使用所得的服装-人物条件，我们以四个先进图像编辑模型生成多样的试穿候选：Nano Banana Pro (Google, 2025)、Qwen-Image-Edit-2511 (Wu et al., 2025a)、FireRed-Image-Edit 1.0 (Team et al., 2026) 与 JoyImage (Song et al., 2026)。经候选级质量过滤后，保留 87,871 个实例，每个实例由一张服装图、一张人物图、一个生成结果及对应指令组成。同一服装-人物条件下的候选随后两两配对，得到 118,074 个用于偏好标注的原始样本对。

我们沿三个维度标注每个候选：服装一致性（服装细节、纹理、颜色与合身度）、身份一致性（脸部、体型、四肢与姿态）与视觉质量（清晰度、噪声、模糊与伪影）。每个候选由至少九名标注者在 (1)–(5) 分制上打分。为降低主观性与标签噪声，所有样本对由不同团队在同一指南下独立重新标注，跨轮差异较大的样本对被剔除。最终得到 99,286 个高质量偏好样本对，构成 TryOnReward-100K 训练集。详细标注指南见原文附录 A。

### 3.2 TryOn-Bench 与 TryOnRewardBench

为全面评估奖励模型及用其训练的试穿模型，我们构建 TryOn-Bench 与 TryOnRewardBench。二者基于同一批服装-人物条件图像；区别在于 TryOnRewardBench 额外纳入多个模型的生成结果及这些结果上的人类偏好标注，以直接检验 TryOnReward 对不同输出的识别是否与真实人类偏好对齐。具体地，我们用六个模型生成候选结果：Nano Banana Pro (Google, 2025)、SeedDream 5.0 (ByteDance, 2026)、SeedDream 4.5 (ByteDance Seed Team, 2025)、Qwen-Image-Edit-2511 (Wu et al., 2025a)、JoyImage (Song et al., 2026) 与 GPT-Image-2 (OpenAI, 2026a)。

两个基准覆盖互补的 VTON 设定：**Cloth2Model** 与 **Model2Model**。Cloth2Model 包含 9,844 对，以平铺商品图作为服装参考，对应标准的「商品图到人」试穿场景。Model2Model 包含 7,045 对，其中源服装穿在另一个人身上。相比 Cloth2Model，它更具挑战性，因为模型必须把服装外观从源穿着者中解耦，并执行复杂的跨人外观迁移。两个子集的服装类别分布见图 2(b)。需要指出，TryOnReward-100K 与 TryOnRewardBench 严格不相交：没有共享的源图像、条件或生成样本。

## 4 方法

**图 3**：TryOnReward 概览。构建于共享的 VLM 骨干网络之上，对服装一致性、身份一致性与视觉质量执行维度特定的评估。TryOnReward 联合建模三个维度上的成对偏好与点级人工分数，同时利用掩码引导的注视校准目标把奖励预测锚定在维度特定的视觉证据上。

**问题设定**：给定参考服装图像 $I^g$、目标人物图像 $I^p$ 与生成的试穿结果 $I^c$，我们的目标是沿三个维度学习细粒度奖励：服装一致性、身份一致性与视觉质量。记维度集合 $\mathcal{D}=\{\mathrm{gar},\mathrm{id},\mathrm{vis}\}$。每个训练样本包含一个服装-人物条件 $(I^g, I^p)$ 与一对试穿候选 $\mathcal{C}=\{A,B\}$。对每个 $c\in\mathcal{C}$ 与 $d\in\mathcal{D}$，提供人工评分 $s_c^d\in\{1,\ldots,5\}$。这些标注同时监督相对偏好次序、绝对评分语义与偏好强度。

### 4.1 模型架构

如图 3 所示，TryOnReward 构建在一个共享的视觉-语言骨干网络之上。给定参考服装 $I^g$、目标人物 $I^p$ 与生成试穿结果 $I^c$，模型为每个评估维度 $d\in\mathcal{D}$ 提取维度条件化的多模态表征 $\mathbf{h}_c^d=F_\theta(I^g,I^p,I^c,P^d)$，其中 $P^d$ 为该维度专用的评估提示词。为了在保留共享视觉表征的同时解耦三个评估准则，我们在每个维度上挂接一个独立的奖励头 $R_d$ 与评分头 $S_d$：

$$(\mu_c^d,(\sigma_c^d)^2)=R_d(\mathbf{h}_c^d),\qquad \mathbf{z}_c^d=S_d(\mathbf{h}_c^d)\in\mathbb{R}^{5}. \tag{1}$$

两个头刻画人类监督中互补的方面。细粒度 VTON 判断可能存在歧义，尤其当两个候选仅存在细微差异时。遵循不确定性感知奖励建模（uncertainty-aware reward modeling）(Ma et al., 2025; Wu et al., 2025c)，奖励头参数化一个高斯分布 $p_c^d(r)=\mathcal{N}(r;\mu_c^d,(\sigma_c^d)^2)$，用于为成对偏好提供监督信号：其均值表示标量奖励，标准差刻画预测不确定性。与此同时，评分头预测五个人工评分档位上的 logits，提供显式的点级监督。两头的联合优化使模型能同时学习绝对与相对的质量概念，从而对质量参差的生成结果实现更密集、更有效的监督信号利用。推理时，$\mu_c^d$ 用作该维度的奖励，总体奖励计算为 $r_c=\frac{1}{|\mathcal{D}|}\sum_{d\in\mathcal{D}}\mu_c^d$。评分头仅在训练阶段使用，不会给候选排序或在线 RFT 引入任何额外开销。

### 4.2 注视校准目标（FCO）

可靠的 VTON 评估要求每个奖励维度关注恰当的视觉证据。然而，由于广泛的视觉-语言对齐训练，VLM 通常对视觉 token 缺乏注意力且极易分心。为此，我们提出利用掩码先验（mask priors）(AI, 2024; Xie et al., 2021) 为候选 $c$ 定义维度特定的目标 token 集合 $\mathcal{S}_c^d$：服装一致性对应参考服装图与生成图中的服装区域；身份一致性对应目标人物图与生成图中的人物区域；视觉质量对应整张生成图。这些掩码仅在训练阶段提供空间监督，推理时不需要。

记 $a_{c,d,j}$ 为在维度 $d$ 下评估候选 $c$ 时分配给视觉 token $j$ 的注意力。相应目标区域内的总注意力质量为：

$$m_c^d=\sum_{j\in\mathcal{S}_c^d}a_{c,d,j}. \tag{2}$$

我们用下式鼓励模型集中于维度相关的视觉证据：

$$\mathcal{L}_{\mathrm{FCO}}=-\mathbb{E}_{c,d}\left[\log\left(m_c^d+\epsilon\right)\right]. \tag{3}$$

该目标提升分配给相关视觉区域的注意力，但不在区域内强加固定分布，允许模型灵活定位每个评估维度所需的证据。实践中，我们将该公式独立应用于最后一层的每个注意力头，并对各头的损失取平均。

### 4.3 多维成对排序

基于式 (1) 的不确定性感知奖励形式化，我们把成对偏好学习表述为概率化排序，而非直接比较确定性的奖励分数。对每个评估维度 $d$，记 $w_d, l_d\in\mathcal{C}$ 分别为偏好候选与被拒绝候选的索引。维度级偏好概率通过对两个潜在奖励分布边缘化（marginalizing）成对似然得到：

$$P_d(I^{w_d}\succ I^{l_d})=\iint\operatorname{sigmoid}(r_w-r_l)\cdot p_{w_d}(r_w)\,p_{l_d}(r_l)\,\mathrm{d}r_w\,\mathrm{d}r_l. \tag{4}$$

其中 $p_{w_d}(r_w)$ 与 $p_{l_d}(r_l)$ 表示两个候选在维度 $d$ 下预测的高斯奖励分布。通过对这些分布边缘化，偏好概率同时纳入了期望奖励差异与每次预测相关的不确定性。不确定性感知排序损失定义为观测人类偏好的负对数似然：

$$\mathcal{L}_{\mathrm{rank}}^d=-\log P_d(I^{w_d}\succ I^{l_d}). \tag{5}$$

这样，目标在保留维度特定偏好信号的同时，显式考虑了细粒度 VTON 评估中固有的不确定性。

### 4.4 边际感知点回归

成对偏好监督只指明哪个候选更受偏好，并未显式刻画二者的绝对质量水平或偏好幅度。为恢复这一信息，我们用评分头预测每个候选的人工评分。对候选 $c\in\{A,B\}$，评分 logits 定义五档评分上的类别分布：

$$p_c^d(k)=\operatorname{softmax}(\mathbf{z}_c^d)_k,\qquad k\in\{1,\ldots,5\}. \tag{6}$$

我们首先用标准交叉熵损失监督预测评分分布：

$$\mathcal{L}_{\mathrm{score}}^d=-\sum_{k=1}^{5}y_{c,k}^d\log p_c^d(k). \tag{7}$$

其中 $y_{c,k}^d$ 为候选 $c$ 在维度 $d$ 下的人工评分标签。该目标把学到的表征锚定到 1–5 评分刻度的语义上，使模型能区分不同的绝对质量水平。

此外，由于交叉熵无法刻画评分的序数结构，我们推导一个可微的期望分数：

$$\widehat{s}_c^d=\sum_{k=1}^{5}k\,p_c^d(k). \tag{8}$$

给定人工评分分别为 $s_A^d$ 与 $s_B^d$ 的两个候选，定义 $\Delta_s=s_{\max}-s_{\min}$ 为最大分差。预测与标注分差之间的归一化残差为：

$$e^d=\frac{(\widehat{s}_A^d-\widehat{s}_B^d)-(s_A^d-s_B^d)}{\Delta_s}. \tag{9}$$

边际感知的分数差目标用 Smooth L1 损失形式化：

$$\mathcal{L}_{\mathrm{gap}}^d=\begin{cases}\frac{1}{2}(e^d)^2,& |e^d|<1,\\[4pt] |e^d|-\frac{1}{2},& |e^d|\geq 1.\end{cases} \tag{10}$$

标注分数差提供了一个与偏好强度成比例的自适应边际。通过共享的 VLM 骨干，点级评分监督与分数差回归相辅相成，与成对偏好学习互为补充。

**总体训练目标**。综合所有监督信号，整体训练目标为：

$$\mathcal{L}_{\mathrm{total}}=\frac{1}{|\mathcal{D}|}\sum_{d\in\mathcal{D}}\left(\mathcal{L}_{\mathrm{rank}}^{d}+\lambda_{\mathrm{score}}\mathcal{L}_{\mathrm{score}}^d+\lambda_{\mathrm{gap}}\mathcal{L}_{\mathrm{gap}}^d\right)+\lambda_{\mathrm{FCO}}\mathcal{L}_{\mathrm{FCO}}. \tag{11}$$

其中排序目标学习相对偏好，评分目标保留绝对评分语义与偏好强度，而注视校准目标把所得奖励锚定于维度相关的视觉证据。

## 5 实验

### 5.1 实现细节

我们采用 Qwen3VL-8B-Instruct (Bai et al., 2025) 作为预训练骨干，并进行全参数微调以优化整个模型。学习率为 $2\times 10^{-6}$，采用余弦学习率调度，warm-up 比例为 0.05，总 batch size 为 16。为提升训练稳定性，所有输入图像被统一预处理到 672×672 分辨率，同时缩放时保持原始宽高比。损失权重 $\lambda_{\mathrm{score}}$、$\lambda_{\mathrm{gap}}$ 与 $\lambda_{\mathrm{FCO}}$ 分别设为 0.1、0.05 与 0.05。更多训练细节见原文附录 B。

### 5.2 评测设置

我们从人类偏好对齐与作为在线 RFT 奖励的有效性两个方面评估 TryOnReward。

**偏好对齐**：在 TryOnRewardBench 上测量模型预测与人类标注的一致性。对比对象包括开源 VLM：Qwen3-VL (Bai et al., 2025)、Qwen3.5 (Qwen Team, 2026)、InternVL3.5 (Wang et al., 2025a)；以及闭源模型：GPT-5 (Singh et al., 2025)、GPT-5.4 (OpenAI, 2026b)、Gemini-3.0-Pro (Pichai, 2025)。我们报告成对准确率与严格的 K 路准确率（K-way accuracy）。成对准确率衡量预测偏好与人类偏好的一致程度；总体准确率中，真值（GT）偏好由三个维度的人工评分均值确定，并与预测总体分数导出的偏好进行比较。对于 K 路准确率，遵循固定的生成器排序，对每个输入按预测总体分数对前 K 个结果排序，并与由维度评分均值导出的人类排序比较；因此 K=2 评估指定的前两个生成器。只有当全部 $\mathrm{C}_K^2$ 个预测成对关系都与人类排序一致时，该排序才算正确。我们报告 K=2,…,6 的结果。

**奖励引导 RFT**：使用 DiffusionNFT (Zheng et al., 2025a) 进行在线后训练，并在 TryOn-Bench 上评估所得策略。采用 Qwen-Image-Edit-2511 (Wu et al., 2025a) 与一个微调过的 VTON-SFT 版本作为策略模型，并与 HPSv3 (Ma et al., 2025)、EditReward (Wu et al., 2025c)、以及基于评分量规（rubric-based）打分的 Gemini-3.0-Pro 作为奖励函数进行对比。我们使用 GPT-5 作为独立的自动评估器，对每个结果在服装一致性、身份一致性与视觉质量上给出 1–5 的评分，并以三者平均作为总体分数。由于 GPT-5 不同于所有被比较的奖励函数、且对所有方法统一使用，可避免自我评估偏差。其作用仅限于 RFT 之后的粗粒度比较，与「通用 VLM 不足以充当细粒度 RFT 奖励」这一论断是正交的。为进一步验证结果，原文附录 E 报告了补充性人类用户研究。

**域外泛化**：在 DressCode (Morelli et al., 2022) 与 VITON-HD (Choi et al., 2021) 上评估 RFT 优化后的模型——两者均未在 RFT 中使用——指标为 FID、KID、LPIPS 与 SSIM。对比的代表性 VTON 方法包括 IDM-VTON (Choi et al., 2024)、OOTDiffusion (Xu et al., 2025)、CatVTON (Chong et al., 2024)、Leffa (Zhou et al., 2024)、PromptDresser (Kim et al., 2024)、Any2AnyTryon (Guo et al., 2025) 与 FastFit (Chong et al., 2025b)，以检验在 TryOn-Bench 上的后训练能否迁移到成熟的 VTON 基准。

## 6 结论

本文提出了 TryOnReward，一个为虚拟试穿定制的细粒度奖励模型。TryOnReward 将人类偏好分解为服装一致性、身份一致性与视觉质量，并引入维度特定的注视校准学习方法，把奖励预测锚定于任务相关的视觉证据。它进一步统一了成对偏好学习与点级分数回归，使学到的奖励空间能够同时刻画排序一致性、评分语义与偏好强度。为支撑奖励模型的训练与系统评估，我们构建了 TryOnReward-100K、TryOn-Bench 与 TryOnRewardBench。大量实验证明，TryOnReward 能够更好地对齐人类偏好，并为试穿模型的强化学习提供有效的奖励信号。

## 创新点提炼

1. **VTON 专用的细粒度多维奖励模型**。TryOnReward 首次把奖励建模系统性地引入虚拟试穿，将人类偏好分解为服装一致性、身份一致性与视觉质量三个维度，并为每个维度学习任务特定的评判标准。这填补了试穿领域缺乏专用奖励模型的空白，使奖励信号能捕捉通用 VLM 判别不了的区域级失败（如服装细节丢失、身份漂移）。

2. **注视校准目标（FCO）：把注意力钉在任务相关区域**。利用服装/人体解析掩码先验为每个质量维度定义目标 token 集合，通过最大化相关区域的注意力质量，把奖励预测锚定在可靠的视觉证据上，抑制 VLM 的全局捷径学习与语言先验依赖。该目标仅在训练时使用掩码、推理零开销，且不约束区域内部的注意力分布，保留了模型自主定位证据的灵活性。

3. **不确定性感知的多维成对概率排序**。奖励头输出高斯分布（均值为标量奖励、标准差为预测不确定性），成对偏好概率通过对两个潜在奖励分布做二维边缘化得到，显式建模了细粒度试穿评估中固有的判断歧义。相比直接比较确定性分数，该设计令排序对主观标注噪声更鲁棒。

4. **边际感知的点级评分回归：统一成对与点级监督**。评分头以交叉熵预测 1–5 分档分布，并通过可微期望分数与 Smooth L1 回归拟合候选间的人工分差，把「偏好强度」作为自适应边际引入训练。由此在单一框架内同时编码排序一致性、评分语义与偏好强度，成对与点级监督经由共享骨干相互增强。

5. **高质量数据与双基准体系**。TryOnReward-100K 提供 99,286 对经三维度 1–5 人工评分、多团队交叉重标的质量偏好对；TryOn-Bench / TryOnRewardBench 覆盖 Cloth2Model 与更具挑战性的 Model2Model 两种场景、六个主流生成器的输出，且与训练集严格不相交，为奖励模型与试穿策略提供了可信的训练与评测基础。

6. **实证可防奖励作弊、可泛化的 RFT 增益**。作为在线 RFT（DiffusionNFT）的奖励函数，TryOnReward 在两个策略模型上均持续提升人类评分（如 Qwen-Image-Edit-2511 在 Model2Model 上总体分 3.047→3.564），并在未参与训练的 DressCode / VITON-HD 上保持领先或具竞争力，说明区域接地（region-grounded）的奖励设计能带来不易被 hack、可泛化到域外的优化收益。
